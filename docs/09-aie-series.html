「AI 엔지니어링 처음부터」 20권 시리즈

공개 커리큘럼 rohitg00/ai-engineering-from-scratch(MIT, 20개 단계·523개 레슨)를 단계 하나당 한 권으로 나누어, 서재의 책 구성 표준에 맞춘 한국어 인터랙티브 책으로 다시 씁니다.

정한 것

  • 요청: 2026-10-08 사용자가 원본 저장소의 내용을 모두 분해해 시리즈 도서로 추가하라고 요청했습니다.
  • 라이선스: 원본은 MIT(Copyright 2026 Rohit Ghumare)입니다. 원문과 코드를 번역해 옮기지 않고, 레슨의 개념·순서·실험 아이디어를 참고해 새로 씁니다. 모든 권의 참고 자료와 꼬리말, 장마다의 "더 읽어 보기"에 원본 레슨 링크를 둡니다.
  • 분권: 원본 단계 하나가 한 권입니다. 권마다 9~12장으로 레슨을 묶고, 각 장의 "더 깊이 보기" 상자가 묶인 레슨의 핵심을 빠짐없이 정리합니다. 권마다 원본 레슨 → 장 대응표를 책 문서(docs/index.html)에 둡니다.
  • 겹침: 서재의 다른 책이 깊게 다룬 내용(예: 벡터와 행렬, 확률과 통계, AI Book의 어텐션, LLM 시스템의 KV 캐시)은 짧게 요약하고 그 책의 장으로 링크합니다.
  • 서가: 분류는 모두 'AI공학'이고, 권 순서대로 서가 끝에 붙여 세웁니다. 이웃한 권은 다른 색을 씁니다.
  • 공통 틀: 첫 권을 만들기 전에 LLM 시스템 책을 바탕으로 같은 화면 구조의 틀(app.js·visual.js·figures.js·lab-guides.js·style.css·테스트)을 만들고, 권마다 이를 복사해 씁니다. 책 사이 코드 의존은 없습니다. 틀의 경로 테스트는 장 데이터 필드, 장마다 고유하고 움직이는 개념 그림, 실험 표·안내의 짝, 원본 크레딧을 검사합니다.
  • 검수: 2026-10-08 서재 규칙에 따라 권마다 집필하지 않은 별도 에이전트가 팩트·출처를 검수하고, 기록(docs/fact-review.html)이 fixed 또는 passed가 된 뒤 병합합니다.
  • 지식 연결: 다섯 권 묶음마다 읽기 노선 하나를 더하고, 각 권의 장을 공통 개념 두 개 이상에 넣으며, 기존 책에서 오는 링크와 기존 책으로 가는 링크를 함께 둡니다.

한 권을 만드는 순서

  1. 집필 에이전트가 원본 단계의 README와 모든 레슨(docs/en.md)을 읽고, 공통 틀을 복사해 books/주제/에 책을 씁니다. 책 폴더 밖은 고치지 않습니다.
  2. 집필 에이전트가 책 테스트(npm test)와 브라우저 검사(tests/browser.cjs, 1280·390·320px의 모든 장·실험·예제·초기화·확인 문제)를 통과시키고, 서가 등록 제안(docs/registration.json)을 남깁니다.
  3. 다른 에이전트가 팩트·출처를 검수하고 docs/fact-review.html에 기록합니다.
  4. 시리즈 진행 세션이 catalog.json에 책·장 색인·공통 개념·읽기 노선을 등록하고, 기존 책에 들어오는 링크를 더한 뒤 루트 검사를 통과시켜 PR로 병합합니다.
