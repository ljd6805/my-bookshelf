서재의 첫 화면을 만든다

2026-10-07 추가 요청: 기존 자료를 탐색하는 메인페이지를 만들고 GitHub Pages로 공개한다.

이번에 구현할 것

분석 문서가 모인 허브를 서재의 실제 입구로 바꾼다. 기존 문서 주소와 내용은 보존하고, 자료 검색·분류·학습 책 등록 구조를 더한다. 첫 책의 주제와 독자는 아직 정하지 않는다.

화면과 정보 구조

차분한 편집물 형태의 밝은 화면을 사용한다. 기존 종이색·남색·파란색을 유지하고, 산세리프 글꼴과 넓은 간격으로 읽기 순서를 드러낸다. DESIGN_VARIANCE 5, MOTION_INTENSITY 2, VISUAL_DENSITY 4로 설정한다.

소개 → 자료 찾기 → 학습 책 → 서재 소개 순서로 구성한다. 실제 조사 화면을 대표 리포트의 미리보기로 사용한다. 콘텐츠 카드의 색·모서리·간격을 통일하고 새로운 브랜드 이미지를 임의로 만들지 않는다.

현재 요구의 중심은 최초 구조와 배포이므로 기존 자료를 활용해 구현한다. 책이 없는 상태, 검색 결과가 없는 상태, JavaScript를 사용하지 않는 상태에서도 안내와 문서 접근이 가능해야 한다.

수정 파일과 확인 방법

index.html, assets/home.css, assets/home.js, data/catalog.json, scripts/build_catalog.py를 중심으로 작업한다. 카탈로그에서 실제 자료와 책 목록을 생성하고 커밋한다. GitHub Pages는 main 브랜치의 루트에서 배포한다.

내부 파일·앵커 검사, 카탈로그 출력·안전한 링크·빈 상태 테스트를 수행한다. 배포 후 실제 URL에서 메인페이지, 검색, 필터, 결과 없음, 문서 이동·복귀를 확인한다. 작은 화면의 가로 넘침도 확인한다.

책 추가: data/catalog.json의 books에 항목을 등록하고 python3 scripts/build_catalog.py를 실행한다. 다른 저장소의 책은 HTTPS 배포 주소를 사용한다. 예시 책을 실제 출간된 책처럼 표시하지 않는다.
