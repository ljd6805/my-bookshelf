01

학습을 이어 가는 개인 서재

이 저장소의 목적은 각기 다른 주제의 교과서를 한곳에서 발견하고, 배운 내용을 다음 학습으로 이어 가게 하는 것이다. 책 본문은 주제별 저장소에서 독립적으로 발전시키고, 서재는 책의 연결과 공통 품질 기준을 관리한다.

사용자가 요청한 이번 작업: books.euiyun.com의 페이지 연결, 이야기 구성, 학습을 돕는 설명, 시각화 방식을 분석한다. 그 결과를 새 서재 저장소에 남겨 앞으로의 운영 기준으로 삼는다.
02

이번에 확정한 범위와 제안

구분내용
사용자 요구여러 저장소의 GitHub Pages를 연결하는 학습용 서재. Codex와 Claude 모두 작업할 수 있어야 한다.
이번 산출물원본 분석 보고서, 전체 점검 목록, 서재 운영 기준, 공동 작업 지침, 문서 허브.
구현 선택저장소 작업명은 my-bookshelf. 기본 HTML·CSS·JavaScript와 JSON만 사용한다.
권장 방향책 본문은 개별 저장소, 책 목록·읽기 경로·운영 기준은 이 저장소에서 관리한다.
이번에 하지 않는 일새 교과서 집필, 기존 교과서 수정, 사용자 계정·학습 서버 구축.
미정첫 등록 교과서와 첫 독자층. 서재 디자인은 2026-10-07에 맑은 색유리·명조체 라벨로 확정하고 GitHub Pages에 공개했다. 미정을 임의의 확정 사항으로 기록하지 않는다.
03

분석에서 운영 기준까지

  1. 포털과 출간된 32권의 첫 화면·목차를 직접 연다.
  2. 모든 발견 가능한 본문 URL과 실험 앵커를 수집하여 누락과 끊어진 연결을 검사한다.
  3. 서로 다른 학습 방식의 대표 본문과 실험을 직접 조작한다.
  4. 관찰된 구조, 그 구조의 의미, 우리 서재에 적용할 규칙을 구분해 쓴다.
  5. HTML 문서와 에이전트 지침을 작성하고 파일·링크·화면을 검증한다.
  6. 새 저장소에 저장하고 원격 상태를 확인한다. 인증이 필요한 단계는 미완료로 표시한다.
04

완료 판정 기준

  • 무엇을 직접 열었고 무엇을 정적 검사했는지 수치와 목록으로 확인할 수 있다.
  • 이야기·시각화·상호작용에 대한 제안마다 실제 사례가 있다.
  • 다음 에이전트가 대화 기록 없이 목적, 결정, 남은 일을 찾을 수 있다.
  • 모든 문서는 허브에서 접근할 수 있다.
  • 원격 저장과 배포는 실제 성공한 상태만 완료로 기록한다.
