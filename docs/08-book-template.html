MY BOOKSHELF / BOOK TEMPLATE

모든 책은 AI Book과 같은 화면과 장 구조로 만듭니다

독자가 어느 책을 펼쳐도 같은 자리에서 목차를 찾고, 같은 순서로 개념을 읽고 실험하고 확인할 수 있게 하려는 기준입니다. GPT와 Claude 중 누가 작업하더라도 이 문서만 보고 같은 구조의 책을 만들 수 있어야 합니다.

분석 대상: books/ai/ (main 2e7abd6 기준, 2026-10-08). 이 문서와 AI Book의 실제 코드가 다르면 코드를 확인한 뒤 이 문서를 고칩니다.

01

왜 표준이 필요한가

2026-10-08 사용자는 모든 책의 화면 배치와 내용 구조를 AI Book과 맞추기로 정했습니다. 책마다 머리말, 목차, 실험 상자의 위치가 다르면 독자는 책을 바꿀 때마다 사용법을 다시 배워야 합니다. 구조가 같으면 독자는 내용에만 집중하고, 작업자는 새 책을 만들 때 화면 설계를 처음부터 고민하지 않아도 됩니다.

이 문서는 books/주제/ 아래의 모든 학습 책에 적용합니다. 서가(루트 index.html)의 디자인은 유리 서가 디자인 기준을, 책과 서가의 연결은 도서 통합 기준을 따릅니다.

한 줄 요약. 새 책은 books/ai/의 파일 뼈대를 복사해서 시작하고, 머리말·두 가지 화면 모드·장 안의 일곱 블록 순서·실험 블록 형식·장 데이터 필드를 그대로 유지합니다. 색, 표지 실험, 장과 실험의 내용은 책마다 새로 만듭니다.

03

화면 뼈대: 머리말과 두 가지 모드

책 화면은 늘 위에 붙어 있는 머리말 아래에서 표지 모드와 읽기 모드 중 하나로 바뀝니다. 주소의 해시가 장 ID이면 읽기 모드(body.reading)가 되어 왼쪽에 장 목차가 나타나고, 그 밖의 해시(#home, #chapters, #sources)는 표지 모드로 그립니다.

머리말 (<header>, 높이 78px, 화면 위 고정)

  1. 왼쪽: 브랜드 링크(href="#home"). 짧은 표지 마크, 책 이름(대문자 영문 또는 짧은 한글), 부제(예: 인터랙티브 교과서).
  2. 오른쪽 <nav aria-label="주 메뉴">: 서가로 버튼 → 전체 목차(#chapters) → 참고 자료(#sources) → 테마 전환 버튼(#theme) → 목차 버튼(#menu, 760px 이하에서만 보임). 이 순서를 바꾸지 않습니다.
  3. 서가로 버튼은 <a class="shelf-return" data-shelf-return href="../../index.html#books">입니다. 320px에서도 보여야 하며 validate.py가 검사합니다(세부 기준).

본문 앞뒤

  • <a class="skip" href="#main">본문으로 이동</a>를 머리말보다 먼저 둡니다.
  • <aside id="sidebar" aria-label="챕터 탐색">은 비워 두고 JavaScript가 "CONTENTS / 전체 목차", "처음으로", 두 자리 번호가 붙은 장 링크를 채웁니다. 현재 장 링크에는 aria-current="page"를 붙입니다.
  • <main id="main" tabindex="-1">은 비워 둡니다.
  • 꼬리말: 서가 복귀 링크(data-shelf-return), 책 한 줄 소개, 책 개발 문서 링크(docs/index.html), 영감을 준 자료(있다면).
  • <noscript>로 JavaScript가 필요하다는 안내를 남깁니다.

04

표지 화면 (#home) 구성 순서

표지는 책을 처음 연 독자에게 "무엇을 할 수 있게 되는지"와 "어디서 시작할지"를 한 화면 안에서 보여 줍니다. 아래 다섯 구역을 이 순서로 둡니다.

  1. 히어로(.hero, 두 칸): 왼쪽에 영문 눈썹 문구(.eyebrow), 두 줄 제목(둘째 줄을 <em>으로 강조), 한 문단 소개, 버튼 두 개(01장부터 읽기와 대표 장으로 가는 실험 버튼), 통계 세 개(장 수 · 실험 수 · 책의 성격을 보여 주는 숫자, AI Book은 "외부 API 호출 0"). 오른쪽에 살아 있는 대표 실험(.hero-lab)을 둡니다. 실제 계산 결과를 그림과 글로 함께 보여 주고 슬라이더 하나로 조작할 수 있어야 합니다.
  2. 한눈에 보는 흐름(.section + .flow): 책 전체를 4~5단계 상자로 요약하고 "각 단계가 아래 장과 연결됩니다"라고 알려 줍니다.
  3. 전체 장(id="chapters", .chapter-grid): 장마다 카드 하나. 카드에는 "CHAPTER 01 / 부 이름", 장별 썸네일 SVG, 장 제목, 시작 질문(desc), "실험 N개" 태그, "약 N분"을 넣습니다.
  4. 나에게 맞는 학습 경로(.path-grid): 독자 유형별 경로 3개. 각 경로는 제목, 한 문장 설명, 장 번호 링크로 이루어집니다.
  5. 참고 자료와 실험의 경계(id="sources"): 출처 목록과, 실험이 무엇을 계산하고 무엇을 생략하는지 밝히는 안내 상자(.note).

06

실험 블록 형식

실험은 책마다 내용이 달라도 상자 모양과 읽는 순서는 같아야 합니다. 그래야 독자가 "어디를 보고 무엇을 눌러야 하는지"를 한 번만 배우면 됩니다.

  • 머리: <article class="lab" id="lab-실험ID"> 안에 "EXPERIMENT 01"과 제목. 번호는 장 안에서 1부터 셉니다.
  • 설명: 무엇을 조절하고 무엇을 관찰하는지 한 문장.
  • 안내 상자(.lab-guide): "무엇을 확인하나요?" 한 문장, 비교 예제 버튼 2~3개와 "실험 초기화", "결과 읽기" 해석 문장. 예제 버튼은 입력값을 바꾼 뒤 실제 input 이벤트를 보내 사람이 조작한 것과 같은 경로로 계산합니다. 선택된 예제에는 aria-pressed="true"를 붙이고, 독자가 직접 조작하면 지웁니다.
  • 조작과 관찰(.lab-columns): 왼쪽은 <label>과 <output>이 붙은 슬라이더나 선택 상자, 오른쪽은 SVG 차트. 아래 결과 상자(.readout)가 계산 과정과 숫자를 글로 보여 주므로 차트를 보지 못해도 결과를 읽을 수 있습니다.
  • 직접 해 보기(.challenge): 결과를 보기 전에 예측하게 만드는 질문 하나(예: "학습률을 1.1로 설정하고 10번 학습하면 수렴할까요?").
  • 계산은 math.js 같은 모델 파일에, 그리기는 labs-*.js에 둡니다. 실험이 실제 계산인지, 미리 정한 시나리오인지, 시각적 비유인지 설명이나 결과 읽기 문장에 밝힙니다.

다른 책으로 이어 읽기: 다른 책의 장으로 가는 링크는 "더 읽어 보기" 블록 안에 둡니다. AI Book은 선택 필드 cross: [[링크 이름, '../주제/#장ID', 이동 이유], …]를 쓰고, 출처 목록 아래 "다른 책으로 이어 읽기" 소제목으로 보여 줍니다. 새 책도 같은 위치와 세 요소(도착 장, 이동 이유, 돌아올 곳)를 지키며, 주소는 validate.py가 도착 책의 book-routes로 검사합니다. 서가의 공통 개념과 읽기 경로는 서가 큐레이션을 따릅니다.

책 단위 구조

장과 부

AI Book은 12개 장을 네 부로 묶습니다: 기초(3) · 언어 모델(4) · 확장(2) · 시스템(3). 새 책은 8~12개 장, 3~4개 부를 기본으로 하고 부 이름은 짧은 명사로 씁니다.

장의 크기

장마다 실험 1~2개, 확인 문제 1개, 읽는 시간 10~18분. 실험 개수는 성과 지표가 아니므로 개념을 보여 주는 데 필요한 만큼만 둡니다.

경로와 ID

카탈로그

data/catalog.json에 책을 등록하고 python3 scripts/build_catalog.py로 서가를 다시 만듭니다. 책등 제목은 공백 제외 6글자 이내(규칙), 펼침 삽화는 assets/shelf-illustration.svg. 닫힌 표지 삽화는 assets/cover-art.svg와 cover_meta(표지 규칙). 색·분류·위치는 서가 진열 규칙을 따릅니다(이웃과 다른 색, 분류 4글자 이내, 같은 분류끼리 붙여 세우기).

09

시각 자료·테마·접근성

  • 서가 펼침 삽화는 움직여야 합니다: 서가에서 책을 꺼내 펼치면 오른쪽 면에 assets/shelf-illustration.svg가 인라인으로 들어갑니다. 이 그림은 책의 핵심 과정을 CSS @keyframes+animation(또는 SMIL)으로 보여 주고, @media(prefers-reduced-motion:reduce)와 html[data-motion=reduce] 두 곳에서 멈춥니다. 서가 페이지에 그대로 끼워 넣으므로 클래스와 id에는 책 접두어(예: lg-ill-)를 붙입니다. python3 scripts/validate.py는 출간된 책의 삽화가 없거나, 움직이지 않거나, 동작 줄이기 규칙이 없으면 오류를 냅니다. 검사기는 움직임의 존재만 확인하므로, 등록하는 사람은 서가에서 직접 책을 펼쳐 무엇이 움직이는지 눈으로 확인하고 확인 결과를 책 문서에 남깁니다. (2026-10-08 LLM 시스템 책이 움직임 없는 삽화로 출간된 일을 계기로 추가)
  • 장마다 그림 세 가지: 장 카드의 썸네일 SVG, "먼저 개념 잡기"의 핵심 관계 그림(그림 N-1), 실험 차트. 표지에는 실제 계산으로 움직이는 대표 실험을 하나 둡니다. 그림마다 무엇을 보여 주는지 한 문장(캡션, aria-label, 또는 결과 문장)을 붙입니다.
  • 두 가지 테마: 기본은 어두운 화면(<html data-theme="dark">), 머리말 버튼으로 밝은 화면 전환. 색은 --bg, --panel, --panel2, --text, --muted, --line, --accent, --orange, --blue, --chart 변수로만 쓰고 [data-theme=light]에서 다시 정의합니다. 강조색(--accent)은 책마다 바꿀 수 있습니다.
  • 글꼴과 줄바꿈: 글꼴은 글꼴 체계를 따릅니다. word-break:keep-all로 한국어 단어가 중간에서 끊기지 않게 합니다.
  • 접근성: 본문 바로가기, 모든 입력에 라벨, 결과는 글로도 표시, :focus-visible 테두리, Esc로 목차 닫기, 정답·결과 알림은 aria-live, 색 외의 표시(굵은 숫자·문장)로 상태 전달.
  • 동작 줄이기: prefers-reduced-motion: reduce에서 스크롤 애니메이션과 전환을 끕니다. 애니메이션이 핵심인 그림은 같은 내용을 정지 그림과 글로도 볼 수 있게 합니다.
09-1

닫힌 표지: 종이 커버와 가로 삽화

서가에서 책을 꺼내면 책이 펼쳐지기 전 약 1초 동안 닫힌 표지가 보입니다. 2026-10-08 사용자는 이 표지에 책 내용과 밀접한 삽화를 넣고, 제목을 라벨 상자에 넣던 방식 대신 세련된 표지로 바꾸라고 요청했습니다. 원형과 네모 메달 목업을 거쳐, 제목과 같은 폭의 가로 삽화를 쓴 종이 커버로 확정했습니다. 이 형식은 모든 책에 같게 적용하고, 그림만 책마다 새로 그립니다.

순서요소내용과 출처
1머리줄왼쪽에 분류(spine_category), 오른쪽에 서가 순번(No. 01). 순번은 생성기가 서가 순서로 넣습니다.
2가로 삽화 판books/주제/assets/cover-art.svg. 제목과 같은 폭, 책 색을 옅게 깐 판 위의 선화와 짧은 주석.
3제목title의 " · " 앞부분을 큰 명조체로, 왼쪽 정렬. 라벨 상자를 쓰지 않습니다.
4짧은 선과 부제책 색의 34px 선 아래에 title의 " · " 뒷부분.
5꼬리줄왼쪽에 cover_meta("12장 · 18개 실험"), 오른쪽에 서재 이름(생성기가 넣음).

삽화 그리는 법

  • 무엇을 그리나: 책 전체를 묶는 공통 사례나 핵심 과정을 한 장면으로 그립니다. 예: AI Book은 손글씨 7이 층을 건너 확률 0.86이 되는 신경망, 컴퓨터 책은 0011과 0100이 덧셈기를 지나 7을 켜는 회로, 확률 책은 센서 20대의 하루 경보 분포와 경보 문턱. 서가 펼침 삽화(움직이는 그림)와 같은 그림을 복사하지 않습니다.
  • 형식: 루트는 <svg class="cover-art" viewBox="0 0 320 150" role="img" aria-label="한 문장 설명">. 가장자리 14px 안쪽에 그립니다. 주석은 짧은 단어나 숫자만 씁니다.
  • 정지 그림: 표지는 곧 넘어가므로 애니메이션을 넣지 않습니다. <style>, style=, 스크립트, 링크, 이미지도 넣지 않습니다.
  • 공통 클래스만: 선과 색은 assets/reader.css의 cv-* 클래스로만 씁니다. cv-node(종이색 상자·원), cv-stroke·cv-hair·cv-bus(먹선), cv-line·cv-fill·cv-grid·cv-dot·cv-on(책 색 강조), cv-tint·cv-bar(옅은 책 색), cv-text·cv-muted·cv-matrix·cv-big(글자), cv-head(화살촉), cv-dash·cv-bold·cv-thin(선 변형). 책 색은 표지의 --glass·--edge로 자동으로 입혀집니다. 새 클래스가 필요하면 이 목록과 reader.css를 함께 고칩니다.
  • id: clipPath 같은 id는 책 접두어를 붙입니다(예: la-cover-clip).

등록과 검사

data/catalog.json에 cover_art와 cover_meta를 채우고 python3 scripts/build_catalog.py를 실행합니다. 생성기(scripts/cover_renderer.py)는 표지를 미리보기 안의 <template class="book-jacket">로 넣고, assets/motion.js가 펼칠 때와 덮을 때 표지 위에 복제합니다. python3 scripts/validate.py는 공개된 책마다 경로, 판 크기, 정지 여부, 클래스, aria-label, cover_meta 형식, 제목의 " · "를 검사합니다. 검사기는 그림이 내용과 맞는지는 판단하지 못하므로, 등록하는 사람이 1280·390·320px에서 책을 펼쳐 표지를 직접 보고 제목 잘림과 그림 넘침이 없는지 확인합니다.

글꼴 체계

서가와 모든 책은 assets/type.css 하나에서 글꼴을 가져옵니다. 목표는 믿을 수 있고 차분하지만 세련된 인상입니다. 그래서 글을 읽는 자리는 군더더기 없는 고딕으로, 장과 표지의 제목은 서가 책등과 같은 명조로, 숫자와 코드는 자릿수가 고정된 글꼴로 나눕니다. 세 글꼴 모두 SIL OFL 1.1로 자유롭게 쓸 수 있고, 원본 파일을 고치지 않고 저장소에서 직접 제공합니다(외부 글꼴 서버에 의존하지 않음).

12-1

책을 서가의 지식 지도에 잇기

2026-10-08 사용자는 책이 추가될 때마다 지식 지도와 큐레이션이 함께 갱신되도록 규칙을 강화하라고 요청했습니다. 그래서 이 단계는 권장이 아니라 검사입니다. python3 scripts/validate.py가 scripts/curation_rules.py로 공개된 모든 책을 확인하고, 하나라도 빠지면 오류 메시지에 이 절의 주소를 붙여 실패합니다.

검사채우는 곳통과 기준

개념은 새로 만들기보다 먼저 기존 개념 중 새 책이 다루는 것을 찾아 장을 더합니다. 개념이 늘수록 섬 사이 다리와 책 중심 보기의 개념 이름표도 늘어나므로, 뜻이 겹치는 개념을 새로 만들지 않습니다. 새 개념이 필요하면 한국어 이름(공백 제외 10글자 이내, 지도의 이름표 하나에 들어가야 합니다), 영문 동의어(aliases, 서가 검색에 쓰임), 한 줄 요약을 쓰고 다른 책의 장도 함께 넣습니다. 노선의 단계 문장은 그 장의 실험에서 실제로 할 수 있는 일이어야 하므로 책 본문을 읽고 씁니다. 지식 지도는 scripts/atlas_renderer.py가 책을 서가 순서의 세로 칸으로, 개념을 가로줄로 그리고 개념 줄을 가장 많이 다루는 분야 묶음에 넣으므로 좌표나 순서를 손으로 넣지 않습니다(지식 지도 구조). 기획 중(planned)이거나 집필 중(writing)인 책은 공개 전까지 검사에서 빠집니다.

새 책 만들기 체크리스트

  1. 공개하는 같은 커밋에서 지식 지도 잇기 다섯 항목(장 색인·공통 개념 두 개·읽기 노선·나가는 링크·들어오는 링크)을 채웁니다. 빠지면 validate.py가 실패합니다.

  4. 전역 객체 접두어, 책 이름, 문서 제목, 강조색, book-routes, info와 guides 표를 새 책에 맞게 바꿉니다. 다른 책 파일을 <script src>로 불러오지 않습니다.
  5. 완결된 한 장 → 같은 사례로 세 장 → 책 전체 순서로 씁니다. 장마다 일곱 블록과 데이터 필드를 모두 채웁니다.

  9. data/catalog.json에 책을 등록하고 python3 scripts/build_catalog.py를 실행합니다.
