서가와 책을 한곳에서 관리합니다

책 추가, 시리즈 구성, 서가와 책 사이의 이동을 하나의 저장소에서 관리합니다.

확정한 결정

교과서는 my-bookshelf의 books/주제/ 폴더에서 개발합니다. AI 교과서를 books/ai/로 복사하고 기존 저장소와 사이트는 보존합니다. 앞으로 AI 교과서의 수정 원본은 이 저장소입니다. 이전 저장소와 자동 동기화하지 않습니다.

책별 본문·실험·전용 자산·테스트·개발 문서는 각 책 폴더에 둡니다. 서가는 카탈로그와 공통 규칙을 맡습니다. 여러 책에서 실제로 반복되는 부분이 확인되기 전에는 공통 프레임워크를 만들지 않습니다.

구현 계획

  1. 원본 파일 목록과 Git blob SHA를 기록하고 본문·실험·자산·테스트·문서를 복사합니다.
  2. 서가 카탈로그를 books/ai/ 상대 경로로 바꾸고 책의 머리말·꼬리말에 서가 복귀 링크를 추가합니다.
  3. 내부 도서 주소와 JavaScript 장 경로를 검증기에 반영합니다. 본문의 기존 장 ID는 보존합니다.
  4. 공통 규칙·책 추가 안내·README를 통합 저장소 기준으로 수정합니다. 원본 CI의 수치 테스트를 루트 CI에 연결합니다.
  5. 기존 수치 테스트, 상대 경로·장 경로 검증, 모든 장 렌더링과 대표 실험, 서가↔책 마우스 이동을 확인합니다.

서가로 돌아가기 버튼 · 2026-10-08

독자는 어느 책, 어느 장을 읽든 한 번에 서가로 돌아갈 수 있어야 합니다. 그래서 모든 책은 첫 화면 파일 books/주제/index.html의 머리말 안에 아래 버튼을 둡니다. 머리말이 화면 위에 고정되어 있으면 장을 읽는 중에도 버튼이 보입니다.

<header> … <a class="shelf-return" data-shelf-return href="../../index.html#books" aria-label="Jdeok.Lee의 서재 서가로 돌아가기"><span aria-hidden="true">←</span>서가로</a> … </header>
  • data-shelf-return 속성은 검사기가 버튼을 찾는 표시입니다. 꼬리말의 복귀 링크에도 붙일 수 있습니다.
  • 주소는 상대 경로 ../../index.html#books로 씁니다. 프로젝트 Pages의 /my-bookshelf/ 경로에서도 그대로 동작합니다.
  • 모양은 각 책의 스타일에 맞추되 테두리가 있는 버튼으로 보이게 하고, 누를 수 있는 높이를 36px 이상으로 둡니다. 320px 화면에서 숨기지 않습니다.
  • 책 사이 코드 의존을 만들지 않기 위해 공통 스타일 파일을 두지 않고, 각 책의 style.css에 .shelf-return 규칙을 직접 씁니다.

python3 scripts/validate.py는 모든 books/*/index.html에서 머리말 안의 data-shelf-return 링크가 서가의 index.html#books를 가리키는지 확인하고, 없으면 오류로 처리합니다. AI Book과 컴퓨터 책에 적용했고 1280·390·320px에서 버튼 클릭 후 서가로 이동하는 것을 확인했습니다.

검증 기록

로컬 및 GitHub Actions에서 Python 19개, 서가 JavaScript 4개, AI 책 13개(기존 수치 11개·장 경로 2개), 총 36개 테스트가 통과했습니다. HTML 23개 내부 파일·앵커·장 경로 검사 오류는 0개입니다. 원본의 모든 js/ 파일은 Git blob SHA가 동일하여 본문·실험 계산 코드는 그대로 복사되었음을 확인했습니다.

GitHub Pages 배포 성공 후 마우스로 서가→책 읽기→서가 복귀를 확인했습니다. 12개 장 제목과 18개 실험의 초기 결과가 표시되었으며, 홈 입력 1에서 99.7% 출력, 에이전트 3단계 후 완료, 모두 경보에서 놓친 이상 0건·오경보 6건을 확인했습니다. 이전 장 링크와 장 hash 주소의 새로고침도 확인했습니다.

이 검증은 이전 과정의 회귀 확인입니다. 모든 실험의 전체 입력 조합·학습 효과·모바일 실기기·Safari·Firefox는 재검증하지 않았습니다. 기존 저장소와 사이트는 수정하거나 삭제하지 않았고 자동 리디렉션도 적용하지 않았습니다.
