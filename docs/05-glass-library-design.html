나만의 서재디자인 결정 · 2026.10.07

빛을 담는 유리 서가

승인한 목업을 실제로 고르고 펼칠 수 있는 개인 학습 서재로 옮긴다.

확정한 방향

개인 학습자를 위한 밝고 부드러운 미래 서재. 맑은 색유리, 촘촘한 책등, 아이보리 라벨, 명조체 제목과 그 아래 분류를 사용한다. 어두운 네온, 큰 태블릿 카드, 무채색 중심 화면은 사용하지 않는다.

디자인 변화 6 / 움직임 6 / 정보 밀도 7. 선택한 책만 움직이며, 시스템의 동작 줄이기 설정과 수동 전환을 제공한다. 특정 회사의 공식 디자인 시스템이 아닌 독자적인 재질 표현이다.

목업에서 추출한 규칙

요소구현 기준
공간밝은 크림 벽, 사선 햇빛, 주변부 식물. 중앙은 글자를 읽기 쉽게 유지한다.
책과 선반넓은 면은 맑게, 가장자리와 두께에 청록·푸른색·살구·세이지 색을 남긴다. 선반은 얇고 둥근 유리판.
책등폭 약 64~76px, 높이 210~230px. 자료가 늘면 같은 분류 안에서 선반을 추가한다.
라벨아이보리 바탕으로 대비 확보. 명조체 제목, 작은 고딕체 분류. 유리의 상하좌우를 가리지 않는다.
펼친 책유리 테두리 안에 따뜻한 읽기 면. 왼쪽 제목·소개, 오른쪽 실제 목차와 읽기 링크.

콘텐츠와 기존 구조

현재 등록된 7개 자료와 기존 운영 문서를 실제 유리 책으로 배치한다. 학습 책은 미등록 상태를 알린다. 목업을 채운 AI·반도체·수학 제목을 발행된 책처럼 추가하지 않는다. 기존 URL과 materials, books, intent, evidence 앵커를 유지한다.

카탈로그를 원본으로 삼는 정적 HTML 생성, 검색·분류, JavaScript 없이도 열리는 문서 링크를 보존한다. 수정키 클릭은 원래 링크 동작을 유지한다. 첫 책의 주제·독자는 이 작업에서 정하지 않는다.

책을 고르고 펼치는 과정

선택

해당 책이 앞으로 나오고 회전한다. 다른 책과 자리는 유지한다.

펼침

두 유리 면이 펼쳐지며 제목·소개·실제 목차를 읽는다.

복귀

닫기나 Escape로 원래 자리와 포커스로 돌아간다.

네이티브 dialog로 배경 접근을 제한한다. 연속 클릭, 애니메이션 도중 닫기, 리사이즈, 키보드, 작은 화면, 동작 줄이기를 확인한다. 모바일은 선반 내부를 가로로 넘기며, 펼친 책은 한 열로 읽는다.

구현과 검증 순서

  1. 카탈로그에 짧은 책등 제목·분류·색을 추가하고 정적 서가 생성기를 분리한다.
  2. home.css, shelf.css, reader.css에 공간·유리·읽기 면의 스타일을 나눈다.
  3. home.js, shelf-model.mjs, reader.js, motion.js로 검색·모달·동작을 분리한다.
  4. 발행 상태, 안전한 URL, 중복 ID, 검색 조건, 반복 생성의 단위 테스트를 수행한다.
  5. 실제 브라우저에서 데스크톱·모바일·검색·펼침·닫기·문서 이동·동작 줄이기를 검사한다.
  6. GitHub Pages 공개 후 운영 방법, 구현·검증 기록, 작업 상태를 갱신한다.

함수는 100줄 이하. 계정·서버·프레임워크는 추가하지 않는다. 미실행 검증을 완료로 기록하지 않는다.
