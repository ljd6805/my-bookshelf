02

이 저장소의 검사

python3 scripts/validate.py로 HTML 내부 파일·앵커·중복 ID, JSON 구문, 카탈로그 연결, Python 함수 길이, 고정 조사 데이터의 항목 수를 검사합니다. 검사기의 별도 단위 테스트는 링크 누락·앵커 누락·중복 ID·카탈로그 참조 오류를 의도적으로 넣어 탐지되는지 확인합니다.

실행 결과는 검증 기록에 있습니다. 이 검사는 외부 링크의 최신 상태나 JavaScript 실행을 보장하지 않습니다.

완성 HTML을 클라우드 브라우저로 열려 했으나 브라우저 보안 정책이 로컬 file: 주소를 허용하지 않았습니다. 이를 우회하지 않았으며, 최종 문서의 렌더링·모바일 화면·검색 필터 동작은 브라우저에서 검증하지 못했습니다. 내부 구조와 CSS 반응형 규칙은 정적으로 확인했습니다.
