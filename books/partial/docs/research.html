3. 확인하지 못한 것

  • 출처 14개의 주소는 집필 세션에서 열어 보지 못했습니다. OpenStax 절 번호(Volume 3의 4.3~4.6, Volume 1의 3.1·3.6)와 Goodfellow 등의 절 번호(4.3, 6.5)는 집필자의 지식입니다. G6에서 열어 본 결과는 팩트·출처 검수 기록에 적습니다.
  • Glorot & Bengio(2010), Bengio 등(1994), Rumelhart 등(1986) 원문은 읽지 못했습니다. 본문은 이 논문들의 구체적인 수치를 인용하지 않습니다.
  • PyTorch 튜토리얼의 주소는 docs.pytorch.org로 적었습니다. 예전 주소(pytorch.org/tutorials)에서 옮겨졌는지는 확인하지 못했습니다.
  • ∂를 읽는 법(“라운드”, “파셜”)은 관용 표현이라 출처를 달지 않았습니다.

  • (2, 12): L = 70 + 144 + 168 − 445.5 − 618 + 750.5 = 69. ∂L/∂w = 70 + 84 − 222.75 = −68.75, ∂L/∂b = 24 + 14 − 51.5 = −13.5. 크기 √(4726.56 + 182.25) = 70.06, 방향 180° + atan(13.5/68.75) = 191.1°.

5. 태오가 모은 오해

  • “미분값만큼 실제로 변한다” → 1장 혼동 상자(−68.75와 −51.25).
  • “∂L/∂w = 0이면 손실이 가장 작다” → 2장 혼동 상자.
  • “상수로 본다 = 0으로 둔다” → 3장 혼동 상자.
  • “접평면 어림은 어디서나 쓸 수 있다” → 4장 혼동 상자.
  • “기울기 벡터는 최솟값 쪽을 가리킨다” → 5장 혼동 상자.
  • “w를 먼저 옮기고 b를 구한다” → 6장 혼동 상자.
  • “바깥 변화율을 입력 자리에서 구한다” → 7장 혼동 상자.
  • “국소 미분이 곧 손실의 기울기다” → 8장 혼동 상자.
  • “경로끼리도 곱한다” → 9장 혼동 상자와 마지막 과제.
  • “기울기 소실은 계산 오류다” → 10장 혼동 상자.
  • “학습이 느리면 학습률부터 본다” → 마지막 과제 혼동 상자.
