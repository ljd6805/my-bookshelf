기획과 범위

합의일: 2026-10-08. 첫 권은 시스템 이해, 구현·프로파일링·분산 학습은 후속 심화편 후보로 분리한다.

독자가 마지막에 할 일

오픈웨이트 모델의 전체·활성 파라미터, 정밀도, 층·KV head·head 차원을 읽고 가중치와 KV 용량을 구분한다. 한 장비의 실행 예산을 작성하고 용량·메모리 대역폭·연산·전송 중 남은 제약과 추가 측정을 설명한다.

공통 사례는 “오늘 회의 내용을 요약해 줘”라는 요청이다. 가상의 Dense 8B, 32층·KV head 8개·head_dim 128·16bit KV를 기본으로 사용하고, 실제 Qwen3-8B와 Qwen3-30B-A3B는 공식 사양 사례로 분리한다.

4부 12장

  1. 모델의 실체: 파일 → 파라미터 → 가중치 용량과 양자화
  2. 응답의 과정: CPU/GPU 이동 → GPU 메모리 계층 → Transformer·타일 → prefill/decode
  3. 하드웨어 제약: KV → roofline → MoE·offload·다중 GPU
  4. 실제 선택: 공식 모델 사양 → 메모리 예산 최종 과제

첫 권의 범위는 일반적인 decoder-only 추론이다. 분리형 NVIDIA GPU를 기본으로 설명하고 Apple 통합 메모리와 다중 GPU, 학습의 추가 비용을 비교한다. CUDA 커널 구현과 장비 구매 순위는 범위에 넣지 않는다.
