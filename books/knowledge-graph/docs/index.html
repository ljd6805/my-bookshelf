01 책의 약속 (templates/book-brief.html의 다섯 가지)

책 ID·폴더knowledge-graph-ontology · books/knowledge-graph/
대상 독자데이터베이스 표나 JSON은 다뤄 봤지만 “트리플”, “온톨로지”, “GraphRAG”가 무엇을 해 주는지 감이 없는 개발자와 학생
끝의 행동세 단계를 이어야 하는 질문에 대해, 필요한 트리플과 식별자를 적고, 문장 검색과 그래프 걷기 중 무엇이 근거를 놓치는지 예측하고, 사실이 빠졌을 때 무엇을 더 모아야 하는지 설명한다
공통 사례퀴리 가족의 사실 21개(js/graph.js): 마리·피에르·이렌·프레데리크·베크렐, 폴로늄·라듐, 1903·1911·1935 노벨상, 바르샤바·파리. 5장부터는 “폴란드·프랑스는 유럽에 속한다” 두 개를 더함
범위RDF 트리플, 식별자와 개체 해소, RDFS·OWL의 기초(클래스 계층, domain·range), 전방 연쇄, SPARQL 기본 그래프 패턴, 추출 평가, TransE, GraphRAG의 그래프 걷기. 다루지 않음: OWL 서로소·개수 제약, SPARQL FILTER·OPTIONAL·경로 표현식, 실제 언어 모델 실행, 그래프 데이터베이스 저장 구조
증거W3C RDF·RDFS·OWL·SPARQL·SHACL 표준, Hogan 외(2021) 개론 논문, Edge 외(2024) GraphRAG 논문, 노벨상 공식 기록(1903 물리학상, 1911·1935 화학상)
이야기 방식제품을 완성한다: 문장 더미에서 시작해 질문에 근거로 답하는 지식 그래프를 장마다 한 부품씩 만든다

02 장 연결표

각 장의 첫 문단 첫 문장은 앞 장의 결과로, 둘째 문단 마지막 문장은 다음 장이 풀 질문으로 썼습니다. 다음 장 링크에는 이동 이유(다음 장의 시작 질문)를 붙였습니다.

장현재 문제이전 장 결과새 도구해결한 부분남은 질문
01 triples문장으로 흩어진 사실(책의 출발점) 퀴리 가족 문장 21개트리플, 점과 간선문장이 같은 점을 공유하며 하나의 그래프로 이어짐연결을 따라가면 무엇을 알 수 있나
02 walk연결된 그래프에서 답 찾기점 14개·사실 21개 그래프너비 우선 탐색, 걸음 수폴로늄에서 3걸음에 1935 화학상다른 자료의 같은 사람은 같은 점인가
03 identity같은 대상의 여러 이름모든 문장이 같은 ID를 썼다는 전제자카드 유사도, 단일 연결 묶기, 식별자글자 비교의 한계와 식별자의 필요점의 종류는 어떻게 알려 주나
04 ontology형식은 맞지만 뜻이 틀린 트리플식별자로 고정된 점클래스 계층, domain·range, 검사와 RDFS규칙이 잡아내는 오류와 RDFS의 타입 추론규칙이 사실을 만든다는 뜻은
05 reasoning적혀 있지 않은 사실RDFS가 결론을 낸다는 관찰전방 연쇄, 라운드, 고정점사실 23개 → 35개, 2라운드 후 고정점늘어난 그래프에 어떻게 묻나
06 query여러 단계 질문을 정확히 묻기추론으로 늘어난 그래프트리플 패턴, 변수, 조인폴로늄을 발견한 사람의 배우자그래프는 글에서 어떻게 만드나
07 extraction글에서 그래프 만들기그래프가 있다는 6장의 가정확신도 문턱, 정밀도·재현율·F1어떤 문턱도 완벽하지 않다는 저울질놓친 사실을 짐작할 수 있나
08 embedding그래프의 빈칸추출에서 놓친 사실TransE, 관계 화살표, 평균 차이 벡터처음 보는 마드리드의 나라를 1위로 맞힘짐작이 아닌 근거로 답하려면
09 graphrag세 단계 질문에 근거로 답하기(마지막 과제)임베딩은 근거를 주지 못함문장 검색 k, 그래프 걸음, 관계 제한, 사슬 확인문장 검색 k=12 vs 그래프 3걸음(관계 제한 시 사실 11개)사실이 빠지거나 새 질문이 오면 무엇을 바꿀까

03 실험과 확인 수준

확인 수준: L1 접근(화면이 열림), L2 반응(입력에 출력이 바뀜), L3 모형(계산 값이 기대값과 일치), L4 학습(독자가 새 상황에서 설명). 모든 실험은 Chromium 자동 검사로 L3까지 확인했고, L4는 실제 독자로 확인하지 않았습니다.

실험종류확인한 값수준경계·조작
triples실제 계산덩어리 수 1·2·3·4·4·3·3·2·1(문장 1~9), 0문장 경계L3예제 4개·초기화·0과 21 끝값
walk실제 계산닿는 점 0·3·9·13·13(0~4걸음), 최단 경로 3L3출발점·도착점 전체 선택 조합 오류 없음
resolve실제 계산J 값 0.17·0.45·0.50·0.67, 어떤 문턱도 섞임0+갈림0 불가L3식별자 모드에서 문턱 입력 비활성
schema실제 계산(규칙 검사)검사 위반, RDFS 결론 “파리는 상”L3모든 주어·관계·목적어 선택 조합 오류 없음
infer실제 계산라운드별 9·3, 고정점; 위치 규칙 5·3L3규칙 없음 경계
query실제 계산1줄 2개, 2줄 1개, 추론 포함 2개L3빈 결과 문장(열린 세계 설명)
extract미리 정한 시나리오(점수)0.30: P 75.0%, 0.50: P=R 88.9%, 0.85: R 33.3%, 1.00: P 정의 안 됨L3문턱 0·1 끝값
transe실제 계산(손으로 정한 2차원 좌표)r̂=(1.53, 1.21), 학습 쌍 4/4, 마드리드 1위L3r=0, 틀린 방향 예제

표지 대표 실험(js/home-graph.js)은 2장의 탐색을 그대로 써서 2걸음은 사슬이 끊기고 3걸음에서 “1935 화학상”으로 완성되는 것을 확인했습니다. 장마다 움직이는 개념 그림(js/figures.js)은 간선이 차례로 그려지며, 동작 줄이기 설정에서 애니메이션이 멈추는 것(animation-name: none)을 확인했습니다.
