「AI 엔지니어링 처음부터」 시리즈 11권의 기획, 원본 레슨 대응, 구현, 검증 기록입니다. 원본은 공개 저장소 rohitg00/ai-engineering-from-scratch(MIT, 2026 Rohit Ghumare)의 phases/10-llms-from-scratch 가운데 24개 레슨(01~22, 25, 34)입니다. 개념·순서·실험 아이디어만 참고하고 문장과 코드는 새로 썼습니다. 작성·확인일 2026-10-08.

1. 기획

항목결정
독자트랜스포머와 경사하강은 알지만, LLM 하나를 처음부터 끝까지 만들 때 어떤 단계가 어떤 순서로 있고 단계마다 무엇이 비용과 품질을 정하는지는 설명하지 못하는 개발자와 학생.
끝의 행동출시 직전 한 단계가 실패했을 때, 의존 그래프에서 다시 해야 할 단계와 재사용할 체크포인트를 고르고, 그 판단의 근거(메모리·계산량·평가 결과)를 숫자로 말할 수 있습니다.
공통 사례"서재봇": 서재의 책과 실험을 추천하는 작은 LLM. 1장의 병합표 학습과 3장의 바이그램 학습은 서재봇 소개문으로 실제 계산하고, 4~11장은 8B 크기의 서재봇을 가정해 메모리·정렬·평가·서빙 결정을 계산합니다.
이야기 방식하나의 제품을 완성한다. 토큰과 데이터 → 사전학습과 규모 → 정렬 → 평가와 서빙의 네 묶음으로 단계를 하나씩 붙이고, 12장에서 열한 단계를 출시 매니페스트로 묶어 되돌리기 범위를 계산합니다.
겹침 처리AI Book의 토큰·생성·어텐션·정렬, LLM GPU 책의 가중치 메모리·KV 캐시·모델 카드, LLM 성능 책의 병렬화·배칭은 짧게 요약하고 cross 링크로 보냅니다. 분량은 원본에만 있는 바이트 BPE 학습, MinHash 중복 제거, Chinchilla 배분, ZeRO·재계산·GPipe, 손실 마스크, DPO·GRPO, ELO, 추측 디코딩, 오픈 모델 config 읽기, 파이프라인 매니페스트에 씁니다.
증거BPE, MinHash·LSH, 패킹, 바이그램 학습, 양자화, GRPO 집단, ELO는 브라우저 안의 실제 계산입니다(작은 말뭉치·작은 행렬·고정 시드). Chinchilla, ZeRO 메모리, 활성값 재계산, GPipe 거품, DPO 손실, 추측 디코딩, 모델 파라미터·KV 캐시는 원본 레슨과 인용 논문의 공식을 계산한 값입니다. SFT 토큰 손실값과 12장의 단계별 시간은 비교용 가정값이며 화면에 밝혔습니다.
마지막 과제12장: 평가 게이트에서 SFT·DPO·양자화 중 하나가 실패했을 때 다시 할 단계와 시간을 의존 그래프로 계산하고, 사전학습처럼 비싼 단계는 체크포인트로 재사용하는 판단을 설명합니다.

확인하지 못한 것: 학습 효과(L4)는 실제 독자로 시험하지 않았습니다. 메모리·속도 수치는 실제 GPU에서 재지 않았고, 공개 모델 수치는 config 공식 계산이며 모델 제작사의 발표값과 작은 항목(편향, 정규화 등)에서 다를 수 있습니다. 화면 낭독기로 읽는 경험과 실제 모바일 기기는 확인하지 않았습니다. 사실·수치는 별도 검수자가 원본과 인용 논문에 대조했습니다.
