2. 식, 단위, 가정, 유효 범위

  • 정규화: 소문자로 바꾸고 문장부호(유니코드 글자·숫자·공백이 아닌 것)를 공백으로 바꾼 뒤 공백으로 나눕니다. 2장 MinHash의 shingles와 같은 함수 words를 씁니다.
  • 문항 겹침률 = (학습 조각 어디든 있는 문항의 n-gram 자리 수) ÷ (어절 수 − n + 1). 단위는 비율(화면은 %). 공식 칸은 집합 크기로 썼고 코드는 자리 수를 셉니다. 한 문항 안에 같은 n-gram이 되풀이될 때만 다르며, 이 실험의 문항(n ≥ 8)에는 되풀이가 없습니다.
  • 전체 겹침률 = 겹친 자리 합 ÷ 검사한 문항의 자리 합. 어절 수가 n보다 적은 문항은 검사 불가로 빼고 셉니다.
  • 게이트: 전체 겹침률 ≤ 0.001이면 통과(같으면 통과).
  • 판정: 자리 하나라도 겹치면 오염 의심. 정답은 그 문항을 담은 학습 조각이 지금 고른 묶음에 있는지입니다. 놓침 = 정답이 오염인데 겹침 0, 헛경보 = 정답이 깨끗한데 겹침 있음.
  • 유효 범위: n은 정수 8~13(슬라이더). 함수는 1 이상 정수만 받고 나머지는 오류를 냅니다. 문항 6개·조각 6개라 n-gram 하나만 겹쳐도 0.1%를 넘으므로, 게이트 판정은 실제 규모의 평가 세트를 대신하지 않습니다.

5. 오해 목록

  • "13-gram 게이트를 통과했으니 평가 세트는 깨끗하다." 복사본을 지운 묶음은 13-gram 0%로 통과하지만 바꿔 쓴 문항 2·3은 학습 데이터에 들어 있습니다.
  • "n을 작게 할수록 좋다." n = 8에서 놓침은 0이 되지만 흔한 끝맺음만 같은 문항 5가 헛경보로 걸립니다.
  • "짧은 문항은 겹침 0%이니 안전하다." 10어절 문항 6은 n ≥ 11에서 아예 검사되지 않습니다. 0%가 아니라 검사 불가입니다.
  • "겹침 검사로 모든 오염을 잡는다." 번역이나 뜻 바꿈은 같은 어절이 이어지지 않아 남습니다.
  • "영어 논문의 13-gram을 한국어에 그대로 쓰면 된다." 어절에는 조사가 붙어 같은 n이라도 영어 낱말보다 일치가 더 쉽게 깨집니다. 한국어에 맞는 n은 이 책에서 정하지 않았습니다.
