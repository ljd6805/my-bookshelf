쓰기 전에 정한 여섯 가지

독자. 컴퓨터를 매일 쓰지만 안에서 무슨 일이 일어나는지 설명해 본 적 없는 고등학생 이상 일반 독자입니다. 프로그래밍 경험은 필요하지 않습니다.

끝의 행동. 작은 CPU 메모리에 프로그램을 넣어 실행하고, 결과가 틀렸을 때 비트 폭·자리올림·깃발 중 무엇 때문인지 근거를 들어 설명하고 고칠 위치를 고릅니다.

공통 사례. 계산기에서 3 + 4를 누르면 화면에 7이 뜨기까지. 모든 장이 이 과정의 한 구간을 맡습니다.

범위. 비트·인코딩·논리 게이트·가산기·레지스터와 클럭·누산기 CPU·점프와 반복·캐시. 운영체제, 네트워크, 파이프라인, 트랜지스터 물리는 다루지 않습니다.

증거. 9장 마지막 과제(100 × 3 = 44)에서 원인·수정 위치·부족한 증거를 스스로 적을 수 있는지로 확인합니다.

이야기 방식. “제품을 완성한다”입니다. 장마다 만든 부품이 다음 장의 재료가 되어, 마지막에 프로그램을 실행하는 컴퓨터가 완성됩니다.

화면 구성 (2026-10-08 개편)

사용자 요청에 따라 AI Book과 같은 틀로 다시 짰습니다. 첫 화면은 소개·직접 만지는 실험·흐름 요약·전체 챕터 카드·학습 경로·참고 자료 순서이고, 장 화면은 왼쪽 목차와 함께 “먼저 개념 잡기(본문·삽화·흐름·식) → 먼저 예측하기 → 실험(무엇을 확인하나요·결과 읽기·직접 해 보기) → 혼동하지 마세요 → 확인 문제 → 남은 질문 → 더 읽어 보기(다른 책으로 이어 읽기 포함) → 이전·다음 장”으로 이어집니다. 2026-10-08 2차 다듬기에서 휴대폰에서 잘리던 그림과 실험을 고치고 색·글꼴·흐름 상자를 AI Book과 같게 맞췄습니다(기록). 장 내용은 js/content.js에 AI Book과 같은 필드로 적었습니다.

교육용 모형의 경계

  • CPU는 메모리 16칸·8비트 누산기 구조이며, 명령 1바이트를 위 4비트 명령·아래 4비트 주소로 나눕니다. 파이프라인·인터럽트·스택·부호 있는 넘침 깃발은 없습니다. 끝나지 않는 프로그램은 500개 명령에서 끊고 오류로 알립니다.
  • 레지스터는 쓰기 허용과 클럭만 모형화합니다. 전기적 지연과 불안정 상태는 생략했습니다.
  • 캐시는 직접 사상 한 단계이며, 적중 1사이클·실패 100사이클은 실측이 아닌 이 책의 가정값입니다. 무작위 패턴은 seed 42의 고정 순서입니다.
  • UTF-8 바이트는 브라우저의 TextEncoder로 실제 계산합니다.

검증 기록 (2026-10-08)

수치 정확성. npm test --prefix books/computer의 단위 테스트 11개가 통과했습니다. 0~255 비트 왕복, 2의 보수 경계(127, 128, 255), UTF-8(“A”, “가”), 다섯 게이트 진리표와 NAND로 만든 AND, 4비트 모든 쌍 256가지의 덧셈, 준비한 네 프로그램의 출력(7, 12, 5…0, 44), 넘침 깃발, 끝나지 않는 프로그램과 잘못된 명령의 오류, 캐시의 대표값(차례 읽기 75%, 반복 2번 실패, 충돌 0% 적중)을 확인합니다.

개편 후 확인. 단위·경로 테스트 14개 통과. Chromium에서 첫 화면 카드 9개와 첫 화면 스위치 실험, 장 이동, 확인 문제 정답 표시, 9개 실험의 입력·출력을 다시 확인했고 페이지 오류는 0건이었습니다. 1280·390·320px에서 가로 넘침이 없었습니다.

동작 확인(개편 전). tests/browser.cjs로 Chromium에서 9개 실험의 입력·출력·초기화와 범위 밖 입력 오류 표시를 확인했고, 페이지 오류는 0건이었습니다. 1280·390·320px 폭에서 가로 넘침이 없음을 확인했습니다.

2차 다듬기 후 확인. 단위·경로·그림 테스트 16개 통과. tests/browser.cjs로 9개 실험의 입력·출력을 다시 확인했고, tests/reader-browser.cjs로 표지와 9개 장을 320·375·390·412·768·1024·1440px, 두 테마(140개 조합)에서 확인해 가로 넘침, 그림 잘림, 머리말 겹침이 없고 그림 글씨가 12.5px 이상임을 확인했습니다.

확인하지 못한 것. Safari·Firefox·실제 모바일 기기·화면 낭독기, 동작 줄이기 설정에서의 실제 체감, 학습 효과는 확인하지 않았습니다.
