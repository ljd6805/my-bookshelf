내용을 편하게 읽고, 관계를 정확히 보는 책

2026-10-08 · 사용자 요청: 좋은 내용은 보존하고 깨진 레이아웃과 어설픈 그림 표현을 개선한다.

현재 상태와 원인

  • 기본 스타일에 다른 책의 실험 CSS와 반복된 모바일 규칙이 누적되어 글자 크기·여백·색의 기준이 불분명하다.
  • 밝은 베이지 그림판이 어두운 본문과 분리되어 보이며, 고정 좌표 SVG가 모바일에서 축소되어 설명을 읽기 어렵다.
  • CPU 메모리·레지스터를 좁은 영역에 중첩 분할한다. 긴 숫자와 한국어 라벨을 담을 최소 폭을 고려해야 한다.
  • 기억 장치 그림의 Q 상승 시점이 클럭 상승 시점과 일치하지 않는다. 설명과 일치하도록 바로잡고 회귀 검증한다.

디자인 결정

기술 교과서의 편집 디자인을 적용한다. 진회색 바탕·청록 강조색, 읽기 폭을 제한한 본문, 동일한 선 두께와 글자 위계를 갖춘 도표를 사용한다. DESIGN_VARIANCE 4 / MOTION_INTENSITY 2 / VISUAL_DENSITY 4. SVG는 장식이 아닌 정확한 관계도에 사용하고 자동 반복 애니메이션을 줄인다.

기존 공통 틀의 머리말 메뉴 순서, 표지·읽기 모드, 왼쪽 목차, 일곱 장 블록, 장 ID와 계산 모델을 유지한다. 공통 서가와 다른 책의 디자인은 이 작업 범위가 아니다.

구현 순서와 변경 파일

  1. assets/style.css를 공통 읽기·실험·반응형 규칙으로 재구성하고 도표 스타일을 분리한다.
  2. js/figures.js를 일관된 관계도로 교체한다. 복잡한 회로는 축소 대신 도표 안에서 이동하고 확대해 읽는다.
  3. js/app.js의 그림 프레임, 장 정보, 목차 및 포커스 처리를 정리한다. 실험 렌더링의 좁은 셀과 가산기 순서를 보완한다.
  4. 자산 버전을 갱신하고 개발 문서 허브·검증 기록·작업 상태를 연결한다.

완료 확인
