AI 개발 작업대 · 제작 문서

「AI 엔지니어링 처음부터」 시리즈 01권 《AI 개발 작업대 · 환경 점검에서 디버깅까지》의 기획, 원본 레슨 대응, 구현, 검증을 한곳에 모았습니다. 작성일 2026-10-08. 원본은 rohitg00/ai-engineering-from-scratch(MIT)의 Phase 0 · Setup & Tooling이며, 원문과 코드를 옮기지 않고 개념과 순서만 참고해 새로 썼습니다.

1. 기획

  • 독자: Python으로 짧은 스크립트는 써 봤지만, 가상 환경·Git·GPU·원격 서버·도커를 엮어 AI 프로젝트를 재현해 본 적은 없는 사람. 명령은 따라 칠 수 있어도 왜 깨지는지 설명하기 어려워합니다.
  • 끝의 행동: 팀원의 고장 보고 한 줄을 받고, 어느 층(환경·CUDA·데이터·학습 코드)을 먼저 확인할지 순서를 세우고, 그 판단에 필요한 증거를 되물을 수 있습니다.
  • 공통 사례: 영화 리뷰 감성 분류 프로젝트 review-lab. 내 노트북에서 시작해 빌린 GPU 상자를 거쳐 팀원의 상자에서 같은 결과로 다시 돌립니다. 모든 장의 첫 문단이 앞 장에서 review-lab에 더한 도구로 시작합니다.
  • 이야기 방식: 하나의 제품을 완성한다. 장마다 작업대에 도구 하나를 올리고, 그 도구가 막아 주는 실패를 실험으로 계산합니다. 마지막 장은 새 실패 상황(팀원의 보고 네 가지)에 이 도구들을 쓰게 합니다.
  • 범위: 원본 Phase 0의 레슨 12개 전부. CPU·메모리·캐시의 하드웨어 원리는 컴퓨터 원리 책에, GPU 메모리 계층과 실행 예산은 LLM 시스템 책에 맡기고 링크로 보냅니다. 이 책은 작업 환경의 공학적 판단(무엇을 고정하고, 무엇을 기록에서 빼고, 어디부터 재는가)에 분량을 씁니다.
  • 증거: 실험 16개 중 대부분은 원본 레슨의 규칙을 브라우저에서 실제로 계산합니다(경로별 필수 검사, 버전 범위 교집합, CUDA 버전 비교, 커밋 그래프, 무시 규칙, 파라미터당 바이트, 권한 비트, 층 캐시, 키 노출 정책, 셀 해석, 시드 분할과 겹침, 경사하강). 빌드 시간·점검 시간·파일 크기·로딩 시간은 교육용 가정값이고, 원격 학습 생존과 확인 순서는 미리 정한 시나리오입니다. 각 실험의 결과 문장에 어느 쪽인지 적었습니다.

부 구성: 기초 공사(1~3장) · 계산 자원(4~6장) · 작업 습관(7~9장) · 진단(10~11장).

5. 2026-10-12 보충

  • 공통: 11개 장마다 전이 문항(transfer, “다른 상황에 써 보기”)을 확인 문제 블록 안에 더했습니다. 블록을 새로 만들지 않아 일곱 블록 순서는 그대로입니다. 보기 순서는 화면에서만 돌려(choiceOrder) 확인 문제의 정답은 장 순번 % 3번째 자리, 전이 문항의 정답은 그다음 자리에 오고, 데이터의 정답 번호와 data-answer·data-transfer 값은 원래 번호를 유지합니다. 장 머리의 문구는 “확인 문제 2개”가 됩니다.
  • 9장 #data: 깊이 읽기 “분할 시드 말고도 결과를 흔드는 것: 학습의 무작위성”과 새 실험 rerun(같은 분할로 다섯 번 다시 학습하기)을 더했습니다. 다섯 번의 정확도는 교육용 시나리오 값이고(고정 안 함 86.2·87.1·85.8·86.9·86.5%, 시드 고정 86.6·86.4·86.7·86.5·86.6%, 결정적 알고리즘까지 모두 86.5%), 평균·범위·표준편차와 “비교할 차이가 범위를 넘는가” 판정은 실제 계산입니다(범위 1.3·0.3·0%p). API 이름과 한계는 PyTorch Reproducibility 문서(2026-10-12 확인)에서 가져왔습니다. 문서에 CUBLAS_WORKSPACE_CONFIG 설명이 없어 본문에 넣지 않았습니다.
  • 11장 #final: 확인 순서 실험에 다섯째 보고 “정확도가 매번 조금씩 다름”(원인 점검: 분할·시드, 증상부터 10분·아래층부터 26분·손실 곡선부터 45분)과 증거 표의 행을 더했습니다. 실험 수는 16개에서 17개가 되었고 registration.json의 cover_meta를 고쳤습니다(루트 data/catalog.json은 편집장이 고칩니다).
  • 검증: npm test, python3 scripts/validate.py(0 오류), python3 scripts/build_catalog.py --check(통과), tests/browser.cjs(1280·390·320px에서 모든 장의 확인 문제·전이 문항 정답/오답 클릭, 실험 예제·경계값·초기화, 가로 넘침, 서가로 버튼)를 실행해 모두 통과했습니다.
