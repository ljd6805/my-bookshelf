# 모델을 움직이는 수학 · 미분에서 푸리에까지

「AI 엔지니어링 처음부터」 시리즈 2권. 음성 명령 인식기 ‘말귀’를 따라가며 AI에 쓰이는 수학을 브라우저에서 직접 계산합니다(12장, 실험 15개).
원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 1을 한국어로 새로 썼습니다.

- 보기: 저장소 루트에서 `python3 -m http.server 8765` 후 `http://127.0.0.1:8765/books/aie-math/`
- 계산·경로 검사: `npm test --prefix books/aie-math`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-math/ node books/aie-math/tests/browser.cjs`
- 개발 문서: `docs/index.html`
