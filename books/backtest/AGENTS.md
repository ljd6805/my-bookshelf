# 백테스트와 자동 매매
루트 AGENTS.md와 docs/08-book-template.html을 따른다. 「금융과 투자 처음부터」 시리즈 13권(마지막 권)이며 12권 「그리드 매매」(books/grid/)·10권 「행동재무학」(books/psychology/)과 같은 화면 구조를 쓴다. 기획·교과과정·장 설계는 docs/index.html이, 사실과 기준값은 docs/research.html이 원본이다. 지금은 G0~G2 초안 단계이며 서가(data/catalog.json)에 등록하지 않았다. 책 본문·실험·테스트는 아직 없다.

- **서윤 G1 결정 대기** (docs/index.html #links-open): 제목 1안 「전략 검증과 자동 매매 · 백테스트 가정을 고치고 주문 봇의 멈춤 조건 시험하기」(공백 제외 32자) 또는 2안 「백테스트와 자동 매매 · 과거 수익률을 다시 계산하고 봇의 멈춤 조건 시험하기」(32자), 색 aqua(제안, 다른 안 plum), 책등 “전략 검증” 또는 “백테스트”, book_id backtest-automation, 폴더 books/backtest, 시리즈 volumes 13권 이름과 12권 next_why 고침, cover_meta “11장 · 11개 실험”. 결정이 나면 이 줄을 결정 내용으로 바꾼다. 책 제목은 공백 제외 32자를 넘기지 않는다.
- **이 책은 학습용이며 투자 권유가 아니다.** 종목·매매 시점·격자 설정을 권하지 않는다. 어느 단계의 수익률도 “기대 수익률”로 쓰지 않고, “가정을 바꾸면 이만큼 바뀐다”까지만 쓴다. “사세요”, “파세요”, “수익 보장”, “이기는 전략”, “검증된 전략”, “최적 설정”, “오를 것”, “내릴 것”을 쓰지 않는다(G3에서 tests/content.test.cjs로 검사).
- **실제 증권사에 연결하지 않는다.** 7~10장과 마지막 과제의 주문 실험은 책 안의 가상 모의 서버(브라우저 안에서만 도는 함수)로만 한다. 실제 증권사의 이름·주소·필드·한도·화면을 본문과 코드에 넣지 않는다. API 키 입력란을 두지 않는다. 증권사 API의 세부는 “증권사마다 다르고 공식 문서에서 확인한다”로만 쓴다(research.html S10·S11은 조사용).
- **제안과 검증을 나눈다(K3, Q3).** 6장은 “이 가상 기록에서 표본 안 1등이 3년째에 82위였다”까지만 쓴다. 이 기록은 3년째에 하락과 낮은 변동성이 오도록 작성 세션이 지어낸 것이라고 1장과 6장에서 밝힌다(research.html V-0). 멈춤 조건(9장)은 “이 기록에서 몇 번째 요청에 걸린다”를 계산하는 예이며, 그 조건이 실제 사고를 막는다고 쓰지 않는다. 한국거래소 킬 스위치는 “도입한다고 보도되었다”까지만 쓴다(시행 여부 확인 전).
- **사례는 가상이다**: 하린(시리즈 공통 인물, 12권 격자의 주인, 이 책의 공통 인물), 새벽전자(가상 주식), 가람200(7권의 가상 ETF), 가상 종목 01~20(번호만). 새 회사 이름을 만들지 않는다. 실제 회사·펀드·증권사·인물의 매매 기록이나 사고를 이름과 금액으로 예시하지 않는다(2013년 12월 사고는 “한 증권사의 주문 실수”로만 쓰고 손실액은 쓰지 않는다).
- **가상 기록은 js/data.js 한 곳에 둔다**(G3에서 만듦): 새벽전자 750거래일 하루 여덟 점 경로와 하루 막대(mulberry32 씨앗 13, 생성 식은 research.html V-0), 배당락 240·490·740일째(주당 400원), 가상 종목 01~20(씨앗 2027), 실전 창 500~559일째와 중복 매수 사건(3년째 11번째 거래일, 19,500원 칸 요청 3건). 자료 생성 식이나 씨앗을 고치면 V-0~V-11의 기준값을 같은 커밋에서 다시 계산한다.
- **정수 원 계산.** 가격·금액은 원 정수로 계산한다. 수수료 = 금액 × 15 ÷ 100,000(버림), 거래세 = 매도 금액 × 2 ÷ 1,000(버림, 가람200 매도는 0), 호가 눈금은 4권 표를 쓴다. 비율은 %로 소수 둘째 자리, 샤프는 소수 셋째 자리로 적는다. 반올림한 중간값을 다시 쓰는 계산은 그렇다고 밝힌다.
- **시점에 민감한 값(⏱)** 셋만 쓰고 js/math.js의 MARKET 한 곳에 둔다: 증권거래세 0.20%(보도 기준, 4권·11권·12권 서재 안 재인용, 법령 원문 확인 못함), 수수료 0.015%(가정), 호가단위 표(4권 재인용). 고정 재확인일 2027-04-14, 그 전이라도 G6 시작일에 4권·11권과 함께 다시 연다. 4장과 마지막 과제에 “세율과 수수료는 바뀌므로 확인일을 보고 다시 확인하세요”를 같은 말로 둔다. 세율 숫자 자체를 확인 문제·복습 퀴즈의 답으로 묻지 않는다.
- **기준값**(research.html V-0~V-11, 계산 스크립트 calc13.py·l2.py는 research.html #calc): tests/math.test.cjs가 대표값을 검사한다. 가정을 하나씩 바꾼 연 수익률 A0 6.24% · A1 12.25% · A2 11.22% · A3 9.09% · A4 7.94% · A5 5.62% · 하루 안 경로 3.05%, A5 샤프 0.502 · 최대 낙폭 −10.14% · 부트스트랩 95% 구간 −7.91~+21.37% · 0 아래 22.67%, 설정 402개 · 표본 안 1등 23.23% → 표본 밖 6.83%(82위) · 순위 상관 −0.161 · 기대 최대 연 샤프 2.112, 실전 창 −71,735원 · 같은 기간 백테스트 −64,557원 · 중복 매수 −17,326원 · 합 −89,061원(−2.97%), 생존 편향 전체 −13.18% 대 남은 16개 −1.32%. 경계값(간격이 왕복 비용보다 좁으면 칸 손익이 음수, 수수료·거래세를 0으로 두면 A5가 A4와 같음, 같은 사건을 두 번 받아도 주문 상태가 바뀌지 않음, 가격이 모든 칸 밖에만 있으면 체결 0건)과 불변 조건(현금 + 보유 평가 = 시작 금액 + 비용을 뺀 실현 손익 + 평가 손익 + 배당, 원인별 금액의 합 = 실제 손익, 체결 수량 + 취소 수량 + 미체결 수량 = 주문 수량, 시험 수 N이 늘면 기대 최대 z가 커짐)도 검사한다. 책 코드로 만든 값과 calc13.py의 값이 다르면 둘 중 어느 쪽이 틀렸는지 따로 계산해 확인한다.
- **실제 계산·미리 정한 시나리오·시각적 비유를 구분한다.** 백테스트 엔진, 수정주가 계수, 지표, 부트스트랩, 설정 402개 시험, 주문 상태 전이, 대사, 멈춤 조건 판정, 체결 짝짓기는 js/math.js가 실제로 계산한다. 가격 기록·실전 창·중복 매수 사건·모의 서버의 초당 2건 한도는 미리 정한 시나리오다. 서가 삽화와 표지는 시각적 비유로 표시한다.
- **실험 기본값과 프리셋은 L2·확인 문제의 답을 보이지 않는다.** app.js의 L2 문장은 docs/index.html #chapters의 L2 칸에서 괄호 속 답을 뺀 질문과 같게, content.js recall은 L1과 같게 둔다. 4장 “하루 안 경로로 계산” 단추는 다섯 칸을 모두 바꾼 뒤에만 연다. 6장 실험은 표본 밖 결과를 독자가 1등을 고른 뒤에 연다.
- **범위 경계**: 호가단위·대기열·비용은 4권 #tick·#queue·#cost, 기준가 조정은 4권 #events, 가격제한폭·VI·서킷브레이커는 4권 #limits, 칸의 손익·박스권·장부·멈춤 가격은 12권 #cell·#box·#ledger·#exit, 최대 낙폭의 성질은 8권 #drawdown, 샤프 비율의 쓰임은 9권 #frontier, 구간과 검정은 확률과 통계 #interval·#testing, 누설 없는 검증과 복잡도는 머신러닝 기초 #pipeline·#tradeoff, 키 관리는 AI 개발 작업대 #keys, 멱등 키와 내구 실행은 자율 시스템 #durable, 비용 상한은 자율 시스템 #budget, 현실 격차는 강화학습 #simreal, 거래세·배당소득세는 11권 #trade·#dividend, 결정 일지는 10권 #final로 링크하고 다시 계산하지 않는다. 고빈도 매매, 파생상품·해외·코인 자동 매매, 기계 학습 매매 신호, 세후 수익 상세, 서버 운영, 알고리즘 거래 법령 해석은 다루지 않는다.
- **떠올리기(L1)** 는 이미 공개된 책(1~12권, 확률과 통계, 머신러닝 기초, AI 개발 작업대, 자율 시스템, 강화학습, 컴퓨터 원리)과 이 책 앞 장에서만 쓴다. 링크는 chapter_index에 있는 앵커만 건다.
- 연구 결과는 학술 원문·학술 초록·서지·공식 문서·2차 자료·보도 등급을 화면에 적는다. 블록 부트스트랩, 걷기 전진의 원 자료, PBO의 정의처럼 원 자료를 열지 못한 것은 research.html #unverified를 보고 쓰지 않거나 “확인 못함”을 붙인다. “개인 투자자의 90%가 자동 매매로 손해 본다” 같은 출처 없는 숫자를 쓰지 않는다.
- 계산은 js/math.js 한 곳(DOM 없음)에 둔다. 화면 글자는 실험 꼬리표로 실제 계산·미리 정한 가정·학술 원문·학술 서지·공식 문서·2차 자료·보도·서재 안 재인용·확인 못함·시각적 비유를 구분하고, 상태는 색과 함께 글자와 ✓ ✗ ▲로 적는다.
- **제목(K7)**: 장 ID는 #backtest #data #lookahead #fills #metrics #overfit #api #orders #limits #monitor #final이며 바꾸지 않는다. 장 제목은 대상과 독자가 하는 일을 직접 말한다. 기획안의 “미래를 미리 본 코드”, “멈춤 단추”, “전략을 믿어도 될까” 같은 장면말·소품말·물음 제목을 장 제목과 실험 제목에 쓰지 않는다. 대표 실험 이름은 “백테스트 가정 하나씩 바꾸기 실험”, “표본 안 1등 실험”, “주문 상태와 잔고 대사 실험”, “봇 멈춤 조건 실험”이다.
