# 백테스트와 자동 매매 · 가정을 고쳐 수익률을 견주고 봇의 멈춤 조건 시험하기

정적 인터랙티브 교과서(「금융과 투자 처음부터」 13권, 마지막 권)로 만들 책의 기획 폴더입니다. 하린이 12권에서 설계한 격자 규칙을 가상 회사 새벽전자의 3년(750거래일) 기록에 돌려 본 백테스트 숫자에서 시작합니다. 가격 자료(수정주가와 배당), 그날 알 수 없던 값을 쓴 코드 줄, 하루 막대 안의 체결 가정, 수수료·거래세를 하나씩 고치며 연 수익률이 12.25%에서 5.62%로 줄어드는 폭을 계산하고, 샤프 비율·최대 낙폭·부트스트랩 구간으로 그 숫자가 얼마나 흔들리는지 말합니다. 설정 402개 가운데 고른 1등이 고르는 데 쓰지 않은 기간에 몇 위였는지 계산한 뒤, 가상 모의 서버에서 주문 상태와 잔고 대사, 멈춤 조건, 모의 서버 체결과 백테스트 체결의 차이를 다룹니다. 마지막 과제는 표본 안 연 23.23%를 보고 시작한 봇이 모의 서버 석 달 −89,061원(−2.97%)으로 끝난 까닭을 원인별 금액으로 나누는 일입니다. 모든 기록은 가상이며, 3년째는 가격이 내려가고 변동이 작아지도록 지어낸 구간입니다. 어떤 설정도 권하지 않고 자동 매매도 권하지 않습니다. 실제 증권사에 연결하지 않습니다.

현재 상태: **G0~G2 초안 2차 판, 서가 미등록** (2026-10-14). 기획·교과과정·장 설계 초안(docs/index.html)과 조사 노트·기준값·계산 스크립트(docs/research.html)만 있습니다. 한결(G0)·서윤(G1)·해원(G2)의 조건부 승인을 반영했고 팀장의 재확인과 관문 행 기록 전이며, 책 본문·실험·테스트·카탈로그 등록은 G3 이후에 합니다.
