# 재무제표 읽기
루트 AGENTS.md와 docs/08-book-template.html을 따른다. 「금융과 투자 처음부터」 시리즈 5권이며, 7권 「지수와 ETF」(books/etf/)와 같은 화면 구조를 쓴다. 기획·교과과정·장 설계는 docs/index.html, 사실과 기준값은 docs/research.html이 원본이다.
- 이 책은 학습용이며 투자 권유가 아니다. 사례는 모두 가상이다: 하린, 새벽전자(코스피 상장 가정, 1,000만 주, 주가 약 20,000원, 3년 회사채 표면금리 5.0%, 배당 주당 400원 = 40억 원은 앞선 권과 맞춘 설정), 9장의 “가상의 유통 회사”·“가상의 소프트웨어 회사”(이름을 붙이지 않는다). 실제 상장회사의 숫자를 예로 분석하지 않는다. DART 화면은 어디에서 무엇을 찾는지만 보이고 실제 회사 숫자는 가린다.
- 새벽전자 재무 숫자의 원본은 research.html V-2~V-10(억 원, 2023년 말 기초 → 2024 사업연도 → 2025 사업연도)이다. 가정(매출원가 70%, 판매비와관리비 18%, 감가상각 = 기초 유형자산 10%, 이자비용 12억 원, 이자수익 2억 원, 법인세 20%, 배당 40억 원, 이자 지급은 영업활동·배당 지급은 재무활동, 기말 현금 50억 원 미만이면 50억 원 단위 단기차입, 차입은 연말이라 그해 이자비용은 그대로)은 js/math.js의 ASSUME 한 곳에만 둔다.
- 대표 실험(5장 세 재무제표 연동 실험)의 대조 네 줄은 어떤 입력에서도 맞아야 한다: 자산 = 부채 + 자본, 기초 이익잉여금 + 순이익 − 배당 = 기말, 기초 현금 + 현금흐름 합계 = 기말 현금, 기초 유형자산 + 설비투자 − 감가상각 = 기말. tests/math.test.cjs가 대표값·경계값(매출 0, 매출채권 0, 큰 설비투자로 차입 발생)과 무작위 입력으로 이 불변 조건을 검사한다. “연결 장부”라는 이름은 연결재무제표와 헷갈리므로 쓰지 않는다.
- 회계기준·제출 기한·감사의견에 따른 거래소 조치는 2026-10-13 확인 기준이다. 화면에 확인일과 출처 등급(한국거래소·DART·국제회계기준재단 원문 / 법무법인·회계법인 안내 / 확인 못함)을 붙이고, “기준과 공시 규칙은 바뀌므로 한국회계기준원·금융감독원·한국거래소의 공식 자료로 다시 확인하세요”를 머리말·8장·10장에 같은 말로 둔다. 2027년 1월 1일 이후 시작하는 회계연도의 변경(K-IFRS 제1118호, 현금흐름표 이자·배당 분류)은 3·4장 안내 상자로만 쓰고 본문 계산은 현행 기준으로 한다. 기한·규칙 숫자는 js/math.js의 RULES 한 곳에만 둔다.
- 결과 문장은 판정이 아니라 “이 가정에서는 …”, “더 확인할 신호”로 쓴다. “분식회계”를 판정어로 쓰지 않고 “추천”, “사세요”, “피하세요”, “유리”를 쓰지 않는다(tests/guides.test.cjs가 검사). 7장과 10장에는 “가상의 회사로 계산한 사례이며, 특정 주식을 사고팔라는 권유가 아닙니다”를 붙인다.
- 가치 평가(PER·PBR·EV/EBITDA·DCF)는 6권 「기업 가치 평가」(books/valuation, 2026-10-13 공개)의 몫이라 이 책에서 계산하지 않는다. 본문은 책 이름으로 안내하고, 링크는 “더 읽어 보기”에 “깊이 보기 (뒤 권)”으로 둔다(#ratios → ../valuation/#per, #final → ../valuation/#fcf, 마지막 장 다른 책 → ../valuation/#price). 배당소득세는 11권 #dividend, 장부 항등식은 12권 #ledger로 보낸다. 뒤 권(7·8·11·12권)은 선수가 아니라 깊이 보기(뒤 권)이며, 본문 떠올리기(L1)는 1·3·4권과 이 책 앞 장으로만 쓴다.
- 계산은 js/math.js 한 곳(DOM 없음, 금액은 억 원·소수 첫째 자리, 비율은 소수 첫째 자리)에 둔다. 비율의 정의(평균·기말 분모, 재고회전율은 매출원가 기준)는 화면에 함께 적는다. 발생액 비율 (순이익 − 영업현금흐름) ÷ 평균 총자산은 “이 책의 단순화”라고 표시한다. tests/math.test.cjs가 research.html V-1~V-10과 본문·복습·L2 숫자를 대조한다. app.js의 L2 문장은 docs/index.html #chapters의 L2 칸에서 괄호 속 답을 뺀 질문과 같게, content.js recall은 L1과 같게 둔다.
- 실험 꼬리표로 실제 계산·공식 원문·안내 기준·미리 정한 가상 시나리오·이 책의 단순화·확인 못함·시각적 비유를 구분하고, 대조와 신호의 상태는 색과 함께 글자와 ✓ ✗ ▲로 적는다.
- 서가 펼침 삽화의 클래스·id·keyframes는 fs- 접두어. 표지 삽화는 공통 cv-* 클래스만 쓰고 펼침 삽화와 다른 장면(세 재무제표가 나란히 놓이고 순이익 → 이익잉여금, 현금흐름 합계 → 현금 화살표)으로 둔다. 책 색은 sage.
- 함수와 즉시 실행 블록은 100줄 이내. 스크립트·스타일을 고치면 index.html의 ?v= 한 값을 함께 올린다. npm test와 tests/browser.cjs를 실행하고 docs/index.html에 검증 범위를 기록한다.
