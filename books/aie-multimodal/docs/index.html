멀티모달 AI · 제작 문서

「AI 엔지니어링 처음부터」 시리즈 13권 《멀티모달 AI · 보고 듣고 말하는 모델》의 기획, 원본 레슨 대응, 구현, 검증을 한곳에 모았습니다. 작성일 2026-10-08. 원본은 rohitg00/ai-engineering-from-scratch(MIT)의 phases/12-multimodal-ai 레슨 25개입니다. 원문과 코드를 옮기지 않고 개념과 순서, 실험 아이디어만 참고해 한국어로 새로 썼습니다. 원본이 다룬 최신 모델(Qwen2.5-VL, InternVL3, Qwen2.5-Omni, π0, ColPali 등)의 내용은 원본 커리큘럼 기준(확인일 2026-10-08)으로만 적었고, 원본과 인용 논문에 없는 수치를 새로 만들어 넣지 않았습니다.

1. 기획

  • 독자: 트랜스포머와 LLM 응용을 한 번 다뤄 봤고(시리즈 12권 LLM 엔지니어링까지), 이미지나 소리를 모델에 넣어 본 적은 있지만 시각 토큰이 문맥을 얼마나 먹는지, 연결 방식과 해상도 전략을 어떻게 고르는지 스스로 계산해 본 적은 없는 사람.
  • 끝의 행동: 사진·영상·소리·문서·화면이 섞인 요청을 받았을 때 각 입력을 몇 토큰으로 어떻게 넣을지, 무엇을 검색하고 무엇을 생성할지, 어디서 실패를 검증할지를 숫자로 근거를 대어 설계할 수 있습니다.
  • 공통 사례: 세탁기 A/S 센터 상담 도우미. 고객이 보낸 E-21 표시창 사진, 탈수 소음 녹음, 90초 드럼 영상, 48쪽 스캔 설명서, 수리 예약 웹페이지를 장마다 하나씩 더 읽습니다.
  • 이야기 방식: 하나의 제품을 완성한다. 1장에서 사진 한 장을 토큰으로 바꾸고, 장마다 입력 하나나 출력 하나를 더해 마지막 장에서 화면을 직접 누르는 도우미가 됩니다. 마지막 과제는 건조기 고객(6분 영상 속 0.3초 불꽃, 손글씨 보증서, 영어 120쪽 설명서, 모바일 앱 예약)으로 바뀐 상황을 같은 도구로 다시 설계하는 일입니다.
  • 범위: 원본 레슨 25개 전부를 12장 16개 실험으로 묶었습니다. 장마다 시작 질문, 이전 장의 결과, 새 도구, 해결 결과, 남은 질문을 잇고, 문제 → 예측 → 조작 → 관찰 → 설명 → 전이 흐름을 따릅니다.
