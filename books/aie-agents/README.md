# 에이전트 엔지니어링 · 루프에서 작업대와 제품 판단까지

「AI 엔지니어링 처음부터」 시리즈 15권. 원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 14 레슨 54개를 한국어로 새로 쓴 12장·16개 실험의 인터랙티브 책입니다. 장애 대응 에이전트 “당직 도우미”를 루프에서 작업대와 제품 판단까지 만듭니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765` 후 `http://127.0.0.1:8765/books/aie-agents/`
- 계산 검사: `npm test --prefix books/aie-agents`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-agents/ node books/aie-agents/tests/browser.cjs`
- 작업 규칙: [AGENTS.md](AGENTS.md), 제작 문서: [docs/index.html](docs/index.html)
