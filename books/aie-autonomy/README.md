# 자율 시스템 · 밤새 혼자 일하는 에이전트에 울타리 치기

「AI 엔지니어링 처음부터」 시리즈 16권. 원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 15 레슨 22개를 한국어로 새로 쓴 12장·16개 실험의 인터랙티브 책입니다. 온라인 서점 책마루의 야간 에이전트 누리 하나가 긴 실행의 신뢰도에서 자기 개선 고리, 권한·기록·예산·멈춤 단추, 원칙과 분류기, 연구소 정책과 외부 평가까지 거치며 자율 운영 명세서를 완성합니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765` 후 `http://127.0.0.1:8765/books/aie-autonomy/`
- 계산 검사: `npm test --prefix books/aie-autonomy`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-autonomy/ node books/aie-autonomy/tests/browser.cjs`
- 작업 규칙: [AGENTS.md](AGENTS.md), 제작 문서: [docs/index.html](docs/index.html)
