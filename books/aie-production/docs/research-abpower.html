식과 기준값

  • p₂ = p + δ, q = 1 − p. nraw = (z₁₋α/₂ + z₁₋β)²·(p(1 − p) + p₂(1 − p₂))/δ², n = ⌈nraw⌉.
  • 하루 집단당 표본 = 하루 요청 × 피드백 비율 ÷ 2 (50:50 배정). 기간(일) = n ÷ 하루 집단당 표본, 날짜 수 = 올림.
  • CUPED 뒤 표본 = ⌈nraw·(1 − ρ²)⌉.

단위·가정·유효 범위

  • 단위: p와 δ는 비율(화면에서는 %와 %p), 표본은 “피드백을 남긴 대화” 수, 기간은 일.
  • 교육용 가정: 기준 만족률 60%, 피드백 비율 5%, CUPED 상관 ρ. 하루 5만 건은 책 전체의 누리봇 사례(NURI.daily)와 같습니다.
  • 유효 범위: 0 < p < 1, δ > 0, p + δ < 1. 정규 근사라 표본이 작거나 p가 0.05·0.95 근처면 정확 검정과 어긋날 수 있습니다(크기는 확인하지 못함). 표본을 다 모은 뒤 한 번만 본다고 가정합니다.
  • 넣지 않은 것: 원본이 권한 비결정성 여유(1.3~1.5배), 순차 검정 보정, 요일 효과, 다중 비교 보정.
  • 공통 사례와의 이음매: 같은 장의 카나리 실험은 “싫어요 비율 5%”를 요청 기준 교육용 가정으로 씁니다. abpower의 가정(피드백 5% × 싫어요 40%)으로 환산하면 요청 기준 싫어요는 2%라 두 가정이 맞지 않습니다. 두 실험은 서로 다른 질문(관문 잡음, A/B 기간)을 다루어 결론은 바뀌지 않지만, 다음 개정에서 한쪽 가정을 맞추거나 본문에 “다른 가정”이라고 밝힐 일로 남깁니다(교과과정팀 해원에게 넘김).

실제 계산·시나리오·비유

  • 실제 계산: 표본 크기, 기간, CUPED 뒤 표본, z 값. 결과 문장이 “실제 계산입니다(두 비율 양측 검정의 정규 근사)”라고 밝힙니다.
  • 미리 정한 시나리오: 누리봇의 만족률 60%와 새 프롬프트의 +3%p는 이야기를 위한 가정이며 측정값이 아닙니다.
  • 비유: 없음. 막대그래프와 7일 점선은 계산 결과를 그대로 그린 것입니다.

오해 목록 (태오 → 교수법팀 연우)

  • “δ가 절반이면 기간도 두 배” → n은 δ²에 반비례해 약 네 배(확인 문제의 오답 보기).
  • “표본 크기는 하루 요청 수로 정해진다” → 하루 요청은 기간만 바꾸고 필요한 표본은 p·δ·α·검정력이 정합니다.
  • “3.3일이면 사흘 돌리고 끝” → 날짜로는 4일이고, 요일 효과를 보려면 한 주를 채우는 편이 안전합니다(본문의 남는 문제).
  • “결과가 좋아 보이는 날 멈춰도 된다” → 고정 표본 식은 한 번만 보는 가정입니다. 중간에 볼 계획이면 순차 검정.
  • “CUPED는 공짜로 표본을 줄인다” → 실험 전 값과의 상관이 있어야 하며 ρ = 0이면 그대로입니다.
