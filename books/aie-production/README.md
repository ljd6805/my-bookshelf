# AI 인프라와 운영 · 모델 서버에서 운영 장부까지

「AI 엔지니어링 처음부터」 시리즈 18권. 원본 커리큘럼 rohitg00/ai-engineering-from-scratch(MIT)의 Phase 17 · Infrastructure and Production(레슨 28개)를 상담 챗봇 누리봇 하나를 운영하는 이야기로 한국어로 재구성한 12장 16개 실험의 인터랙티브 책입니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765` 후 http://127.0.0.1:8765/books/aie-production/
- 계산 테스트: `npm test --prefix books/aie-production`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-production/ node books/aie-production/tests/browser.cjs`
- 제작 문서: [docs/index.html](docs/index.html), 작업 규칙: [AGENTS.md](AGENTS.md)
