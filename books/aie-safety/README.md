# AI 안전과 윤리 · 출시 전에 무엇을 확인할까

「AI 엔지니어링 처음부터」 시리즈 19권. 원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 18 레슨 30개를 한국어로 새로 쓴 12장·16개 실험의 인터랙티브 책입니다. 누리은행의 상담 AI 누리를 출시하기 전에 보상 신호, 숨은 결함, 감독, 공격과 방어, 공정성·프라이버시·규제를 차례로 점검합니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765` 후 `http://127.0.0.1:8765/books/aie-safety/`

- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-safety/ node books/aie-safety/tests/browser.cjs`
- 작업 규칙: [AGENTS.md](AGENTS.md), 제작 문서: [docs/index.html](docs/index.html)
- 규제 일정과 법률 내용은 원본 커리큘럼 기준(확인일 2026-10-08)입니다. 실제 판단 전에는 공식 문서를 확인하세요.
