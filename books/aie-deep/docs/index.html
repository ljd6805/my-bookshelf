1. 기획

항목결정
독자경사하강과 행렬 곱은 들어 보았지만, 여러 층의 기울기를 어떻게 구하고 학습이 왜 멈추는지는 설명하지 못하는 개발자와 학생. PyTorch 코드를 따라 써 본 사람도 포함합니다.
끝의 행동멈춘 학습의 손실 곡선과 층별 기울기를 보고, 활성화·초기화·옵티마이저·학습률·규제 중 무엇을 바꿀지와 그 이유, 아직 부족한 증거를 말할 수 있습니다.
공통 사례"원 판별기": 평면 [-1,1]² 위의 점이 반지름 0.8 원 안(1)인지 밖(0)인지 맞히는 작은 신경망. 1~3장은 그 가장 작은 판인 네 모서리 XOR로 시작하고, 4장 이후의 학습 실험은 모두 같은 판별기를 js/math.js의 train()으로 실제 학습시킵니다.
이야기 방식하나의 제품을 완성한다. 장마다 부품(퍼셉트론 → 층 → 역전파 → 활성화 → 손실 → 옵티마이저 → 일정 → 초기화 → 규제 → 프레임워크 → 디버깅)을 하나씩 붙이고, 마지막 장에서 깊게 만든 판별기가 멈춘 새 상황을 진단합니다.
범위완전연결 다층망, 전체 배치 경사하강, 이진 분류. 합성곱·순환망·트랜스포머 구조, GPU 실행, 대규모 데이터는 다루지 않습니다. 겹치는 AI Book의 뉴런(#neuron)·경사하강(#learning), 벡터와 행렬의 층(#layer)은 짧게 요약하고 링크로 보냅니다.
증거17개 실험 중 14개와 표지 실험은 브라우저 안의 실제 계산(학습 포함), 골짜기 옵티마이저는 실제 계산이지만 교육용 2차원 함수, 자동미분 단계·모델 크기는 공식 계산입니다. 미리 정한 시나리오나 비유만으로 된 실험은 없습니다. 장 그림 중 프레임워크 고리와 드롭아웃 X 표시는 비유이며 캡션에 밝혔습니다.
마지막 과제12장: 폭 8 × 6층 시그모이드·작은 초기화·SGD로 만든 판별기가 손실 0.693에 멈춤. 무엇을 바꿀지, 왜인지, 부족한 증거는 무엇인지 답합니다.

1장 minibatch“배치를 8에서 80으로 키우면 학습률을 몇 배로”는 깊이 읽기의 선형 스케일링 규칙(k배)으로 답할 수 있음예제 셋. B = 80·η = 0.3은 손실 0.656, B = 8은 0.493(오른 갱신 36.5%), B = 80·η = 3은 0.488안내 문장의 숫자와 화면이 같음깊이 읽기가 “지금까지 이 책의 학습 실험은”으로 시작하는데 이 장이 1장이 되어 “지금까지”가 가리킬 실험이 없음 → “이 책의 다른 학습 실험은 … 구합니다”로 고침
