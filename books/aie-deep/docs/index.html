딥러닝 핵심 · 퍼셉트론에서 나만의 작은 프레임워크까지 · 제작 문서

「AI 엔지니어링 처음부터」 시리즈 4권의 기획, 원본 레슨 대응, 구현, 검증 기록입니다. 원본은 공개 저장소 rohitg00/ai-engineering-from-scratch(MIT, 2026 Rohit Ghumare)의 phases/03-deep-learning-core 13개 레슨이며, 개념·순서·실험 아이디어만 참고하고 문장과 코드는 새로 썼습니다. 작성·확인일 2026-10-08.

1. 기획

항목결정
독자경사하강과 행렬 곱은 들어 보았지만, 여러 층의 기울기를 어떻게 구하고 학습이 왜 멈추는지는 설명하지 못하는 개발자와 학생. PyTorch 코드를 따라 써 본 사람도 포함합니다.
끝의 행동멈춘 학습의 손실 곡선과 층별 기울기를 보고, 활성화·초기화·옵티마이저·학습률·규제 중 무엇을 바꿀지와 그 이유, 아직 부족한 증거를 말할 수 있습니다.
공통 사례"원 판별기": 평면 [-1,1]² 위의 점이 반지름 0.8 원 안(1)인지 밖(0)인지 맞히는 작은 신경망. 1~3장은 그 가장 작은 판인 네 모서리 XOR로 시작하고, 4장 이후의 학습 실험은 모두 같은 판별기를 js/math.js의 train()으로 실제 학습시킵니다.
이야기 방식하나의 제품을 완성한다. 장마다 부품(퍼셉트론 → 층 → 역전파 → 활성화 → 손실 → 옵티마이저 → 일정 → 초기화 → 규제 → 프레임워크 → 디버깅)을 하나씩 붙이고, 마지막 장에서 깊게 만든 판별기가 멈춘 새 상황을 진단합니다.
범위완전연결 다층망, 전체 배치 경사하강, 이진 분류. 합성곱·순환망·트랜스포머 구조, GPU 실행, 대규모 데이터는 다루지 않습니다. 겹치는 AI Book의 뉴런(#neuron)·경사하강(#learning), 벡터와 행렬의 층(#layer)은 짧게 요약하고 링크로 보냅니다.
증거16개 실험 중 13개와 표지 실험은 브라우저 안의 실제 계산(학습 포함), 골짜기 옵티마이저는 실제 계산이지만 교육용 2차원 함수, 자동미분 단계·모델 크기는 공식 계산입니다. 미리 정한 시나리오나 비유만으로 된 실험은 없습니다. 장 그림 중 프레임워크 고리와 드롭아웃 X 표시는 비유이며 캡션에 밝혔습니다.
마지막 과제12장: 폭 8 × 6층 시그모이드·작은 초기화·SGD로 만든 판별기가 손실 0.693에 멈춤. 무엇을 바꿀지, 왜인지, 부족한 증거는 무엇인지 답합니다.

3. 구현

  • 파일: js/math.js(모든 계산, DOM 없음), js/content.js(모든 글), js/visual.js(공통 UI), js/figures.js(장마다 움직이는 개념 그림 12개), js/labs-neuron.js(1~4장), js/labs-train.js(5~9장), js/labs-tools.js(10~12장), js/home-lab.js(표지 실험), js/lab-guides.js, js/app.js. 전역 접두어는 A04입니다.
  • 학습 엔진 train(): 입력 2 → 은닉(폭·깊이·활성화 선택) → 시그모이드 출력, 이진 교차 엔트로피(또는 MSE), 전체 배치로 epoch마다 한 번 갱신, SGD·모멘텀·AdamW(분리된 감쇠), 역드롭아웃, 다섯 가지 학습률 일정, 디버깅용 의도적 고장(학습률 ×200, 기울기 누적, 라벨 뒤섞기, 입력 ×50). mulberry32 난수로 시드를 고정해 같은 입력은 같은 결과를 냅니다. 검증 손실은 실행당 최대 101번만 재서 한 번 갱신이 대체로 0.1~0.3초 안에 끝납니다.
  • 그 밖의 계산: 퍼셉트론 학습 규칙, 손으로 정한 2-2-1 XOR 망, 뉴런 하나의 연쇄법칙과 중앙 차분, 깊은 망의 순방향 활성값·역방향 기울기 통계(deepStats), 손실·기울기 공식, 2차원 골짜기 옵티마이저 경로, 작은 자동미분 엔진(역위상 순서와 누적), MLP 파라미터 수와 메모리, 기울기 검사.
  • 가정과 한계: 데이터는 수십~수백 점의 2차원 합성 데이터이며 결과는 한 시드의 한 번 실행입니다. 프레임워크 속도 비교, MNIST 정확도, 공개 모델의 학습률 수치는 원본 커리큘럼이 제시한 범위를 "원본 커리큘럼 기준(확인일 2026-10-08)"으로 옮겼고 직접 재현하지 않았습니다.
  • 서가 삽화: assets/shelf-illustration.svg는 값이 앞으로, 기울기가 거꾸로 흐르고 손실 곡선이 그려지는 시각적 비유입니다. @keyframes 4개, prefers-reduced-motion과 html[data-motion=reduce]에서 멈춥니다. 표지 그림 assets/cover-art.svg는 신경망과 원 판별 지도의 정지 그림입니다(cv-* 클래스만).
  • 서재 등록 제안: registration.json(장 색인, 개념, 읽기 노선 단계, 들어오는 링크).

확인하지 못한 것: 대표 독자가 새 조건의 결과와 이유를 설명하는지(L4)는 시험하지 않았습니다. 학습 결과는 고정 시드 하나에서만 검사했고, 다른 시드에서 같은 경향이 나오는지는 확인하지 않았습니다. 실제 PyTorch·JAX 코드는 실행하지 않았고, 서가에서 책을 펼쳐 삽화가 움직이는지는 서재 등록 뒤 관리자가 확인해야 합니다. 느린 기기에서 학습 실험 한 번의 반응 시간은 재지 않았습니다(이 컨테이너의 Node에서 0.02~0.25초).
