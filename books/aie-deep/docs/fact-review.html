편집팀 관점별 점검

  • 기획·연결 (서윤·하람·도현·민재): 공통 사례(원 판별기)가 1장 XOR에서 마지막 과제의 6층 판별기까지 이어지고, 마지막 과제는 “무엇을 바꾸나·왜·부족한 증거”를 표로 적게 해 관찰 가능한 행동으로 끝납니다. 장 색인 12개, 공통 개념 6개, 읽기 노선 “모델이 배우기까지 직접 쌓기”의 #backprop 정거장이 있고, 노선 과제(손실 0 근처와 0.35 근처 멈춤 찾기)는 시드 1·η 2(0.005)와 시드 6·η 2(0.353)로 실제로 재현됩니다. 다른 책에서 들어오는 링크는 6권에서 7개(시리즈 이동 포함)로 적은 편입니다.
  • 지식조사 (은재·지호·유진): 원본 레슨의 실무 수치(죽은 뉴런 10~40%, RMSNorm 약 10% 가벼움, 학습률 범위, MNIST 97.8%)는 “원본 레슨 기준”으로 표시되어 있고, 원본이 SimCLR 기본값을 0.07로 잘못 적은 점은 이미 본문이 바로잡았습니다. 이번에 과장 1건과 과도한 단정 1건, 정의 누락 1건을 고쳤습니다.
  • 수치·실험 (수아·건우·시우): 학습 실험은 모두 고정 시드의 실제 계산이고, 골짜기 함수·장난감 모형은 “교육용 함수, 계산은 실제”로 구분되어 있습니다. 안내 상자 숫자와 계산이 모두 일치했습니다(예: 시그모이드 z=4 기울기 0.0177, Xavier+ReLU 50층 5.8×10⁻⁹, He+ReLU 50층 0.19, ε=10⁻⁵ 상대 차이 1.4×10⁻¹¹).
