# 거시경제 · GDP·물가·고용 지표를 계산하고 발표 뒤 금리·환율·물가의 경로를 가설로 세우기

정적 인터랙티브 교과서(「금융과 투자 처음부터」 2권). 가상의 인물 하린이 2026년 10월 둘째 주에 본 경제 뉴스를 지표 장부에 옮기며, 모형 경제로 GDP(900조 원)와 실질 성장률을, 가상 장바구니로 물가지수(106.3)를, 가상 동네로 실업률·고용률을 계산하고 GDP 갭으로 경기 국면을 나눈다. 미리 정한 정책 시나리오 모형(계수는 가정, 예측 아님)에 정책 금리와 정부 지출을 넣어 환율·GDP·물가가 가장 크게 반응하는 분기를 읽고, 원/달러 환율 변화를 원화 금액으로, 경상수지를 네 수지의 합으로 계산한다. 시차 상관으로 선행·동행 지수를 견주고 1997·2008·2020 위기를 지표로 비교한 뒤, 마지막에 물가가 예상보다 0.4%p 높게 나온 가상의 발표를 세 시간 범위의 가설표와 확인 지표로 바꾼다. 기준금리는 2026-10-13 확인 기준 연 3.00%(2026-08-27 결정)이며 다음 결정은 2026-10-22이다. 학습용 계산이고 시장 가격의 예측이나 매매 권유가 아니다.

현재 상태: G3 작성 중. js/math.js(계산), js/content.js(장 데이터), review.json(복습 문항), tests/가 있고 화면(index.html·app.js·실험·그림)은 아직 없다. 서가에 등록되지 않았다.
