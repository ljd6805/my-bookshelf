# 강화학습 · 보상에서 정책까지

「AI 엔지니어링 처음부터」 시리즈 10권. 원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 9 레슨 12개를 한국어로 새로 쓴 12장·16개 실험의 인터랙티브 책입니다. 창고 배송 로봇 나르미 하나가 MDP에서 PPO·RLHF·게임 탐색까지 배워 갑니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765` 후 `http://127.0.0.1:8765/books/aie-rl/`
- 계산 검사: `npm test --prefix books/aie-rl`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-rl/ node books/aie-rl/tests/browser.cjs`
- 작업 규칙: [AGENTS.md](AGENTS.md), 제작 문서: [docs/index.html](docs/index.html)
