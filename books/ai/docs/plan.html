AI Book 설계와 구현 계획

2026-10-06 · 구현 전 결정 사항

목표

한국어로 읽고, 수식을 확인하고, 입력을 바꾸며 결과를 관찰하는 AI 인터랙티브 교과서를 만든다. SensorBook의 학습 구성과 챕터 탐색 방식을 참고하되 문장·코드·그림은 새로 작성한다.

범위

12개 장, 18개 실험, 장별 확인 문제와 해설. 입문 개발자가 신경망에서 RAG와 에이전트까지 연결해 이해하도록 구성한다.

  1. 신경망: 뉴런, 활성화 함수
  2. 학습: 회귀 직선, 경사하강법
  3. 일반화: 과적합
  4. 토큰: BPE 병합
  5. 임베딩: 벡터 유사도
  6. 어텐션: QK 점수, 인과 마스크
  7. 생성: temperature, top-k/top-p
  8. 비전: 합성곱
  9. 사후 학습: 선호도에 따른 선택 확률
  10. 추론: 양자화, 메모리 산정
  11. RAG: 문서 검색
  12. 에이전트: 도구 실행 상태, 분류 평가

구현 결정

HTML/CSS/JavaScript 정적 사이트. CDN, API 키, 유료 추론, 빌드 도구 없이 실행한다. 해시 주소로 장을 전환하므로 GitHub Pages의 하위 경로에서도 동작한다. 수치 계산, 도해, 실험, 콘텐츠, 화면 구성을 모듈로 분리한다. 함수는 100줄 미만으로 유지한다.

설계

잉크색 배경, 청록색 데이터, 주황색 조작점으로 실험 도구의 시각적 질서를 만든다. 데스크톱은 목차와 본문을 병렬 배치하고 모바일은 접이식 목차로 전환한다. 차트는 SVG로 선명하게 표시한다. 숫자 결과와 대체 설명을 함께 제공한다.

검증

softmax 확률 합, 경사하강법 수렴, top-p 경계, 코사인 유사도, BPE 병합, 양자화 오차, 합성곱, 평가 지표를 단위 테스트한다. 전체 장·실험의 조작과 데스크톱·모바일 화면을 브라우저로 확인한다.
