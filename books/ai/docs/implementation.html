교육용 가정

  • 어텐션은 손으로 지정한 Q·K·V를 사용한다.
  • 과적합은 직선과 7차 보간 다항식을 혼합한다. 신경망 훈련이 아니다.
  • BPE는 단어 내부의 문자 쌍 병합만 구현한다.
  • 샘플링은 고정 로짓과 고정 시드 의사난수를 사용한다.
  • 사후 학습 실험은 보상과 KL 제약에 따른 정책 분포 계산이다.
  • 메모리는 고정 GQA 구조의 가중치·KV 부분 합계다.
  • RAG는 단어 출현 여부 검색 후 근거를 발췌한다.
  • 에이전트는 실패와 재시도를 보여 주는 고정 상태 머신이다.

접근성과 호환성

본문 건너뛰기, 명시적 입력 레이블, 키보드 포커스, 화면 모드 전환, SVG 대체 설명, 결과 텍스트, 모바일 목차를 제공한다. 애니메이션 자동 재생은 없으며 외부 폰트나 CDN에 의존하지 않는다.

의도적으로 제외한 범위

실제 LLM 다운로드·실행, 사용자 계정, 서버 저장, 분석 추적, 유료 API는 포함하지 않는다. 숫자 모형으로 원리를 배우는 데 집중한다.
