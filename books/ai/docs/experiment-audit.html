EXPERIMENT AUDIT · 2026-10-07

조작이 이해로 이어지는지 점검했습니다.

홈 신경망과 본문 18개 실험을 계산, 교육 목적, 변화의 가시성, 결과 해석, 모바일 화면의 다섯 기준으로 검토했습니다.

발견한 문제와 수정

  • 홈 신경망: 장식 애니메이션을 입력→은닉층→출력의 실제 계산으로 교체했습니다.
  • 벡터: 가로·세로 축척을 같게 맞춰 각도의 왜곡을 없앴습니다.
  • 마스크: 선택한 Query 행을 테두리로 표시합니다.
  • 추출: 이론 확률과 실제 추출 비율을 각각 표시합니다.
  • 합성곱: 커널별 색 범위를 구분하고 중앙 계산에 쓰는 입력 9칸을 표시합니다.
  • 경사하강법: 발산 시 무한 계산을 막습니다. 에이전트에는 계속 실패하는 경로와 답변 보류를 추가했습니다.
  • 전체: 비교 예제, 초기화, 관찰 목적, 결과 해석을 추가했습니다. 변화하지 않는 것이 정상인 조건과 교육용 모형의 가정을 설명합니다.
  • 시인성: 본문·숫자·축 눈금을 확대하고 한글 결과의 글꼴을 통일했습니다. 평가 샘플 카드와 메모리 구성비를 추가했습니다.

실험별 동작 검증

Chromium에서 모든 본문 실험의 비교 예제, 슬라이더 양 끝, 선택 항목, 초기화와 핵심 버튼을 실행했습니다. 1440px 데스크톱과 390px 모바일의 36개 실험 캡처를 검토했고, 모바일 가로 넘침과 JavaScript 오류는 없었습니다. 밝은 테마는 대표 평가 화면에서 추가 확인했습니다.

실험확인한 기대 결과결과
1. 뉴런가중치 0에서 수평 출력, 입력·가중치 극단값통과
2. 활성화 함수ReLU(−2)=0, sigmoid(−2)=0.119통과
3. 직선 회귀w=2, b=1에서 MSE=0.038통과
4. 경사하강법작은 학습률 수렴, 큰 학습률 발산 및 계산 중단통과
5. 과적합혼합 비율 0.64의 검증 오차 <0.1, 비율 1의 훈련 오차 0·검증 오차 0.1237통과
6. BPE8번 병합 후 토큰 수 감소통과
7. 벡터 유사도45° 그림의 축척 일치, 90° 유사도 0통과
8. 어텐션Q=[0,0]에서 각 25%, 출력 3.5통과
9. 인과 마스크첫 행 [1,×,×,×,×], 선택 행 테두리 이동통과
10. 온도낮은 온도의 집중과 높은 온도의 분산통과
11. 확률 추출Top-k=1에서 동일 후보 100회, 관측 막대와 설정 초기화통과
12. 합성곱빈 입력 0, 중앙 픽셀 평균 필터 0.111, 키보드 포커스 유지통과
13. 보상평가 비중을 반대로 바꾸면 A·C 확률 교환통과
14. 양자화8 bit 오차가 2 bit보다 작음통과
15. 메모리문맥 길이 두 배 → KV 두 배통과
16. 근거 검색관련 문서 검색, 우주선 질문 답변 보류통과
17. 에이전트성공 종료, 반복 실패 시 1회 재시도 후 중단통과
18. 평가 지표12개 샘플 표시, 임계값 0/1, 정의 불가 정밀도 설명통과

홈은 입력 0·0.5·1, 실제 마우스 드래그, 키보드 Home/End, 비교 버튼, 화면 전환 및 재진입을 검증했습니다. 낮음·높음 출력은 입력 양 끝에서 99.7%와 0.3%로 반전합니다.

재현 방법

수치 단위 테스트 11개: npm test

브라우저 회귀 검사: 별도 테스트 환경에 Playwright와 Chromium을 설치하고 사이트를 8001 포트에서 연 뒤 node tests/browser.cjs를 실행합니다. AI_TARGET으로 배포 주소를, AI_CHROMIUM으로 브라우저 경로를 지정할 수 있습니다. 결과 JSON과 화면 캡처는 운영체제 임시 폴더에 저장됩니다.

검증 범위

계산과 UI 동작은 자동 검증하고 설명과 화면은 직접 검토했습니다. 실제 사용자의 이해도를 측정한 사용자 테스트는 아니며, 모든 모바일 기기·브라우저의 호환성을 보증하는 결과도 아닙니다. 실험은 각 화면에 적은 가정에 따른 교육용 모형입니다.
