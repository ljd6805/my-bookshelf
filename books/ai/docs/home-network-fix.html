홈 신경망 실험 수정

2026-10-07 · 사용자 피드백: 슬라이더를 움직여도 달라지는 것이 보이지 않는다.

원인과 수정 결정

기존 3·5·5·2 구조는 각 층의 계산을 연결하지 않고 입력값에 따라 점의 밝기를 바꾸는 그림이었다. 변화가 작고 출력 결과가 없어 LIVE VIEW라는 이름에 맞는 학습 경험을 제공하지 못했다. 회전 그림을 입력 1개·중간 뉴런 2개·출력 2개의 명시적인 순전파 실험으로 교체한다.

구현

고정 가중치로 h₁=sigmoid(8x−4), h₂=sigmoid(−8x+4)를 계산한다. 그 결과에서 두 로짓을 계산하고 softmax로 출력 확률을 구한다. 뉴런 내부 값, 선, 숫자 확률과 막대가 함께 갱신된다. 입력 0·0.5·1 버튼과 계산식 설명을 추가한다. 실제 모델을 학습하거나 정확도를 측정하는 실험은 아니다.

검증 기준

입력 0에서 높은 입력 출력은 약 0.31%, 0.5에서 50%, 1에서 약 99.69%가 되어야 한다. 중간 뉴런 값도 바뀌어야 하며, 버튼·키보드·슬라이더가 같은 결과를 내야 한다. 모바일에서도 숫자와 조작부가 잘리지 않아야 한다.

검증 결과

수치 단위 테스트 11개 통과. Chromium에서 마우스 드래그, Home/End 키, 입력 0·0.5·1 버튼, 화면 모드 전환, 챕터 이동 후 복귀를 검증했다. 입력 0과 1에서 출력 0.3%↔99.7% 변화 및 SVG 값 갱신을 확인했다. 390px 모바일 가로 넘침 없음, 실행 오류 0건.
