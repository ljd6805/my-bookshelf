검증 범위

수치 계산 테스트에는 softmax의 정규화와 큰 값 처리, top-p 경계 후보, 코사인 유사도, BPE의 문자열 복원, 합성곱, 양자화, 평가 지표, 보간 정확성과 경사하강 수렴을 포함했다. 실제 모델의 학습 성능·추론 속도나 장비 메모리는 측정하지 않았다.

문제 해결 기록

  • 차트의 x축 눈금이 안쪽 SVG에서 잘릴 수 있어 데이터 영역만 clipPath로 제한하도록 수정했다.
  • 좁은 목차에서 챕터 번호가 줄바꿈되지 않도록 번호 너비를 고정했다.
  • 검증 환경의 기본 Chromium 다운로드가 실패해 공식 npm 레지스트리의 Chromium 패키지로 전환했다. 애플리케이션에는 검증용 의존성을 추가하지 않았다.
  • 검증 환경에 한글 폰트가 없어 테스트 전용 Noto Sans KR을 주입해 화면을 확인했다. 실제 사이트는 시스템 한글 폰트를 사용한다.

배포 상태

2026-10-07: 비공개 저장소 ljd6805/ai-book-interactive의 main 브랜치로 GitHub Pages 배포를 완료했다. GitHub Actions의 수치 테스트와 Pages build/deploy가 모두 성공했다. 공개 주소에서 index.html, CSS, 전체 JavaScript 모듈, 문서 허브가 HTTP 200으로 제공되며 로컬 검증본과 바이트 단위로 일치함을 확인했다. AI Book 열기

완료한 배포 절차

  1. ljd6805 계정에 ai-book-interactive 저장소를 private로 생성한다.
  2. 검증한 전체 파일을 main 브랜치에 커밋한다.
  3. Settings → Pages에서 main / (root)를 배포 대상으로 설정한다.
  4. 배포 완료 후 실제 URL의 홈과 챕터·실험을 확인한다.

비공개 저장소의 Pages 지원 여부는 계정 요금제에 따라 다르다. 저장소를 공개로 전환하거나 유료 요금제에 가입하는 변경은 자동으로 수행하지 않는다.
