편집장 선정표(검토서 g1-core의 AI Book 제안 #2·#3·#4와 공통 전이 문항)에 따라 더했다. 장 ID·앵커·book-routes는 바꾸지 않았다.

  • 장마다 같은 블록 안에 세 칸: 실험 앞의 “먼저 예측하기”(predict), 실험 뒤·“혼동하지 마세요” 앞의 “해결한 것과 남은 질문”(remaining), 다음 장 링크 아래의 이동 이유(next, 마지막 장 제외). 블록 순서는 그대로다.
  • 숫자로 한 번 따라가기: 12개 장 모두 paragraphs에 실험 기본값과 같은 숫자로 손계산하는 문단을 더했다(예: neuron z=1·σ≈0.731, learning 최소제곱 해 1.96·1.02, inference 4 GB≈3.73 GiB와 KV 1 GiB).
  • 2장 역전파 절과 실험 backprop: 연쇄 법칙·죽은 ReLU·수치 미분 문단 두 개와 실험 하나(실제 계산, x=1·t=3 고정). 기준값 w₁=0.5, w₂=2에서 L=4, ∂L/∂w₁=−8, η=0.05 한 걸음 뒤 L=1.2321. 실험은 18개에서 19개가 되었다.
  • 전이 문항: 장마다 transfer 하나를 확인 문제 블록 안 “다른 상황에 써 보기”로 보인다. 장 머리는 “확인 문제 2개”.
  • 정답 자리 고르게: 보기는 화면에서만 돌린다(확인 문제는 장 번호 % 3, 전이 문항은 (장 번호+1) % 3번째 자리). data-answer·data-transfer는 원래 번호다(AIMath.choiceOrder).

검증 결과

  • npm test --prefix books/ai: 16/16 통과(역전파 손계산·수치 미분·죽은 ReLU, choiceOrder, 전이 문항 형식 검사 추가).
  • tests/browser.cjs(Chromium, 1440·390px): 19개 실험 예제·초기화·극값·넘침 통과, 페이지 오류 0건.
  • 별도 Chromium 확인(1280·320px): 12개 장 모두 블록 순서, 정답 자리, 전이 문항 오답·정답 피드백, 다음 장 이유, 가로 넘침 없음, 콘솔 오류 0건. backprop 예제 세 개·초기화·학습률 0.3에서 10걸음(넘친 뒤 죽은 ReLU로 L=9에서 멈춤)을 확인했다.
  • python3 scripts/validate.py 오류 0건, build_catalog.py --check 최신.

확인하지 못한 것

  • 새 문단과 전이 문항은 집필 세션이 계산을 다시 돌려 맞췄지만, 다른 세션의 팩트·출처 검수는 아직 받지 않았다.
  • 학습 효과(독자가 예측·전이 문항으로 실제로 더 잘 이해하는지)는 측정하지 않았다.
  • 새 외부 출처는 더하지 않았다. GB(10⁹ byte)와 GiB(2³⁰ byte)는 정의로만 썼다.

검증 범위

수치 계산 테스트에는 softmax의 정규화와 큰 값 처리, top-p 경계 후보, 코사인 유사도, BPE의 문자열 복원, 합성곱, 양자화, 평가 지표, 보간 정확성과 경사하강 수렴을 포함했다. 실제 모델의 학습 성능·추론 속도나 장비 메모리는 측정하지 않았다.

문제 해결 기록

  • 차트의 x축 눈금이 안쪽 SVG에서 잘릴 수 있어 데이터 영역만 clipPath로 제한하도록 수정했다.
  • 좁은 목차에서 챕터 번호가 줄바꿈되지 않도록 번호 너비를 고정했다.
  • 검증 환경의 기본 Chromium 다운로드가 실패해 공식 npm 레지스트리의 Chromium 패키지로 전환했다. 애플리케이션에는 검증용 의존성을 추가하지 않았다.
  • 검증 환경에 한글 폰트가 없어 테스트 전용 Noto Sans KR을 주입해 화면을 확인했다. 실제 사이트는 시스템 한글 폰트를 사용한다.

완료한 배포 절차
