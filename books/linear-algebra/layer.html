10장 · A neural network layer

신경망 한 층은 행렬 곱과 꺾기

9장까지의 도구는 모두 직선을 직선으로 보냈습니다. 그래서 “일정 수준을 넘으면 좋아하고, 아니면 관심 없다”는 판단은 만들지 못했습니다. 이 장에서는 행렬 곱에 덧셈 하나와 ‘0 아래는 자르기’ 하나를 더합니다. 그것이 신경망의 한 층입니다.

현재 문제
문턱을 넘으면 반응이 바뀌는, 직선적이지 않은 취향을 계산해야 합니다.
이전 결과
행렬의 행은 점수표(3·4장), 변환을 이으면 곱(5장), 납작해지면 정보를 잃음(6장)

남는 질문
특징이 하나 더 생기면 지금까지 만든 추천기의 무엇을 바꿔야 할까요?

점수표에 문턱 달기

4장에서 만든 두 점수표를 다시 씁니다. 첫째 행 (0.45, 0.89)는 내 취향 방향의 점수, 둘째 행 (0.89, −0.45)는 그와 직각인 “빠르지만 차분한” 정도의 점수입니다. 여기에 두 가지를 더합니다.

  • 편향 b: 점수에 일정한 값을 더해 문턱을 옮깁니다. b₁ = −2이면 취향 점수가 2를 넘어야 양수가 됩니다.
  • ReLU: 음수는 0으로 자르고 양수는 그대로 둡니다. “문턱 아래는 관심 없음”을 뜻합니다.

접으면 무엇이 같아질까

예측해 보기. b = (0, 0)에 ReLU를 켜면, 여덟 곡 중 몇 곡의 h₁(취향 신호)이 정확히 0이 될까요?

실험 10 · 노래를 은닉 공간으로 보내기

왼쪽은 원래 노래 공간입니다. 붉은 점선은 h₁ = 0, 보라 선은 h₂ = 0이 되는 경계선입니다. 오른쪽은 한 층을 지난 뒤의 공간(h₁, h₂)입니다. 편향을 옮기고 ReLU를 켜고 끄며 비교하세요. 실제 계산

b = (0, 0), ReLU를 켜면 h₁이 0인 노래는 4곡입니다.

W = [0.45, 0.89 ; 0.89, −0.45](고정), b₁·b₂는 −3~3. 표는 h₁이 큰 순서입니다. 이 W와 b는 학습한 값이 아니라 설명을 위해 직접 정한 값입니다. 실제 신경망은 데이터로부터 W와 b를 학습합니다.

무엇이 보였나

ReLU를 끄면 오른쪽 그림은 4장의 행렬 변환에 평행이동을 더한 것일 뿐입니다. 노래들이 돌고 밀려도 흩어진 모양은 그대로입니다. ReLU를 켜면 왼쪽 그림에서 붉은 점선 아래에 있던 새벽 산책, 비 오는 창가, 자장가, 골목 재즈의 h₁이 모두 0으로 접힙니다. 오른쪽 그림에서 이 곡들은 세로축 위에 붙어 섭니다.

이제 b₁을 −2로 내려 보세요. 경계선이 내 취향 방향으로 2만큼 물러나고, h₁이 0보다 큰 곡은 여름 축제(1.58), 옥상 록 공연(1.34), 아침 달리기(0.23)만 남습니다. “확실히 내 취향인 곡에만 신호를 보낸다”는 문턱이 생겼습니다.

설명: 직선 변환 + 꺾기

  1. W·x는 노래를 점수표들에 동시에 투영하고(3·4장), +b는 문턱을 옮기며, ReLU는 문턱 아래를 0으로 접습니다. 접는 단계가 있어야 “문턱을 넘으면 반응”이라는 판단이 생깁니다.
  2. x는 입력 노래, W는 가중치 행렬(행마다 점수표 하나), b는 편향, h는 은닉 벡터입니다.
  3. h = ReLU(W·x + b)    ReLU 없이 두 층을 쌓으면 W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)
  4. 여름 축제 x = (3, 2.5), b = (−2, 0)이면 W·x = (0.45 × 3 + 0.89 × 2.5, 0.89 × 3 − 0.45 × 2.5) = (3.58, 1.55), 편향을 더하면 (1.58, 1.55), ReLU 뒤에도 (1.58, 1.55)입니다. 골목 재즈 (−1, 0.5)는 W·x + b = (−2.01, −1.12)이므로 ReLU 뒤 (0, 0)입니다.

셋째 줄의 오른쪽 식이 이 장의 핵심입니다. 5장에서 변환을 이어 붙이면 행렬 하나가 된다는 것을 보았습니다. ReLU가 없으면 층을 백 개 쌓아도 결국 행렬 하나와 덧셈 하나로 줄어들어, 직선적인 판단밖에 못 합니다. ReLU가 층 사이마다 평면을 접어 주기 때문에 층을 쌓을수록 더 복잡한 경계를 만들 수 있습니다.

예측의 정답과 이유

4곡입니다. b₁ = 0이면 h₁은 3장의 취향 점수 그대로이고, 점수가 음수인 곡이 접힙니다. 새벽 산책(−1.56), 비 오는 창가(−2.91), 자장가(−3.58), 그리고 정확히 직각에 가까운 골목 재즈(−0.01)입니다. 출근 지하철은 +0.01로 아슬아슬하게 남습니다.

ReLU가 정보를 잃게 한다면, 6장의 ‘납작해짐’과 무엇이 다른가요?

행렬식 0인 행렬은 평면 전체를 한꺼번에 납작하게 만들어 모든 곳에서 같은 방향의 정보를 잃습니다. ReLU는 경계선 한쪽만 접고 다른 쪽은 그대로 둡니다. “관심 없는 노래끼리의 차이”는 버리고 “관심 있는 노래끼리의 차이”는 지키는, 장소에 따라 다른 선택적 손실입니다.

새 상황에 써 보기

“신나는 노래는 좋지만 너무 시끄러우면 싫다”는 취향은 어떻게 만들까요? 첫째 칸 h₁ = ReLU(에너지 − 0)과 둘째 칸 h₂ = ReLU(에너지 − 2.5)를 만든 뒤, 다음 층에서 h₁ − 3·h₂를 계산하면 됩니다. 에너지가 2.5를 넘는 순간부터 점수가 꺾여 내려갑니다. 직선 하나로는 그릴 수 없는 산 모양의 반응이 ReLU 두 개로 만들어집니다.

실제 신경망은 W와 b를 어떻게 정하나요?

처음에는 무작위 값으로 시작해, 정답과의 오차가 줄어드는 방향으로 W와 b를 조금씩 고칩니다(경사하강법). 그 방향을 계산할 때도 행렬 곱이 쓰입니다. 오차를 각 층의 W에 나누어 거꾸로 전달하는 계산이 W의 전치(행과 열을 바꾼 행렬)와의 곱이기 때문입니다. 이 책은 학습 과정을 다루지 않습니다. 학습은 AI Book의 2장과 3장에서 이어집니다.

남은 질문

노래를 벡터로 적는 것에서 시작해 닮음, 투영, 행렬 변환, 되돌리기, 고유벡터, 주성분, 그리고 신경망 한 층까지 왔습니다. 이제 추천기의 부품이 모두 갖춰졌습니다. 마지막으로 처음 보는 상황을 줍니다. 노래에 셋째 특징이 생긴 날, 지금까지 만든 추천기의 무엇을 그대로 두고 무엇을 고쳐야 할까요?
