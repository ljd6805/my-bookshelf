5장 · Composition

변환을 이어 붙이면 순서가 중요하다

4장에서 행렬 하나로 평면을 옮겼습니다. 실제 추천기는 여러 단계를 거칩니다. 먼저 단위를 맞추고, 그다음 점수표를 적용하는 식입니다. 이 장에서는 변환 두 개를 이어 붙이는 계산, 행렬의 곱을 만들고 순서를 바꾸면 무슨 일이 생기는지 직접 비교합니다.

현재 문제
변환을 여러 단계로 이어서 할 때 결과를 한 번에 계산하고 싶습니다.
이전 결과
행렬의 열이 e₁, e₂의 도착지라는 것, M·s를 계산하는 법을 압니다.
새 도구
행렬의 곱, 합성 변환, 교환법칙이 성립하지 않는 경우
이 장에서 해결할 것
여러 단계를 행렬 하나로 줄이는 법과, 단계의 순서를 지켜야 하는 이유
남는 질문
어떤 변환은 평면을 납작하게 만들었습니다. 그 정도를 숫자 하나로 잴 수 있을까요?

양말 먼저, 신발 나중

일상에서도 순서가 결과를 바꾸는 일은 흔합니다. 양말을 신고 신발을 신는 것과 신발을 신고 양말을 신는 것은 다릅니다. 평면의 변환도 그럴까요? 90° 회전과 가로 2배 늘이기를 생각해 봅시다. 둘 다 4장에서 만든 행렬입니다.

그림이 방향을 가진 모양이어야 차이가 잘 보이므로, 이 장에서는 노래 대신 깃발 하나를 옮깁니다. 깃대는 원점에서 위로 2칸, 깃발은 오른쪽을 향합니다. 나의 취향 화살표 (1, 2)도 함께 옮깁니다.

돌리고 늘이기, 늘이고 돌리기

예측해 보기. “90° 회전 → 가로 2배”와 “가로 2배 → 90° 회전”의 결과 깃발은 어떻게 다를까요?

실험 5 · 순서 바꿔 보기

첫째 변환과 둘째 변환을 고르면 왼쪽 그림은 그 순서대로, 오른쪽 그림은 반대 순서로 적용합니다. 회색 점선은 원래 깃발, 청록 점선은 첫 단계 뒤, 파란 면은 최종 결과입니다. 실제 계산

90° 회전 다음 가로 2배 = [0, −2 ; 1, 0], 가로 2배 다음 90° 회전 = [0, −1 ; 2, 0]. 순서를 바꾸면 결과가 달라집니다.

변환: 90° 회전 [0, −1 ; 1, 0], 가로 2배 [2, 0 ; 0, 1], 오른쪽으로 밀기 [1, 1 ; 0, 1], 가로축 뒤집기 [1, 0 ; 0, −1]. 같은 변환을 두 번 고를 수도 있습니다. 결과 판정은 네 칸이 모두 10⁻⁹ 이내로 같은지로 합니다.

무엇이 보였나

기본 조합에서 왼쪽(회전 → 늘이기)은 깃발이 누워 있고 깃대가 가로 방향이라 늘어난 것은 깃대입니다. 오른쪽(늘이기 → 회전)은 깃발이 먼저 가로로 늘어났다가 돌아가므로 길어진 것은 깃발입니다. 나의 취향 (1, 2)도 왼쪽에서는 (−4, 1), 오른쪽에서는 (−2, 2)에 도착합니다.

모든 조합이 다른 것은 아닙니다. 회전을 두 번, 늘이기와 뒤집기처럼 축 방향을 따로 다루는 변환끼리는 순서를 바꿔도 같습니다. 반면 회전과 뒤집기, 밀기와 늘이기는 순서에 따라 결과가 갈립니다.

설명: 행렬의 곱은 “열마다 다시 적용하기”

  1. A를 먼저 하면 e₁은 A의 첫째 열로 갑니다. 그다음 B를 하면 그 화살표가 다시 B로 옮겨집니다. 그러니 합성 변환의 첫째 열은 “B·(A의 첫째 열)”입니다. 둘째 열도 같습니다.
  2. A는 먼저 하는 변환, B는 나중에 하는 변환, B·A는 둘을 이어 붙인 변환입니다.
  3. (B·A)·s = B·(A·s)    B·A의 i행 j열 = (B의 i행) · (A의 j열)
  4. A = 90° 회전 [0, −1 ; 1, 0], B = 가로 2배 [2, 0 ; 0, 1]이면 B·A의 첫째 열은 B·(0, 1) = (0, 1), 둘째 열은 B·(−1, 0) = (−2, 0)이므로 B·A = [0, −2 ; 1, 0]입니다. 반대로 A·B = [0, −1 ; 2, 0]입니다. 나 (1, 2)에 적용하면 각각 (−4, 1)과 (−2, 2)입니다.

숫자의 곱셈은 2 × 3 = 3 × 2이지만, 행렬의 곱셈은 일반적으로 B·A ≠ A·B입니다. 두 행렬이 같은 순서로 ‘축을 따로 다루는’ 경우처럼 특별한 때만 같아집니다.

예측의 정답과 이유

한쪽은 깃대가, 한쪽은 깃발이 길어집니다. 가로 2배는 “지금 가로 방향에 있는 것”을 늘립니다. 회전을 먼저 하면 깃대가 가로로 누운 뒤 늘어나고, 늘이기를 먼저 하면 원래 가로 방향이던 깃발이 늘어난 뒤 돌아갑니다. 같은 동작이라도 그때 무엇이 가로에 있느냐가 다릅니다.

90° 회전을 네 번 하면 어떤 행렬이 될까요?

항등행렬 [1, 0 ; 0, 1]입니다. 실험에서 첫째와 둘째를 모두 90° 회전으로 고르면 180° 회전 [−1, 0 ; 0, −1]이 나오고, 그것을 두 번 하면 제자리입니다. 회전끼리는 순서를 바꿔도 결과가 같다는 것도 확인할 수 있습니다.

새 상황에 써 보기

추천기에서 “단위를 맞추는 단계 S”와 “점수표 W”를 이어 붙이면 W·S라는 행렬 하나로 줄일 수 있습니다. 노래가 백만 곡이면 두 번 곱하는 대신 미리 W·S를 계산해 한 번만 곱하면 됩니다. 단, S를 먼저 해야 한다는 순서를 지켜 W·S로 곱해야 하고, S·W로 바꾸면 다른 추천기가 됩니다. 10장에서는 이 성질 때문에 신경망이 행렬만 겹쳐서는 안 되는 이유를 봅니다.

오늘 꼭 해 볼 실험 하나 첫째를 ‘오른쪽으로 밀기’, 둘째를 ‘가로축 뒤집기’로 골라 보세요. 한쪽 깃발은 오른쪽 아래로, 다른 쪽은 왼쪽 아래로 기울어집니다. 같은 두 동작이 정반대 기울기를 만드는 장면입니다.
순서를 바꿔도 결과가 같은 변환은 어떤 것들인가요?

원점을 중심으로 한 회전끼리, 그리고 가로·세로를 따로 늘이거나 뒤집는 대각행렬끼리는 언제나 순서를 바꿔도 같습니다. 일반적으로 두 행렬이 “같은 방향들을 늘이기만 하는” 관계일 때 교환이 됩니다. 이 ‘늘이기만 하는 방향’이 8장의 고유벡터입니다.

남은 질문

순서에 따라 깃발이 길어지기도, 뒤집히기도 했습니다. 그런데 4장의 ‘한 직선으로 납작하게’ 예시처럼 깃발이 아예 선이 되어 버리는 변환도 있었습니다. 변환이 넓이를 얼마나 늘리고 줄이는지, 뒤집는지, 납작하게 만드는지를 숫자 하나로 알아낼 수는 없을까요?
