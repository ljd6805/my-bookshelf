7장 · Inverse & linear systems

기록에서 원래 노래 되찾기

6장에서 행렬식이 0이면 정보가 사라진다는 것을 보았습니다. 이번에는 반대 방향입니다. 추천기의 기록에는 변환된 점수 두 개만 남아 있습니다. 변환 규칙은 알고 있으니, 기록에서 원래 노래의 빠르기와 에너지를 되찾아 봅시다.

현재 문제
점수 b만 남았을 때 M·x = b를 만족하는 원래 노래 x를 찾아야 합니다.
이전 결과
det M = 0이면 평면이 납작해져 서로 다른 노래가 같은 결과가 됩니다.
새 도구
역행렬 M⁻¹, 연립일차방정식, 두 직선의 교점, 해의 민감도
이 장에서 해결할 것
기록에서 노래를 되찾는 계산과, 되찾은 답을 믿어도 되는 조건
남는 질문
어떤 변환은 특정 방향을 돌리지 않고 늘이기만 합니다. 그런 방향을 찾으면 무엇이 쉬워질까요?

점수 두 개, 미지수 두 개

기록 규칙은 M = [2, 1 ; 1, 1.5]입니다. 첫째 점수는 “빠르기 2배 + 에너지”, 둘째 점수는 “빠르기 + 에너지 1.5배”입니다. 어떤 노래의 기록이 b = (5.5, 4.25)로 남았습니다. 빠르기를 x, 에너지를 y라고 하면 다음 두 식을 동시에 만족해야 합니다.

2x + y = 5.5     x + 1.5y = 4.25

식 하나는 평면 위의 직선 하나입니다. 첫째 식을 만족하는 (x, y)는 무수히 많지만 모두 한 직선 위에 있습니다. 두 식을 모두 만족하는 점은 두 직선이 만나는 곳입니다.

규칙이 거의 납작하면

예측해 보기. 규칙의 d를 1.5에서 0.6으로 바꾸면(det 2 → 0.2), 같은 기록 b = (5.5, 4.25)에서 되찾은 노래는 어떻게 될까요?

실험 7 · 기록에서 노래 되찾기

기록된 점수 b₁, b₂와 규칙의 d를 바꿔 보세요. 붉은 점선은 식 ①, 보라 실선은 식 ②의 직선입니다. 보라 점이 되찾은 노래입니다. 실제 계산

5.50
4.25
1.50

d = 1.5, b = (5.5, 4.25)이면 det M = 2이고 x = (2, 1.5), 아침 달리기입니다.

M = [2, 1 ; 1, d]. b₁, b₂는 −6~6(0.25 간격), d는 0~2(0.05 간격). |det M| < 0.02이면 하나의 답을 정할 수 없다고 판단해 해를 표시하지 않습니다. 되찾은 노래가 그림 범위(−4~4) 밖이면 점은 보이지 않고 숫자만 나옵니다.

무엇이 보였나

처음 값에서 두 직선은 (2, 1.5)에서 만나고, 그 자리에 아침 달리기가 있습니다. 기록에서 노래를 정확히 되찾았습니다. b₂를 4.25에서 4.5로 한 칸 올리면 답은 (1.88, 1.75)로 조금 움직입니다.

이제 d를 줄여 보세요. 보라 직선이 점점 주황 직선과 나란해지고, 교점이 빠르게 멀어집니다. d = 0.6에서는 같은 기록의 답이 (−4.75, 15)로 그림 밖까지 날아가고, 여기서 b₂를 한 칸(0.25)만 바꿔도 답이 (−6, 17.5)로 크게 움직입니다. d = 0.5에서는 두 직선이 평행해져 답이 하나로 정해지지 않습니다.

설명: 역행렬은 변환을 거꾸로 돌리는 행렬

  1. M이 평면을 납작하게 만들지 않았다면, 옮겨진 격자를 원래대로 펴는 변환이 있습니다. 그 변환의 행렬이 역행렬 M⁻¹이고, 기록에 곱하면 원래 노래가 나옵니다.
  2. M = [a, b ; c, d]는 기록 규칙, b는 기록된 점수, x는 되찾을 노래, M⁻¹은 역행렬입니다.
  3. M⁻¹ = (1 / det M) · [d, −b ; −c, a]    x = M⁻¹·b    M⁻¹·M = 항등행렬
  4. M = [2, 1 ; 1, 1.5]이면 det M = 3 − 1 = 2, M⁻¹ = ½·[1.5, −1 ; −1, 2] = [0.75, −0.5 ; −0.5, 1]입니다. x = (0.75 × 5.5 − 0.5 × 4.25, −0.5 × 5.5 + 1 × 4.25) = (2, 1.5)입니다.

역행렬 공식에 1/det M이 들어 있다는 점이 핵심입니다. 행렬식이 0이면 나눌 수 없어 역행렬이 없고, 0에 가까우면 아주 큰 수로 곱하게 되어 기록의 작은 오차가 답에서 크게 부풀려집니다.

예측의 정답과 이유

평면 밖으로 멀리 날아갑니다. 답이 사라지는 것은 det M이 정확히 0일 때뿐입니다. 0.2처럼 작지만 0이 아니면 답은 존재하지만 1/0.2 = 5배로 부풀려진 값이 되어, 원래 노래 범위(−3~3)를 크게 벗어난 (−4.75, 15)가 나옵니다. 계산은 틀리지 않았지만, 이 규칙으로 남긴 기록은 되찾기에 믿을 만하지 않습니다.

5장의 90° 회전을 되돌리는 역행렬은?

−90° 회전 [0, 1 ; −1, 0]입니다. 공식으로 계산해도 det = 1이고 [0, 1 ; −1, 0]이 나옵니다. 회전은 넓이를 바꾸지 않으므로 되돌려도 오차가 부풀지 않습니다.

새 상황에 써 보기

GPS 수신기는 위성 여러 개까지의 거리로 위치를 계산하는데, 위성들이 하늘 한쪽에 몰려 있으면 위치 오차가 커집니다. 직선들이 거의 나란하게 만나는 실험 7의 상황과 같습니다. 추천기에서도 같은 교훈이 나옵니다. 기록을 남길 점수표 두 장은 서로 충분히 다른 방향이어야 나중에 노래를 되찾을 수 있습니다. 6장의 행렬식이 그 확인 수단입니다.

오늘 꼭 해 볼 실험 하나 d를 1.5와 0.6에 각각 두고 b₂를 4.25 ↔ 4.5로 바꿔 보세요. 같은 0.25의 기록 오차가 답을 얼마나 움직이는지 비교하면, ‘풀 수 있다’와 ‘믿을 수 있다’가 다른 말이라는 것이 보입니다.
식이 미지수보다 많으면 어떻게 하나요?

점수표가 세 장인데 특징은 두 개라면, 세 직선이 한 점에서 만나지 않는 경우가 많습니다. 그때는 모든 식을 정확히 만족하는 대신 오차의 제곱합이 가장 작은 답을 고릅니다. 이것을 최소제곱법이라 하고, 3장의 투영으로 풀 수 있습니다. 기록 b를 “M의 열들이 만들 수 있는 공간” 위로 투영한 뒤 그 점을 되찾는 것입니다. AI Book의 직선 맞추기 실험이 바로 이 문제를 손으로 푸는 실험입니다.

남은 질문

변환을 되돌리는 법과 그 위험을 알았습니다. 그런데 변환을 하나 하나 분석할 때마다 네 숫자를 계속 따지는 것은 번거롭습니다. 4장의 ‘가로 2배, 세로 절반’은 가로 방향과 세로 방향을 각각 늘이기만 해서 이해하기 쉬웠습니다. 다른 행렬에도 이렇게 “돌리지 않고 늘이기만 하는” 특별한 방향이 숨어 있을까요?
