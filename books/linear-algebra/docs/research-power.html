8장 eigen에 더한 실험 power “같은 변환을 여러 번”(실험 8-2)이 기대는 사실과 숫자를 모았습니다. 집필·실험·검수가 같은 숫자를 보도록 만든 노트이며, 독자가 읽는 본문은 js/content.js와 js/lab-views.js에 있습니다. 문장과 그림은 참고 자료의 구조만 참고했고 내용은 새로 썼습니다.

식

  • v = c₁u₁ + c₂u₂ (u₁, u₂는 고유벡터)이면 Mⁿv = c₁λ₁ⁿu₁ + c₂λ₂ⁿu₂ = λ₁ⁿ(c₁u₁ + c₂(λ₂/λ₁)ⁿu₂).
  • [2, 1 ; 1, 2]에서 (1, 0) = ½(1, 1) + ½(1, −1)이므로 Mⁿ(1, 0) = ½(3ⁿ + 1, 3ⁿ − 1). 테스트 불변 조건과 같습니다.
  • 둘째 성분이 처음 비율의 1% 아래로 줄어드는 횟수: n ≥ ln 0.01 / ln|λ₂/λ₁|.
  • [2.95, 0.05 ; 0.05, 2.95]에서 (1, 0)으로 시작한 방향 각도의 닫힌 식: atan((1 − rⁿ)/(1 + rⁿ)), r = 2.9/3.
  • 실험 표의 배율: |Mᵏv| / |Mᵏ⁻¹v|. 돈 각도: 앞 단계 방향과의 차이를 (−180°, 180°]로 맞춘 값.

가정·단위·유효 범위

  • 시작 벡터 v₁, v₂는 −3~3(0.5 간격)의 단위 없는 점수입니다. n은 0~30번입니다.
  • 정규화하지 않고 실제로 곱합니다. n = 30이면 성분이 약 2×10¹⁴에 이르지만 배정밀도 범위 안이라 오차는 표시 자리수에 나타나지 않습니다.
  • ‘자리를 잡았다’는 판정은 가장 큰 |λ|의 고유벡터 직선에서 0.5° 안입니다. 이 문턱은 설명용으로 정한 값이며 수학적 정의가 아닙니다.
  • 행렬은 세 가지로 고정했습니다. 가장 큰 |λ|가 둘인 경우(예: λ = 3, −3)는 실험에 넣지 않았고 본문에서도 다루지 않습니다.

실제 계산 · 미리 정한 시나리오 · 시각적 비유

  • 실제 계산. 표와 결과 문장의 모든 숫자는 js/linalg.js의 powerSteps와 eigen2가 입력마다 계산합니다.
  • 미리 정한 시나리오. 없습니다. 예제 버튼은 입력값을 채울 뿐입니다.
  • 시각적 비유·연출. 그림의 화살표 길이는 모두 2.2로 맞춘 것이라 실제 길이가 아닙니다. ‘n을 0부터 30까지 늘리기’ 재생은 계산 결과 사이를 이어 보이는 연출입니다. 과제 문장의 “처음 어떤 취향이었는지는 흐려진다”는 방향에 대한 사실을 쉽게 풀어 쓴 표현입니다.

예상되는 오해

  • “고윳값이 크면 빨리 수렴한다.” 빠르기를 정하는 것은 크기가 아니라 비율 λ₂/λ₁입니다. 확인 문제의 오답 보기로 겨냥합니다.
  • “어떤 시작 벡터든 반드시 끌려간다.” 큰 쪽 성분이 0이면 움직이지 않습니다((1, −1) 예제).
  • “오래 곱하면 언젠가 멈춘다.” 실수 고유벡터가 없으면(회전) 멈추지 않습니다.
  • “계산 오차 때문에 느려진다.” 느린 수렴은 오차가 아니라 비율 때문입니다(확인 문제 첫 보기).
