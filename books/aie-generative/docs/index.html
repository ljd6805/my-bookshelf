생성 모델 · 제작 문서

「AI 엔지니어링 처음부터」 시리즈 09권 《생성 모델 · 오토인코더에서 디퓨전과 플로까지》의 기획, 원본 레슨 대응, 구현, 검증을 한곳에 모았습니다. 작성일은 2026-10-08입니다. 원본은 rohitg00/ai-engineering-from-scratch(MIT)의 Phase 8 · Generative AI입니다. 원문과 코드는 옮기지 않았고, 개념과 순서만 참고해 새로 썼습니다.

1. 기획

  • 독자: 신경망 학습과 트랜스포머의 기본(앞 권)은 알지만, 그림을 “만드는” 모델이 왜 흐려지거나 한 가지만 그리거나 느려지는지 설명해 본 적은 없는 사람입니다.
  • 끝의 행동: 생성기에 들어온 이상 보고 한 줄(흐림, 다양성 손실, 느림, 의심스러운 점수 향상)을 읽고, 원인을 겨냥한 손잡이 하나와 더 필요한 증거를 고를 수 있습니다.
  • 공통 사례: 그림책 작업실의 여우 캐릭터 “도토리” 그림 2,000장입니다. 그림을 특징값 하나로 줄이면 낮 장면 N(−2, 0.5²)과 밤 장면 N(+2, 0.5²)이 반반인 두 봉우리 분포가 됩니다. 모든 장의 실험이 같은 분포에 다른 생성기를 써 보게 하므로, 모델 사이의 차이가 데이터 차이와 섞이지 않습니다.
  • 이야기 방식: 하나의 제품을 완성합니다. 장마다 생성기를 한 단계씩 바꾸고(밀도 추정 → VAE → GAN → 조건 → 디퓨전 → 잠재 디퓨전 → 제어 → 다른 매체 → 플로 → VAR), 앞 장에서 남은 문제(흐림, 모드 붕괴, 느림)가 새 도구로 어떻게 풀리는지 확인합니다. 11장에서는 그 개선을 숫자로 믿을 수 있는지 따지고, 마지막 장에서는 새 실패 보고에 이 손잡이들을 씁니다.
  • 범위: 원본 Phase 8의 레슨 15개 전부(01~14, 19)를 다룹니다. 우도·분산·구간 추정은 확률과 통계 책에, 주성분·벡터·행렬 합성은 선형대수 책에, 어텐션과 토큰은 AI Book에, 가중치 메모리와 병목은 LLM 시스템 책에 맡기고 링크로 보냅니다. 이 책은 생성기를 고르고 조정하는 공학적 판단에 분량을 씁니다.
  • 증거: 실험 16개 중 14개는 브라우저에서 실제로 계산합니다. 커널 밀도, β-VAE 닫힌 해, GAN 축소 모형, 정확한 잡음 예측기로 돌린 DDIM과 가이던스, LoRA 매개변수 수, SDEdit 유지 확률, 비디오 토큰 수, 정확한 주변 속도장의 플로 매칭, VAR 잔차 척도, 2차원 FID가 여기에 속합니다. 비디오 압축 비율과 VAR 밝기 줄은 교육용 가정값이고, 마지막 장의 판정은 미리 정한 시나리오입니다. 어느 쪽인지는 각 실험의 결과 문장에 적었습니다. 모델 이름과 연도는 원본 커리큘럼 기준(확인일 2026-10-08)입니다.

부 구성: 생성의 지도(1~2장) · 압축과 적대(3~4장) · 디퓨전(5~8장) · 더 빠르게(9~10장) · 믿을 만하게(11~12장).

3. 구현

  • 파일 구성은 다음과 같습니다. js/math.js(순수 계산), js/content.js(모든 글과 출처 50개), js/visual.js(공통 UI에 분포 막대 hist와 산점도 scatter 추가), js/figures.js(장마다 움직이는 개념 그림 12개), js/labs-shape.js·labs-diffusion.js·labs-speed.js(실험 16개), js/home-lab.js(표지 대표 실험: 순방향 디퓨전 단계 t와 두 봉우리 밀도), js/lab-guides.js, js/app.js.
  • 전역 접두어는 A09, 서가 삽화 접두어는 a09-ill-, 진도 키는 bookshelf:aie-09-generative:v1:progress입니다.
  • 계산 모형은 두 가우스 혼합 하나에 모았습니다. 혼합의 점수는 닫힌 식이므로 최적 잡음 예측기 ε* = −√(1−ᾱ)·∇log p를 신경망 없이 정확히 계산합니다. DDIM, 가이던스(조건부 = 밤 장면, 무조건부 = 혼합), 플로 매칭의 주변 속도장 E[x₁ − x₀ | x_t]도 같은 방식으로 정확히 구합니다. 따라서 실험에서 보이는 흐림이나 과포화는 학습 오차가 아니라 샘플러 자체의 성질입니다. 이 가정은 결과 문장에 밝혔습니다.
  • β-VAE는 선형 가우스 VAE의 닫힌 해를 씁니다. 축 분산 λ가 β/2보다 클 때만 그 축을 쓰고, 재구성 오차는 β/2, KL은 ½ln(2λ/β)입니다. GAN은 생성자 비율 하나와 로지스틱 판별자 두 수로 된 축소 모형입니다.
  • 강조색은 라벤더입니다(어두운 화면 #c9b6ff, 밝은 화면 #5b3fb0). 밝은 화면의 주 버튼 글자는 흰색으로 바꿔 대비를 지켰습니다.
  • 서가 삽화 assets/shelf-illustration.svg에서는 흩어진 노이즈 점들이 낮·밤 두 봉우리로 모이고 봉우리가 솟아오릅니다(시각적 비유). 동작 줄이기 두 규칙에서는 멈춥니다. 표지 그림 assets/cover-art.svg는 노이즈 상자에서 두 봉우리로 갈라지는 정지 그림이며 cv-* 클래스만 씁니다.
  • 나가는 링크는 다음과 같습니다. 1장 → 확률과 통계 #likelihood·AI Book #generation, 2장 → 선형대수 #pca·확률과 통계 #spread, 3장 → AI Book #learning, 4장 → AI Book #vision, 5장 → 확률과 통계 #spread, 6장 → AI Book #attention·LLM 시스템 #weights, 7장 → 선형대수 #matrix·#compose, 8장 → AI Book #tokens·LLM 시스템 #bottleneck, 9장 → 선형대수 #vectors, 10장 → AI Book #generation, 11장 → 확률과 통계 #interval·선형대수 #similarity, 12장 → 확률과 통계 #testing. 서재 등록 제안은 registration.json에 있습니다.

4. 검증

검증일은 2026-10-08입니다. 실제 생성 모델을 학습하거나 GPU에서 측정한 검증은 아닙니다.

  • 계산 검사: npm test --prefix books/aie-generative를 통과했습니다. 계산 함수마다 대표값·경계값·불변 조건을 확인합니다. 예를 들어 1단계 DDIM은 모두 흐린 중간에 떨어지고 20단계는 95% 이상이 장면에 닿는지, β = 2λ에서 재구성과 KL이 연속인지, 신호² + 잡음² = 1인지, 재흐름 경로는 1단계 오차가 0인지, 같은 분포의 FID는 0이고 대칭인지, 10초 1080p 패치 2의 토큰이 489,600개인지 확인합니다.
  • 브라우저 검사: tests/browser.cjs로 1280·390·320px에서 표지와 12장을 열었습니다. 실험 16개마다 예제 버튼, 입력 최솟값과 최댓값, 선택 상자의 모든 값, 초기화를 눌러 결과 문장에 NaN·undefined가 없는지 봤습니다. 확인 문제의 정답·오답 반응, 가로 넘침, 서가로 버튼, 목차 열고 닫기, 콘솔 오류도 확인했습니다.
  • 팩트·출처 검수: 집필하지 않은 에이전트가 사실·수치·실험·용어·출처를 검수하고 팩트·출처 검수 기록에 남겼습니다(2026-10-08, 결과 fixed).
  • 눈으로 확인: 표지, 개념 그림, 320px 실험 스크린숏을 열어 글자 겹침과 잘림을 봤습니다.
  • 확인하지 못한 것: 실제 독자의 학습 효과(L4)는 측정하지 않았습니다. 모델 이름과 연도는 원본 커리큘럼 기준이며, 집필하지 않은 검수 에이전트가 논문·공식 자료와 대조한 결과는 팩트·출처 검수 기록에 있습니다. 서가에서 삽화가 움직이는지는 서재 등록 뒤에 확인해야 합니다.
