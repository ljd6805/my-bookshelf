# 생성 모델 · 오토인코더에서 디퓨전과 플로까지

「AI 엔지니어링 처음부터」 시리즈 09권입니다. 원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 8 레슨 15개를 한국어로 새로 써서 12장 16개 실험의 인터랙티브 책으로 만들었습니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765`를 띄운 뒤 `http://127.0.0.1:8765/books/aie-generative/`를 엽니다.
- 계산 검사: `npm test --prefix books/aie-generative`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-generative/ node books/aie-generative/tests/browser.cjs`
- 작업 규칙은 [AGENTS.md](AGENTS.md)에, 제작 문서는 [docs/index.html](docs/index.html)에 있습니다.
