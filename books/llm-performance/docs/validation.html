화면 검토와 수정

이미지로 검토해 어두운 표지 차트 글자색을 고쳤습니다. 모바일 개념 그림의 불필요한 520px 최소 폭을 제거해 전체 관계가 한 화면에 들어가도록 했습니다. occupancy 막대에는 100% 기준 막대를 함께 두어 자동 축척이 비율을 오해하게 하지 않도록 했습니다.

서가 세 폭에서 새 책을 펼쳐 지식 노선·공통 개념 연결·본문 왕복을 확인했습니다. 펼침 삽화에서 실행 중 CSS 애니메이션 4개를 관찰하고, 두 프레임에서 측정선 위치가 바뀜을 눈으로 확인했습니다. 사용자 설정과 prefers-reduced-motion에서 0개로 멈춥니다.

최신 표지 규칙을 반영한 뒤 서가 열기 애니메이션의 1,150 ms 프레임을 잠시 정지해 닫힌 표지의 제목과 삽화를 세 폭에서 확인했습니다. 이는 화면 검사용이며 제품의 애니메이션 시간은 바꾸지 않았습니다.

실행 환경의 한계

제작 환경에는 PyTorch·CUDA Toolkit·NVIDIA GPU가 없습니다. Python 구문과 통계 helper는 검사하지만 torch.mm CPU/GPU 실행, CUDA 컴파일·커널 실행, Nsight 기록은 이 환경에서 확인하지 못합니다. 실행 예제의 예상 출력은 관측 로그와 구분합니다.

실제 오픈웨이트 모델 성능과 품질, Safari·Firefox·실기기·화면 낭독기, 독자의 학습 효과(L4)는 검증하지 않았습니다. Chromium의 반응형 검사는 실제 모바일 기기 검사가 아닙니다.
