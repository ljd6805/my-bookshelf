구현과 계산의 경계

공통 기준 적용

AI Book의 정적 HTML 뼈대에서 시작했습니다. 같은 표준을 따르는 시스템 이해편의 반응형 차트·본문 보완을 책 안으로 복사하고 독립된 P 접두어로 구현했습니다. 공통 type.css 외에는 다른 책의 런타임을 가져오지 않습니다. 장의 일곱 블록, 표지의 다섯 구역, 머리말 메뉴 순서, 두 테마와 320px 서가 복귀를 유지합니다.

첫 장을 구현한 뒤 같은 사례의 3장까지 완성해 실제 브라우저에서 예제·직접 결과·초기화를 점검하고 12장으로 확장했습니다. 본문·계산·UI·실험·안내·라우터·그림을 별도 파일로 분리했습니다. 대표 삽화는 측정선과 빈 구간 강조가 움직이며 사용자 동작 줄이기와 운영체제 설정에서 멈춥니다.

공통 사례

2,048토큰 회의록을 32토큰으로 요약하는 교육용 요청에서 시작합니다. 커널·KV·배치 장에서는 그 시스템의 부분 문제를 따로 계산하며, 각 실험에서 달리 둔 입력 길이와 작업 범위를 표시합니다. 여러 장의 수치를 하나의 실제 모델 실측처럼 합산하지 않습니다.

계산 모형

실험종류와 핵심 가정
metrics, timing, pipeline일정한 토큰 간격·제출·연산 비용의 산술과 의존성 스케줄. 파이프라인 엔진 간 경합 제외.
mapping, sectors실제 인덱스와 서로 다른 32 byte sector 계산. DRAM 캐시 적중·물리 실행 시간 제외.
occupancy명시한 가상 SM의 자원 상한. register 할당 단위·spill·실제 GPU 성능 제외.
roofline동일 구간의 입력량으로 산술 집약도·처리율 계산. 500 GB/s·50 TFLOP/s 가상 상한.
fusion, attention실제 원소별 출력과 단순 접근량. 어텐션은 score·행 상태 항목만 계산.
paging요청별 올림 할당. Qwen3-8B FP16 KV 144 KiB/token으로 환산. 메타데이터·공유·정렬 제외.

parallel직렬2 ms·이상 분할16/n ms·ring64회, 단계 지연5 μs. 실제 NCCL 선택·겹침 제외.
decision미리 만든 4개 후보 집계값에 대한 조건 판정. 실측이나 특정 제품 벤치마크 아님.

출처와 재현

16개 공식 문서·원 논문을 2026-10-08에 확인했습니다. 본문 장별 출처와 표지의 전체 목록에서 연결합니다. PyTorch stable 문서는 확인 시 2.14 경로로 연결되어 해당 버전 URL을 기록했습니다. 공식 자료의 예제 코드를 복제하지 않고 교육 목적에 맞게 작은 실행 예제를 새로 작성했습니다.

PyTorch 예제는 입력 생성·전송을 제외한 torch.mm을 워밍업 뒤 반복 측정하며 profiler 기록은 별도 실행입니다. CUDA 예제는 scalar bias+ReLU에 경계 검사와 CPU 정답 비교를 포함합니다. 전체 LLM 실행은 하지 않습니다. 실제 모델 실험용 빈 JSON 양식을 제공합니다.

닫힌 표지

제작 중 갱신된 main의 표지 규칙을 반영했습니다. cover-art.svg는 320×150 정지 선화이며 GPU 안 스레드·메모리와 측정 시계를 연결합니다. 공통 cv-* 클래스만 쓰고, 움직이는 펼침 삽화와 별도 그림을 사용합니다. cover_meta는 12장 · 13개 실험입니다.

서가 연결

인공지능 묶음의 끝에 rose 색 “추론 최적화”를 등록했습니다. 12개 장 색인, 메모리·평가·어텐션 개념, “모델은 돌아가는데 왜 느릴까” 노선을 추가했습니다. 시스템 이해편 마지막 장과 새 책이 양방향으로 이어집니다. 새 노선의 과제는 각 장의 실제 조작과 맞췄습니다.

동시 작업 통합

원격의 RAG 도서·표지·노선·개념·CI를 보존했습니다. 7권의 배치에서 일부 개념이 기존 탐색 반경 밖의 빈 공간을 찾지 못해 atlas_renderer.py의 결정적 나선 탐색을 4,000회에서 20,000회로 넓혔습니다. 기존 경계와 겹침 판정을 유지합니다. 같은 색의 RAG 책은 다른 분류 묶음에 있어 이웃하지 않습니다.
