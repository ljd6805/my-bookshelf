본문으로 돌아가기

내 장비에서 측정으로 이어가기

본문의 모형을 실제 프로그램과 연결하는 두 예제입니다. 전체 LLM을 내려받거나 실행하지 않습니다. CUDA 장비가 없으면 PyTorch 예제의 CPU 경로와 본문 실험을 사용할 수 있습니다.

1. PyTorch에서 완료 시간 재기

profile_matmul.py 내려받기. Python 3과 PyTorch가 필요합니다. 설치 명령은 운영체제·드라이버에 맞춰 공식 설치 안내에서 고르세요. 아래 명령은 예제 파일이 있는 디렉터리에서 실행합니다.

python3 profile_matmul.py --device cpu --n 256 --batch 1 --repeats 20
python3 profile_matmul.py --device cuda --n 4096 --batch 1 --repeats 30 --output decode-shape.json
python3 profile_matmul.py --device cuda --n 4096 --batch 128 --repeats 30 --output wider-shape.json

X[M,N]과 W[N,N]의 float32 행렬곱입니다. batch 인수는 M행 수이며 실제 LLM의 동시 요청 수를 그대로 구현하지 않습니다. 작은 M과 큰 M의 shape를 비교하는 출발점입니다. 자동회귀 생성·KV 캐시·모델 가중치는 없습니다.

입력 생성·전송과 CPU 기준값 계산은 측정 밖입니다. 워밍업 후 반복마다 GPU 완료를 기다리고 CPU wall time과 CUDA event time을 따로 남깁니다. 두 event는 같은 current stream에 기록합니다. 이처럼 매 반복 동기화한 결과를 동시 요청이 겹치는 서비스 처리량과 비교하지 마세요. wall에는 event 제출·대기와 Python 비용도 포함됩니다.

실행 결과에는 환경, shape, 모든 표본, 중앙값·nearest-rank p95, float64 CPU 기준과의 오차가 남습니다. 20개 표본의 p95는 정렬한 값 중 19번째이므로 큰 모집단의 꼬리를 안정적으로 추정한 값이라고 볼 수 없습니다. 다른 프로세스의 GPU 사용, 전력·온도·클럭도 함께 기록하세요.

2. 같은 구간의 trace 확인

python3 profile_matmul.py --device cuda --n 2048 --batch 32 --trace matmul-trace.json --output measured.json

먼저 profiler 없이 타이밍을 수집한 뒤, 별도의 한 번을 프로파일링합니다. Chrome trace 형식 파일에서 book_matmul_XW 구간과 실제 CUDA 커널을 찾아 연결합니다. 결과 표와 trace가 서로 다른 실행이라는 점을 기억하세요. Nsight Systems에서는 CUDA 호출·복사·GPU timeline을, Nsight Compute에서는 관심 커널의 메모리와 자원 지표를 더 살펴볼 수 있습니다. 도구 옵션과 권한은 설치된 버전의 공식 문서를 확인합니다.

3. 배열 경계를 지키는 CUDA 커널

bias_relu.cu 내려받기. NVIDIA GPU와 해당 장비를 지원하는 CUDA Toolkit·드라이버, C++ 컴파일러가 필요합니다. CUDA Toolkit이 설치된 터미널에서 실행합니다.

nvcc -O2 bias_relu.cu -o bias_relu
./bias_relu

예상되는 정답 검사 결과는 N=100, blocks=2, out-of-range threads=28, failures=0입니다. 이는 테스트 입력에서 기대하는 값이며 이 문서를 만들 때 CUDA로 실행해 얻은 로그는 아닙니다. 이 예제는 bias가 scalar라서 본문 8장의 bias 벡터 트래픽과 다릅니다. 아주 작은 커널의 실행 시간으로 실제 LLM 속도를 추정하지 않습니다.

4. 오픈웨이트 모델로 확장하기

실험 기록 양식과 Qwen3-8B 공식 모델 카드를 함께 엽니다. revision·tokenizer·thinking 모드·출력 길이를 먼저 고정하고, 선택한 엔진의 공식 실행법으로 모델을 올립니다. 장비 메모리 조건은 시스템 이해편의 예산 실험으로 계산합니다. 이 책은 실제 Qwen 실행을 대신 완료했다고 주장하지 않습니다.

입력 길이만 바꾸는 prefill 비교, 출력 길이·문맥을 고정한 decode 비교, 부하를 바꾸는 서빙 비교를 따로 계획하세요. 모든 실험에서 출력과 품질을 확인한 뒤 시간 기록을 해석합니다. 12장 과제로 돌아가 검증 계획을 완성하세요.
