# 찾고 정렬하고 잇기 · 알고리즘과 자료구조 실험실

정적 인터랙티브 교과서. 저장소 루트에서 HTTP 서버를 실행하고 books/algorithms/를 연다.

검사: `npm test --prefix books/algorithms`

브라우저 검사: `BOOK_URL=http://127.0.0.1:8782/books/algorithms/ node books/algorithms/tests/browser.cjs`
