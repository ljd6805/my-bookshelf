# 영어 회화 기초 · 기본 문장 틀로 묻고 답하며 3분 대화 이어 가기

영문법은 배웠지만 영어로 말하면 첫 대답 뒤에 말이 끊기는 성인을 위한 정적 인터랙티브 교과서입니다. 서울 마케팅팀의 지우(지어낸 인물)가 싱가포르 지사에서 오는 동료 Sam과 첫 점심을 준비하는 과정을 따라가며, 낱말의 음절 수와 문장 강세, 주어와 동사의 기본 틀, 질문 만들기, 시제, 대답 늘리기, 부탁하기, 되묻기, 연음 받아쓰기, 말하기 속도와 군말을 11개 장과 11개 실험으로 익힙니다. 마지막 과제는 실제 점심 대화 기록에서 대화가 끊긴 세 순간을 고치는 일입니다.

문장 판정과 낱말 오류율, 분당 낱말 수는 브라우저 안의 계산 모델(js/english.js)이 계산합니다. 듣기는 브라우저의 음성 합성(Web Speech API)을 쓰며, 녹음하거나 발음을 채점하지 않습니다. 시리즈 「영어 말하기」의 1권이고, 2권은 「오픽 대비」입니다.
