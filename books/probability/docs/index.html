01 책의 약속

책 ID·제목probability-statistics · 확률과 통계 · 경보가 울렸다, 정말 고장일까 (폴더 books/probability/)
대상 독자비율과 평균은 알지만 "표본", "유의하다", "신뢰구간"이 나오면 막히는 사람. AI를 쓰거나 평가하면서 숫자를 얼마나 믿어야 할지 판단해야 하는 사람.
학습 후 할 일적은 데이터로 내린 결론이 얼마나 흔들리는지 계산하고, 경보·검사·실험 결과를 믿어도 되는지 기저율·신뢰구간·p값·검정력을 근거로 설명한다.
공통 사례한빛 공장의 모터 20대와 진동 센서. 담당자 서윤이 "오늘 경보 5번은 고장 신호인가"를 조사한다. 기준값: 센서별 하루 경보 확률 10%, 고장률 1%, 민감도 90%, 오경보율 5%.
끝의 과제새 공급업체 센서의 시험 자료(150센서·일 중 오경보 4번, 고장 재현 20번 중 19번 감지)를 보고 도입 여부, 부족한 증거, 다음 측정을 쓴다.
이야기 방식사건을 조사한다. 장마다 도구 하나를 얻고, 그 도구로 풀리지 않는 질문이 다음 장을 부른다.
범위·제외이산 확률, 이항분포, 요약 통계, 중심극한정리, 베이즈, 비율의 신뢰구간, 한쪽 이항검정, 우도와 교차 엔트로피. 연속분포의 일반 이론, 회귀분석, 다중검정, 베이즈 추론의 사전분포 설계, 인과추론은 다루지 않는다.
증거모든 수치 예시는 js/stats.js·js/inference.js로 다시 계산해 본문과 맞췄다. 개념 설명은 참고 자료 화면의 출처와 대조할 수 있다.

07 2026-10-12 보충

  • 4장 clt. “z와 68·95·99.7” 두 문단을 더했습니다(z = (x̄ − μ) ÷ (σ/√n), ±1·2·3에 68.27·95.45·99.73%, 95%는 ±1.96, 99%는 ±2.58, z = 2.5의 양쪽 꼬리 약 1.24%). 실험 clt에 “μ ± 1.96 × σ/√n 띠 보기”와 예제 버튼(n = 30, 띠 켜고 500개)을 더해 띠 안에 든 평균의 비율과 이론값 95%를 나란히 보여 줍니다. 씨앗 4, 평균 500개에서 n = 30이면 치우침 94.8%, 균등 95.8%, 주사위 95.6%이고, 균등·주사위 n = 1이면 100%입니다. 계산은 stats.js의 zScore·normalCoverage·twoSidedTail, inference.js의 shareWithin입니다. 정규분포 비율은 기존 출처(A&S 7.1.26 근사, NIST 핸드북) 범위 안의 값이라 새 출처를 더하지 않았습니다.
  • 마지막 과제. 다섯째 질문으로 “기댓값으로 비용 비교하기”를 더했습니다(질문 6개). 가정값: 오경보 점검비 5만 원, 놓친 고장 500만 원, 고장률 2%. 모터 한 대·하루당 기존 센서 1.49만 원, 새 센서(95%·4%) 0.696만 원, 감지율 Wilson 하한 76%이면 2.596만 원, 비용이 같아지는 감지율 약 87%. 계산은 stats.js의 expectedCost이고 테스트로 지킵니다. 비용 수치는 실제 자료가 아니라 설명용 가정입니다.
  • 공통. 장마다 “새 상황에 옮기기”에 보기 문항(transfer.quiz)을 붙였습니다. 이 책의 확인 문제는 보기 없는 서술형이라 돌릴 보기가 없고, 보기 문항만 화면에서 돌려(js/quiz.js) 정답 자리가 (장 번호 + 1) % 3에 오게 했습니다. 예측 질문의 정답 자리는 이미 1·2·3번에 고르게 있어 바꾸지 않았습니다.
  • 검증. npm test 25개 통과. 실제 Chromium으로 1280·390·320px에서 모든 경로를 열어 가로 넘침·콘솔 오류 없음, 실험 8개 조작·초기화, 4장 예제 버튼의 띠 비율과 초기화, 8개 장 보기 문항의 오답·정답 피드백, 마지막 과제 질문 6개를 확인했습니다(tests/browser.cjs).
  • 확인하지 못한 것. 밝은 화면, 실제 독자의 풀이 결과. 팩트·출처 재검수는 집필하지 않은 세션이 새 회차로 해야 합니다.

08 2026-10-12 새 장 · 9장 correlation

  • 배치. 다른 책 링크가 쓰는 01~08 번호를 지키려고 likelihood 뒤에 09로 두었습니다. 순서는 8장 → 9장 → 마지막 과제입니다. 8장의 남은 질문·다음 장 이유를 9장으로 잇고, 9장의 다음 장 이유가 마지막 과제로 이어집니다. 기존 장 ID는 바꾸지 않았고 book-routes에 correlation을 더했습니다.
  • 내용. 산점도, 피어슨 r(중심화한 두 벡터의 코사인), 교란 변수(부하), 층화, 무작위 실험을 다룹니다. 공장 기록은 가상 데이터라고 본문에 밝혔습니다. 이 장에는 “혼동하지 마세요” 블록(warning 필드, r은 직선 관계만 잰다)을 처음 넣었고, 다른 장에는 아직 없습니다.
  • 실험 correlation. 씨앗 112로 고정한 모터 20대 × 5~30일 기록. 진동 = 3.0 + 4·c·(부하 − 0.7) + N(0, 0.6²), 온도 = 45 + 30·c·(부하 − 0.7) + N(0, 3²), 부하는 0.4·0.7·1.0 중 하나를 같은 확률로 고르므로 Var(부하) = 0.06이고, 진동은 0.1 아래로 자릅니다(영향은 무시할 만함). 모델의 기대 r = 7.2c² ÷ √[(0.96c² + 0.36)(54c² + 9)]이므로 c = 1이면 0.7895, c = 0.5이면 0.4899입니다. 기본 10일(200개)의 표본 r은 0.791이고, 부하 단계별 r은 0.021(56개)·−0.039(72개)·0.009(72개), 온도를 무작위로 정하면 0.005, c = 0이면 −0.009입니다. 계산은 stats.js의 normalSample·cosine·pearson, inference.js의 sensorDays·correlationTheory·correlationSummary이고 화면은 js/labs-c.js가 그립니다.
  • 출처. Rodgers & Nicewander (1988), The American Statistician 42(1): 59–66의 여덟째 방법(중심화한 변수 벡터 사이 각의 코사인)을 참고 자료에 더했습니다. 집필 세션은 DOI를 열지 못했고, 검수 세션이 2026-10-12 Crossref 서지(DOI 10.1080/00031305.1988.10475524)와 공개 사본의 13개 방법 목록으로 확인했습니다. 교란과 무작위 실험은 기존 출처 OpenIntro Statistics의 범위입니다.
