# 확률과 통계 · 경보가 울렸다, 정말 고장일까

공장 진동 센서의 경보 하나를 따라가며 확률, 이항분포, 평균과 표준편차, 중심극한정리, 베이즈, 신뢰구간, 가설검정, 우도와 손실을 직접 실험으로 배우는 책입니다.

- 열기: 저장소 루트에서 `python3 -m http.server 8000` 후 `http://localhost:8000/books/probability/`
- 테스트: `npm test --prefix books/probability`
- 개발 기록: [docs/index.html](docs/index.html)
