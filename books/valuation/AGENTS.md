# 기업 가치 평가
루트 AGENTS.md와 docs/08-book-template.html을 따른다. 「금융과 투자 처음부터」 시리즈 6권이며, 5권 「재무제표 읽기」(books/statements/)와 같은 화면 구조를 쓴다. 기획·교과과정·장 설계는 docs/index.html, 사실과 기준값은 docs/research.html이 원본이다. 제목은 「기업 가치 평가 · 배수 비교와 현금흐름 할인으로 주당 가치의 범위 계산하기」, 시리즈 6권 이름 “기업 가치 평가”, 책등 “가치 평가”, 색 plum이다(서윤 G1 결정, 2026-10-13). 마지막 과제 제목은 “마지막 과제 · 같은 회사의 주당 가치가 두 배 차이 나는 이유를 가정·숫자·평가 시점으로 나눠 설명하기”(한결·서윤 지적)이고, 과제는 목표주가가 아니라 2025년 말 기준 현재가치를 견준다.
- 이 책은 학습용이며 투자 권유가 아니다. 사례는 모두 가상이다: 하린, 새벽전자(코스피 상장 가정, 1,000만 주, 주가 20,000원, 3년 회사채 표면 5.0%·할인 금리 5.061%, 배당 주당 400원 = 40억 원은 앞선 권과 맞춘 설정), “비교 회사 가·나·다·라”, “분석가 A·B”(새 고유명사를 만들지 않는다). 실제 상장회사의 값·배수·목표주가를 예로 쓰지 않고 실제 증권사 이름을 쓰지 않는다.
- 새벽전자 재무 숫자는 5권 research.html V-2~V-10과 books/statements/js/math.js ASSUME에서 가져온 값만 쓴다(억 원, 2024·2025 사업연도). 5권을 고치지 않고, 재무제표 읽는 법을 다시 가르치지 않는다.
- 가치 평가 가정(기준안: 매출 성장률 5%, 영업이익률 12%, 법인세 20%, 감가상각 = 기초 유형자산 10%, 유형자산 = 매출 × 708/1,800, 운전자본 = 매출 × 28%, 할인율 8.3%, 영구성장률 2%, 평가 시점 2025년 말·연말 할인, 순차입금 387.2억 원)과 분석가 A·B의 가정은 js/math.js의 ASSUME 한 곳에만 둔다. 기준값: 기준안 22,750원, A 31,833원, B 15,867원, 배수 범위 16,978~19,776원(research.html V-1~V-10).
- 계산의 불변 조건: 영구성장률 ≥ 할인율이면 값을 내지 않고 “g ≥ r” 오류를 보인다. 주주 몫 = 기업가치 − 순차입금, PBR = ROE × PER(같은 해 이익·같은 시점 자본)이 언제나 성립해야 한다. tests/math.test.cjs가 V-1~V-10 대표값, 경계값(g가 r 바로 아래, 성장률 0, 운전자본 비율 18%·32.2%), 차이 나누기의 합이 A − B와 같은지를 검사한다.
- 시장 숫자(국고채 10년 4.395% 2026-10-08 보도, 한국 주식 위험 프리미엄 4.87% Damodaran 2026-01 추정, 코스피 배수)는 2026-10-13 확인 기준이다. 6장 화면에 “확인일 2026-10-08”(이야기 시점 2026년 4월의 금리가 아님)을, 화면마다 확인일과 출처 등급(대학 교재·강의 원문 / 보도·2차 자료 / 이 책의 단순화 / 확인 못함)을 붙이고, “금리와 위험 프리미엄은 바뀌므로 확인일을 보고 다시 확인하세요”를 머리말·6장·마지막 과제에 같은 말로 둔다. 코스피 PER·PBR은 계산 입력으로 쓰지 않는다. 시장 숫자는 js/math.js의 MARKET 한 곳에만 둔다.
- 결과 문장은 판정이 아니라 “이 가정에서는 …”, “이 가정 범위에서 약 ○원~○원”으로 쓴다. “싸다”, “비싸다”, “저평가”, “고평가”, “추천”, “사세요”, “파세요”, “유리”를 결과 문장에 쓰지 않는다(tests/guides.test.cjs가 검사). 8·9·10장에는 “가상의 회사와 가상의 분석가로 계산한 사례이며, 특정 주식을 사고팔라는 권유가 아닙니다”를 붙인다.
- 겹침: 고든 모형의 원래 계산과 1 ÷ (r − g)는 3권 #equity, NPV·IRR은 1권 #npv, ROE는 5권 #ratios를 떠올리기(L1)와 링크로만 쓴다. CAPM은 6장에 식과 숫자 세 개만 두고 베타 추정·분산투자는 “9권(준비 중)”으로 글로만 안내하며 링크를 걸지 않는다(10권도 같음). 배당소득세는 11권 #dividend, 시가총액 가중은 7권 #weight, 변동성은 8권 #measure로 보내고 모두 깊이 보기(뒤 권)로 표시한다. 본문 L1은 1·3·4·5권과 이 책 앞 장으로만 쓴다. 확률과 통계 #interval 링크는 “신뢰구간과 가정의 범위는 다르다”는 이유로만 둔다.
- DCF는 2025 실적 FCFF(−225.2)가 아니라 2026~2030 예측 FCFF로 계산한다(기준안 2026년 196.8억 원 중 50.8억 원이 운전자본 비율 32.2% → 28% 회수). 8장은 가정마다 1%p당 변화를 보이고(개념 “기울기와 역전파”, 서윤 결정), 막대 순서가 고른 범위에 달렸고 운전자본 범위가 비대칭임을 적는다. 9장 비교 회사 PER은 후행 PER이고 배당성향 × (1 + g) ÷ (r − g)로 푼다.
- 계산은 js/math.js 한 곳(DOM 없음, 금액은 억 원 소수 첫째 자리, 주당 값은 원, 민감도 표는 10원 반올림, 비율은 소수 둘째 자리)에 둔다. 시장가 비중을 주가 20,000원으로 고정하는 것, 연말 할인, 평가 시점 2025년 말은 “이 책의 단순화”라고 표시한다. app.js의 L2 문장은 docs/index.html #chapters의 L2 칸에서 괄호 속 답을 뺀 질문과 같게, content.js recall은 L1과 같게 둔다.
- 실험 꼬리표로 실제 계산·공식 원문·보도 기준·미리 정한 가상 시나리오·이 책의 단순화·확인 못함·시각적 비유를 구분하고, 오류와 상태는 색과 함께 글자와 ✓ ✗ ▲로 적는다. 대표 실험 이름은 “DCF 민감도 표”이고 “판”, “함정”, “뼈대” 같은 그림말을 제목에 쓰지 않는다(K7).
- 서가 펼침 삽화의 클래스·id·keyframes는 vl- 접두어. 표지 삽화는 공통 cv-* 클래스만 쓰고 펼침 삽화와 다른 장면(FCFF 막대 다섯 개와 영구가치 막대가 할인을 지나 기업가치 막대로 모이고 순차입금을 덜어 주주 몫이 남는 장면)으로 둔다. 책 색은 plum(서윤 결정, 11권 plum과 세 칸 떨어짐).
- 함수와 즉시 실행 블록은 100줄 이내. 스크립트·스타일을 고치면 index.html의 ?v= 한 값을 함께 올린다. npm test와 tests/browser.cjs를 실행하고 docs/index.html에 검증 범위를 기록한다.
