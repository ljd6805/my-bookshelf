# 음성과 오디오 · 파형에서 대화하는 목소리까지

「AI 엔지니어링 처음부터」 시리즈 07권. 원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 6 레슨 17개를 한국어로 새로 쓴 12장·16개 실험의 인터랙티브 책입니다. 부엌의 음성 비서 솔이를 샘플링부터 말차례와 출시 후 진단까지 한 부품씩 만듭니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765` 후 `http://127.0.0.1:8765/books/aie-audio/`
- 계산 검사: `npm test --prefix books/aie-audio`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-audio/ node books/aie-audio/tests/browser.cjs`
- 작업 규칙: [AGENTS.md](AGENTS.md), 제작 문서: [docs/index.html](docs/index.html)
