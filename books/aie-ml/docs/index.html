머신러닝 기초 · 제작 문서

「AI 엔지니어링 처음부터」 시리즈 03권 《머신러닝 기초 · 데이터에서 믿을 만한 예측까지》를 어떻게 기획했는지, 원본 레슨을 어느 장에 넣었는지, 무엇으로 구현하고 어디까지 검증했는지 정리했습니다. 작성일은 2026-10-08입니다. 원본은 rohitg00/ai-engineering-from-scratch(MIT)의 Phase 2 · ML Fundamentals(레슨 18개)입니다. 원문과 코드는 옮기지 않았고, 다루는 주제와 순서만 참고해 새로 썼습니다. 원본 커리큘럼 기준이며 확인일은 2026-10-08입니다.

1. 기획

  • 독자: 02권까지 읽고 손실, 기울기, 확률을 계산할 수 있는 사람입니다. scikit-learn의 fit과 predict는 불러 봤지만, 점수가 왜 좋게 나왔는지 또는 왜 운영에서 무너졌는지는 설명하기 어려운 독자를 생각했습니다.
  • 끝의 행동: 분류 모델 하나를 받았을 때 기준선과 비교하고, 문턱과 지표를 비용에 맞게 고르고, 누설과 불균형을 점검하고, 데이터가 바뀐 날에 문턱만 고칠지 다시 학습할지를 증거로 판단하는 것이 목표입니다.
  • 공통 사례: 가상의 작은 온라인 서점 결제 기록(결제 1,000건 중 사기 약 3%)과 일별 주문 수입니다. 고객 무리(5장), 고객 문의 단어(6장)도 같은 서점의 기록으로 둡니다.
  • 이야기 방식: 하나의 제품을 완성하는 이야기입니다. 1장에서 “규칙 대신 데이터로 경보를 만든다”는 결정을 내리고, 모델(2~6장), 평가(7~9장), 실전 공정(10~11장)을 거쳐 마지막 장에서 새 결제 수단이 들어온 날의 판단으로 끝납니다.
  • 범위: 원본 18개 레슨을 12장으로 묶었습니다. 서재의 다른 책이 깊게 다룬 내용(AI Book의 학습·일반화, 확률 책의 베이즈 정리, 선형대수 책의 유사도·PCA)은 한 문단으로 줄이고 cross 링크로 보냈습니다.
  • 증거의 종류: 16개 실험 중 15개는 시드를 고정한 가상 데이터로 실제 계산합니다. 12장 drift 실험의 “재학습” 대응만 “이동의 75%를 되찾는다”는 가정을 둔 시나리오이며 화면에 그렇게 밝힙니다. 10장 그림과 11장 SMOTE 그림은 원리를 보여 주는 비유입니다.

확인하지 못한 것

  • L4 학습 효과: 실제 독자에게 시험해 보지 않았습니다.
  • 스크린 리더(VoiceOver, NVDA)로 직접 읽어 보지 않았습니다. role과 aria-label, role=status의 존재만 확인했습니다.
  • 서가(루트 index.html)에서 책을 펼쳤을 때 삽화가 움직이는지는 카탈로그 등록 전이라 확인하지 못했습니다. 등록 제안은 docs/registration.json에 있습니다.
  • 외부 참고 자료 링크의 현재 응답 상태는 다시 열어 보지 않았습니다.
  • 모든 수치는 교육용 가상 데이터의 값이며 실제 결제 서비스의 사기율이나 비용이 아닙니다.
