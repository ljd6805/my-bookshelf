1. 기획 (G0~G1 · 기획·연결팀 서윤·도현·민재)

요청과 범위

서재 주인(jdeoklee)이 2026-10-19 프로젝트 스레드에서 LoRA와 파라미터 효율적 미세조정을 다루는 책을 요청했습니다. 요청에는 장 목록 12개와 마지막 과제, 장마다 실험 하나, 브라우저 계산, 공개 모델 설정과 논문으로 확인한 수치만 쓰라는 조건이 들어 있습니다. 공통 사례는 지어낸 인물 하린입니다. 하린은 회사 문서의 말투로 답하도록 7B 모델을 GPU 24GB 한 장에서 미세조정하려다 메모리 부족을 겪고, 마지막 과제에서 13B 모델로 같은 목표를 세워 전체 미세조정·LoRA·QLoRA 가운데 하나를 숫자로 고릅니다.

제목과 서가 위치

요청의 예시 제목 「큰 모델은 얼려 두고 포스트잇만 고치기 · LoRA의 원리」는 “포스트잇”이 주제를 대신하는 소품이라 K7에 맞지 않습니다. 대상(LoRA 미세조정)과 독자가 하는 일(저랭크 행렬로 학습할 파라미터와 GPU 메모리 줄이기)을 말하는 「LoRA 미세조정 · 저랭크 행렬로 학습할 파라미터와 GPU 메모리 줄이기」(공백 제외 30자)로 정했습니다. 책등은 “LoRA 원리”(6자), id는 lora, 폴더는 books/lora/, 전역 접두어는 LR(스크립트)·lr-(CSS)입니다.

요청은 분류를 “AI”로 적었지만 서가에는 “AI” 분류가 없고 “인공지능”(AI Book·LLM 시스템·LLM 성능·트랜스포머 속)과 “AI공학”(20권 시리즈)이 있습니다. 이 책은 시리즈의 한 권이 아니고, 7B·13B 모델의 메모리와 서빙을 다루는 LLM 시스템·LLM 성능과 가까워 “인공지능” 묶음 끝(트랜스포머 속 다음)에 둡니다. 이웃 색이 겹치지 않도록 violet을 씁니다.

반대 의견과 결론 (민재)

민재: “AI공학 12권 LLM 엔지니어링에 이미 LoRA 장(#lora)이 있다. 새 책이 같은 내용을 되풀이하지 않는가?” 결론: 12권의 장은 LoRA를 써서 말투를 맞추는 사용법을 보여 주고, 이 책은 왜 저랭크로 충분한지(SVD·내재 차원), 식의 각 부분(B = 0 시작, α/r), 메모리를 바이트 단위로 세는 법을 다룹니다. 12권 #lora에서 이 책 4장으로 가는 링크를 이동 이유와 함께 두고, 이 책 4장은 12권으로 돌아가 실제 학습 파이프라인을 보게 합니다. 겹치는 사용법 설명은 이 책에 다시 쓰지 않습니다.
