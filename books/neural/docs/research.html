0. 읽는 법

이 세션의 셸에서는 외부 주소가 막혀 있어(프록시 403), 웹 가져오기 도구로 읽을 수 있었던 공식 문서 넷(PyTorch Conv2d·RNN, Keras Conv2D, NumPy 브로드캐스팅)만 2026-11-11에 직접 확인했습니다. 논문과 교과서의 서지 정보는 집필자의 지식에 기대어 적었고, 주소가 열리는지는 G6 검수에 넘깁니다. 4~7장의 참고 커리큘럼(rohitg00/ai-engineering-from-scratch, MIT)은 「딥러닝 핵심」을 만들 때(2026-10-08) 확인한 내용을 그대로 썼습니다.

사내 교육 자료(구글 드라이브의 딥러닝 보강 자료와 서재 주인의 필기)는 주제의 목록과 순서를 정하는 데만 썼습니다. 문장·그림·예제·수치는 옮기지 않았습니다. 그 자료에서 본 다음 내용은 쓰지 않거나 바로잡았습니다: 역전파 논문의 연도(1986으로 씀), Adam의 설명(이 책에서 다루지 않고 「딥러닝 핵심」으로 보냄).

3. 확인하지 못한 것

  • PyTorch 텐서 문서 본문(자료형 표)은 가져오기 도구가 목차만 돌려주어 읽지 못했습니다. “float32가 기본 실수 자료형”은 집필자의 지식입니다.
  • 논문 DOI·arXiv 주소와 교과서 주소는 열어 보지 못했습니다.
  • Minsky·Papert 《Perceptrons》 원문, Bengio 등(1994) 원문은 읽지 못하고 교과서의 요약에 기댔습니다.
  • “ReLU 뉴런의 10~40%가 죽을 수 있다”의 1차 측정 출처는 찾지 못했습니다. 본문은 원본 레슨의 설명이라고 밝힙니다.

4. 수아의 검산

  • 카페 기록의 최소제곱 선: 평균 x = 3.5, 평균 y = 25.75, Σ(x − 3.5)(y − 25.75) = 170, Σ(x − 3.5)² = 42 → w = 170/42 ≈ 4.048, b = 25.75 − 4.048 × 3.5 ≈ 11.583. MSE ≈ 1.4256.
  • w = 4, b = 12의 오차: 0, 1, −1, 2, 0, −1, 2, −1 → 제곱 합 12, MSE 1.5, MAE 8/8 = 1.0.
  • b = 12에서 dL/dw(w = 0) = (2/8)Σ(12 − y)x = −138.75. 곡률 2 × 평균(x²) = 2 × 17.5 = 35, 한계 2/35 ≈ 0.0571. 최솟값 w = Σx(y − 12)/Σx² = 555/140 ≈ 3.964.
  • w와 b를 함께 찾을 때의 헤세 행렬 2[[17.5, 3.5], [3.5, 1]]의 큰 고윳값 ≈ 36.42 → 한계 ≈ 0.0549. η = 0.05는 수렴, 0.06은 발산(실험과 맞음).
  • 파라미터 수: 150,528 × 64 + 64 = 9,633,856. 9 × 3 × 64 + 64 = 1,792. 32 × 64 + 64 × 64 + 64 = 6,208. 4 × (32² + 32) = 4,224. 784-256-128-10 망 235,146.
  • 0.25¹⁰ = 9.54 × 10⁻⁷, 0.25³ = 0.015625.

5. 태오가 모은 오해

  • “학습률은 작을수록 안전하다” → 3장 혼동 상자.
  • “손실이 낮으면 예측을 믿어도 된다” → 2장 혼동 상자.
  • “XOR은 더 오래 돌리면 배운다” → 4장 혼동 상자.
  • “층을 쌓으면 표현력이 는다(활성화와 무관하게)” → 5장 혼동 상자와 마지막 과제.
  • “역전파가 가중치를 고친다” → 6장 혼동 상자.
  • “ReLU는 기울기 소실을 없앤다” → 7장 혼동 상자.
  • “새 구조가 옛 구조를 대신한다”, “LLM은 신경망과 다른 기술이다” → 8장.
  • “학습 정확도가 높으면 끝” → 마지막 과제.
  • “차원”의 두 뜻 → 1장.
