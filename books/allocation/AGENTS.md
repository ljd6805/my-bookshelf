# 자산배분
루트 AGENTS.md와 docs/08-book-template.html을 따른다. 「금융과 투자 처음부터」 시리즈 9권이며, 2권 「거시경제」(books/macro/)·6권 「기업 가치 평가」(books/valuation/)와 같은 화면 구조를 쓴다. 기획·교과과정·장 설계는 docs/index.html, 사실과 기준값은 docs/research.html이 원본이다. 지금은 G0~G2 초안 단계이며 서가(data/catalog.json)에 등록하지 않았다.

- **서윤 G1 결정 대기** (docs/index.html #links-open): 제목 1안 「자산배분 · 상관과 비중으로 포트폴리오 위험을 계산하고 계좌 비중 다시 짜기」(공백 제외 32자) 또는 2안, 색 plum(제안) 또는 violet(왼쪽 이웃 macroeconomy가 rose라 rose 금지), 책등 “자산배분”, book_id asset-allocation, 폴더 books/allocation, 시리즈 volumes 9권 title “위험을 나누는 법” → “자산배분”, cover_meta “10장 · 10개 실험”. 결정이 나면 이 줄을 결정 내용으로 바꾼다. 책 제목은 공백 제외 32자를 넘기지 않는다(펼친 책 삽화가 눌리지 않게, 2권 G5 기록).
- **이 책은 학습용이며 투자 권유가 아니다.** 실제 독자에게 권하는 비중·상품을 내놓지 않는다. 결과 문장은 “이 가정에서는 표준편차 ○%, 위기 시나리오 손실 ○원이고 조건 □□를 만족한다/만족하지 못한다”로 쓰고 “최적 비중”, “정답 비중”, “추천”, “사세요”, “파세요”, “유리”, “안전한 비중”, “오를 것”, “내릴 것”을 쓰지 않는다(G3에서 tests/content.test.cjs로 검사). 효율적 투자선·접점·풀이 예시의 비중에는 “V-0 가정에서 계산한 값이며 권하는 비중이 아닙니다”를 붙인다.
- **사례는 가상이다**: 하린(시리즈 공통, 1~9장의 위험 장부), 새벽전자(한 종목)·누리200(국내 주식 지수)·해외주식 묶음·채권 묶음·현금 다섯 자산, 마지막 과제의 윤 씨(55세, 은퇴까지 10년, 3억 원 가운데 IRP 1억 원, 지금 비중 안 A 30·30·20·10·10). 새 회사 이름을 만들지 않는다. 실제 회사·실제 펀드·실제 증권사의 이름이나 실제 시장 자료로 추정한 상관·베타를 예로 쓰지 않는다.
- **다섯 자산의 가정**(research.html V-0)은 js/math.js의 ASSETS 한 곳에만 둔다: μ 9.0·7.0·6.5·3.5·2.5%, σ 35·18·16·6·0%, 상관 새벽–누리 0.67, 새벽–해외 0.4, 새벽–채권 −0.1, 누리–해외 0.6, 누리–채권 −0.2, 해외–채권 0. 위기 상관은 주식끼리 0.9, 주식·채권 +0.3. 화면마다 “미리 정한 가정 · 예측 아님 · 실제 시장 자료에서 추정하지 않음”을 붙인다. 모델 결과는 예측이 아니다. 본문은 “이 가정이라면”으로 한정하고, 4장에 “기대수익 1%p를 바꾸면 접점 비중이 크게 움직인다”는 비교 예제를 둔다.
- **켈리 기준(8장)은 계산 연습이다.** 제목에 “(계산 연습)”을 유지한다. f*와 함께 같은 장에서 절반·2배·3배 비율의 성장률(0.0038·−0.0001·−0.0162), 연속 다섯 번 손실 뒤 자산(0.59·0.33), 승률 과대 추정을 계산한다. 연속형 1.39배는 “빌려야 하는 비율이며 따르는 값이 아니라 가정이 얼마나 공격적인지 보여 주는 값”으로 쓴다. 켈리 비율을 계좌 비중으로 쓰라는 문장을 쓰지 않고, 마지막 과제에 켈리 기준을 쓰지 않는다.
- **마지막 과제**: 윤 씨의 조건(위기 시나리오 한 해 손실 4,500만 원 이내, 은퇴 첫 3년 생활비 일부를 채권·현금으로)은 과제에 숫자로 못 박는다. 풀이 예시 B(5·20·20·40·15)는 “조건을 만족하는 예 하나이며 정답이 아님”으로 쓴다. 과제 화면과 풀이에 “가상의 인물과 가정으로 만든 계산 연습이며, 실제 계좌의 비중을 권하지 않습니다. 실제 결정에는 세금·비용·소득·건강·다른 자산을 함께 보아야 합니다”를 같은 말로 둔다.
- **시점에 민감한 값(⏱)** 셋은 js/math.js의 MARKET 한 곳에만 두고 확인일·출처 등급을 붙인다: 퇴직연금 위험자산 70% 한도(2026-10-13 확인, 보도 두 곳, 2026-06 보도 시점 완화 검토 중), 국고채 금리 4.4%(6권 확인 2026-10-08, 서재 안 재인용), 주식 위험 프리미엄 4.9%(6권 확인 2026-01-05, 서재 안 재인용). 고정 재확인일 2027-04-13, 그 전이라도 G6 시작일에 다시 연다. 6권 값이 바뀌면 같은 커밋에서 고친다. 머리말·5장·마지막 과제에 “한도와 금리는 바뀌므로 확인일을 보고 다시 확인하세요”를 같은 말로 둔다. 70% 한도의 숫자는 확인 문제·복습 퀴즈의 답으로 묻지 않는다.
- **실험 기본값과 프리셋은 L2·확인 문제의 답을 보이지 않는다.** 기본값: 1장 σ 30·ρ 0.3·N 10, 2장 누리200·해외·채권, 3장 누리200·채권 ρ −0.2·주식 60%, 4장 40·20·40·r_f 2.5%, 5장 12개월 가상 자료, 6장 60/30/10, 7장 1억 원 4년 경로, 8장 p 0.55·b 1, 9장 네 종목 σ 25%와 60/40 평상시·위기, 10장 안 A. 2장 “불가능한 상관 행렬” 예제는 L2 뒤에 연다. 9·10장 L2 입력(σ 30·6·ρ +0.3, 안 C)과 8장 L2 입력(p 0.45·b 2)은 프리셋에 넣지 않는다. app.js의 L2 문장은 docs/index.html #chapters의 L2 칸에서 괄호 속 답을 뺀 질문과 같게, content.js recall은 L1과 같게 둔다.
- **기준값**(research.html V-1~V-10): tests/math.test.cjs가 대표값(1장 18.25%, 3장 최소분산 14.29%·5.27%, 4장 접점 22.52·13.30·64.18%와 샤프 0.3463, 5장 β 1.3118, 7장 끝 금액 셋, 8장 f* 0.10, 9장 19.80%, 10장 안 A·B·C), 경계값(ρ = 1이면 분산 효과 없음, ρ = 0이면 σ/√N, 현금만이면 σ 0, p 0.5·b 1이면 f* 0), 불변 조건(비중 합 100%, 고윳값 ≥ 0이 아닌 상관 행렬 거부, 현금을 섞어도 샤프 비율 그대로, 위험 기여의 합 100%)을 검사한다.
- **범위 경계**: 표준편차·연율화·변동성 손실·꼬리·낙폭은 8권(#measure·#drag·#tails·#drawdown), 상관계수와 인과는 확률과 통계 #correlation, 투영·고유벡터·주성분은 「벡터와 행렬」(#projection·#eigen·#pca), 제약 최적화는 「모델을 움직이는 수학」 #optimize, CAPM의 금리·위험 프리미엄은 6권 #wacc, 채권 민감도는 3권 #duration, 수수료는 1권 #fees, 연금 계좌·거래세는 11권(#pension·#trade, 깊이 보기(뒤 권)), 실제 위기 지표는 2권 #crisis로 링크하고 다시 계산하지 않는다. 본문 L1은 이미 나온 권과 이 책 앞 장으로만 쓴다. 10권(투자 심리)·13권은 “10권(준비 중)”처럼 글로만 안내하고 링크를 걸지 않는다.
- **12권(그리드)은 링크하지 않는다.** 7장 리밸런싱에서 12권 #compare로 보내면 계좌 안 격자 매매 조언으로 읽힐 수 있다(2권·6권과 같은 판단). 꼭 필요해지면 서윤의 결정을 받는다.
- **서가 연결 초안**(서윤 결정 대기): 기존 개념 “흔들림과 분산”에 #diversify·#crisis, “차원 줄이기”에 #matrix. 새 개념 “제약 속 최적화”(aie-math #optimize + #frontier)는 4장 실험이 공매도 금지 손잡이로 투자선의 차이를 보일 때만 만든다. 새 노선 correlated-losses: 8권 #measure → 확률과 통계 #correlation → #diversify → 「벡터와 행렬」 #pca → #crisis. 들어오는 링크(G5): 8권 #final “준비 중인 책” 상자 → #diversify, 6권 #wacc 본문 105행·연결 114행 → #beta, 「벡터와 행렬」 #pca → #matrix. 개념 이름은 공백 제외 10글자 이내.
- 연구 결과(“열 종목이면 충분”과 반론, 위기 상관, 자산배분 연구의 세 질문, 켈리의 좋은 성질과 나쁜 성질)는 학술 서지·초록·2차 자료 등급을 화면에 적는다. “배분이 수익의 90%를 정한다”는 잘못 인용된 숫자로 오해 상자에만 쓴다. “위기에는 상관이 1이 된다”를 사실로 쓰지 않는다.
- 계산은 js/math.js 한 곳(DOM 없음)에 둔다. 화면 글자는 %는 소수 둘째 자리, 베타·샤프 비율은 소수 셋째~넷째 자리, 원화 금액은 만 원 단위. 반올림한 중간값을 다시 쓰는 계산은 그렇다고 밝힌다(예: 5장 CAPM 10.82%는 β 1.31로 계산).
- 실험 꼬리표로 실제 계산·미리 정한 가정·서재 안 재인용·보도 기준·교재 정의·학술 서지·확인 못함·시각적 비유를 구분하고, 상태는 색과 함께 글자와 ✓ ✗ ▲로 적는다. 대표 실험 이름은 “포트폴리오 비중 실험”이고 제목·장 제목에 “구름”, “달걀”, “바구니”, “사다리” 같은 소품이나 그림말을 쓰지 않는다(K7).
- 서가 펼침 삽화의 클래스·id·keyframes는 al- 접두어. 표지 삽화는 공통 cv-* 클래스만 쓰고 펼침 삽화와 다른 장면(기대수익–표준편차 평면의 두 자산 점, 상관별 곡선 셋, 무위험 금리에서 닿는 직선)으로 둔다. localStorage 키는 bookshelf:allocation:v1:study(공통 book-study.js)를 쓴다.
- 함수와 즉시 실행 블록은 100줄 이내. 스크립트·스타일을 고치면 index.html의 ?v= 한 값을 함께 올린다. npm test와 tests/browser.cjs를 실행하고 docs/index.html에 검증 범위를 기록한다.
