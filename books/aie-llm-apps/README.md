# LLM 엔지니어링 · 프롬프트에서 서비스까지

「AI 엔지니어링 처음부터」 시리즈 12권. 원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 11 · LLM Engineering 레슨 17개를 한국어로 새로 쓴 12장·16개 실험의 인터랙티브 책입니다. 가상의 온라인 서점 "책다락"의 고객 지원 도우미 하나를 프롬프트에서 출시까지 키웁니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765` 후 `http://127.0.0.1:8765/books/aie-llm-apps/`
- 계산 검사: `npm test --prefix books/aie-llm-apps`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-llm-apps/ node books/aie-llm-apps/tests/browser.cjs`
- 작업 규칙: [AGENTS.md](AGENTS.md), 제작 문서: [docs/index.html](docs/index.html), 서재 등록 제안: [docs/registration.json](docs/registration.json)
