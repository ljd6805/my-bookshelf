# 멀티 에이전트 · 여럿이 나눠 맡고 서로 확인하기

「AI 엔지니어링 처음부터」 시리즈 17권. 원본 커리큘럼 [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)(MIT)의 Phase 16 레슨 25개를 한국어로 새로 쓴 12장·16개 실험의 인터랙티브 책입니다. 공공자전거 대여소 확대를 조사하는 보고서 팀 하나가 혼자 일하는 에이전트에서 반장·조사원·검증자가 있는 팀으로 자라며 겪는 일을 계산합니다.

- 읽기: 저장소 루트에서 `python3 -m http.server 8765` 후 `http://127.0.0.1:8765/books/aie-multiagent/`
- 계산 검사: `npm test --prefix books/aie-multiagent`
- 브라우저 검사: `BOOK_URL=http://127.0.0.1:8765/books/aie-multiagent/ node books/aie-multiagent/tests/browser.cjs`
