조사 노트 · 4장 검출 AP 실험(ap)

지식조사팀(은재)이 2026-10-12 개정 관문 G3에서 묶은 노트입니다. 4장 detect의 둘째 실험 「검출 AP 직접 계산하기」가 기대는 사실과 숫자를 한곳에 모았습니다. 장면의 숫자는 이 노트를 쓰면서 책 코드(js/math.js)와 따로 Python 분수 계산으로 다시 구했고, 외부 사실은 아래 출처 절에 확인일과 함께 적었습니다. 참고 자료는 정의와 규칙만 참고했고 문장과 코드는 새로 썼습니다.

식과 정의

  • IoU(A, B) = |A ∩ B| / |A ∪ B|. 상자는 (x1, y1, x2, y2) 픽셀 좌표이고 넓이는 (x2 − x1)(y2 − y1)로 셉니다(경계 픽셀을 +1 하지 않는 연속 좌표 방식).
  • 정밀도 = TP / (TP + FP), 재현율 = TP / (TP + FN). 순위 k까지의 점은 (재현율_k, 정밀도_k)입니다.
  • 포락선: 정밀도를 오른쪽에서부터 누적 최댓값으로 바꾼 값 env_k = max_{j ≥ k} 정밀도_j.
  • 모든 점 보간 AP = Σ (재현율_k − 재현율_{k−1}) · env_k (재현율이 오르는 k만 더함). COCO 101점 AP = (1/101) Σ_{r ∈ {0, 0.01, …, 1}} env(재현율이 처음 r 이상이 되는 순위).
  • 예측이 없으면 정밀도는 0/0이라 정의되지 않고, 재현율과 AP는 0으로 둡니다. 정답이 없으면 재현율과 AP가 정의되지 않습니다(이 장면에는 정답이 항상 셋).

가정·단위·유효 범위

  • 단위는 픽셀 좌표(480×280 그림 판 안)이고, 점수는 0~1의 모델 점수입니다. 점수 문턱 입력 범위 0.1~0.95(0.05 간격), 판정 IoU 0.5·0.75, NMS 끔·0.45입니다.
  • 영상 한 장, 클래스를 구분하지 않는 단일 클래스 평가입니다. 실제 COCO 평가는 영상과 클래스별로 모아 계산하고, crowd 정답·면적 범위·영상당 최대 예측 수(maxDets)를 따로 다룹니다. 실험은 이것을 다루지 않는다고 결과 문장에 “정답이 셋뿐인 장면 하나”로 밝힙니다.
  • 정답이 셋뿐이라 재현율은 1/3씩만 움직입니다. 그래서 AP 차이가 실제 데이터보다 크게 보입니다.

실제 계산·시나리오·비유의 구분

  • 실제 계산: IoU, NMS, 점수 순 맞춤, TP·FP·FN, 정밀도·재현율, 포락선, AP. 모두 js/math.js의 순수 함수입니다.
  • 미리 정한 예시: 후보 상자 일곱 개와 점수, 사람이 그렸다고 정한 정답 상자 셋. 실제 모델의 출력이 아닙니다.
  • 시각적 비유: 없음. 그림은 계산한 상자와 계단을 그대로 그립니다(실선 TP, 점선 FP, 흐린 점선은 판정에서 빠진 상자).

오해 목록

  • “NMS를 켜면 AP는 언제나 오른다.” 판정 0.75에서는 NMS가 정답 B와 더 잘 맞던 b2를 지워 AP가 0.667에서 0.556으로 내려갑니다. NMS는 예측끼리의 겹침만 봅니다.
  • “NMS 임계값과 판정 IoU 문턱은 같은 겹침 기준이다.” NMS는 예측과 예측, 판정은 예측과 정답의 겹침입니다.
  • “점수 문턱을 올리면 AP가 오른다.” AP는 바뀌지 않고, 그 문턱에서의 정밀도만 오릅니다(0.3 → 0.5에서 0.429 → 0.600, AP 0.917 그대로).
  • “같은 물체를 두 번 맞히면 TP가 둘이다.” 정답 하나는 예측 하나와만 짝이고 중복은 FP입니다.
  • “AP50이 높으면 상자가 정확하다.” AP75처럼 엄격한 문턱에서 떨어지면 대략만 찾는 것입니다.
