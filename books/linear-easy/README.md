# 쉬운 선형대수 · 벡터·행렬·텐서를 3D로 보며 신경망 계산하기

딥러닝 책을 읽는 데 필요한 선형대수를 덧셈과 곱셈에서 시작해 다루는 정적 교과서입니다. 카페 음료 레시피(지어낸 예)를 숫자 세 개짜리 벡터 (샷, 우유, 시럽)으로 적고, 직접 돌릴 수 있는 3차원 그림에서 벡터의 덧셈과 길이, 내적과 뉴런, 행렬과 행렬 곱, 모양 규칙과 텐서, 역행렬과 랭크, 고윳값, 야코비안을 14개 장과 14개 실험으로 계산합니다. 마지막 과제에서 작은 신경망의 순전파를 모양과 함께 손으로 따라가고 모양 오류 세 건을 고칩니다.

- 실행: 저장소 루트에서 정적 서버를 띄우고 `books/linear-easy/`를 엽니다.
- 검사: `npm test`, `npm run browser`(Playwright 필요, `PW_EXECUTABLE_PATH`로 크로미움 경로 지정 가능).
- 제작·조사: [docs/index.html](docs/index.html), [docs/research.html](docs/research.html), [docs/fact-review.html](docs/fact-review.html)
