조사 노트 · 돈의 시간 가치

이 노트에 대하여

지식조사팀장 은재가 정리했습니다. 1차 출처는 지호가 찾았고, 기준값은 수아가 책 코드와 상관없이 따로 계산했으며, 장별 오해는 태오가 모았습니다. 확인일은 모두 2026-10-12입니다.

이 책이 기대는 사실은 두 갈래입니다. 하나는 단리·복리, 실효 금리, 현재가치, 연금, 상환 방식, NPV·IRR, 피셔 관계, 연환산 수익률처럼 어느 나라에서나 같은 계산 규칙입니다. 다른 하나는 이자소득세, 예금자보호 한도, 기준금리, 물가, 중도상환수수료, 연체이자율, 신용점수처럼 한국에서 정해지고 자주 바뀌는 제도와 수치입니다. 앞의 것은 수식이 맞는지를, 뒤의 것은 언제 기준인지를 중심으로 확인했습니다.

출처에는 등급을 붙였습니다. 공식 원문 확인은 제도를 운영하는 기관(한국은행, 국가데이터처, 금융위원회, 예금보험공사 등)의 글이나 보도자료를 직접 읽은 경우입니다. KDI 경제정보센터처럼 정부 자료를 그대로 다시 실은 곳에서 읽은 경우도 여기에 넣고 그렇다고 적었습니다. 보도로 확인은 언론 기사나 은행·증권사의 안내문 같은 2차 자료로만 확인한 경우입니다. 교재 수준 확인은 계산 규칙을 백과사전·교재 성격의 글에서 읽고, 수아가 직접 계산으로 맞춰 본 경우입니다. 확인 못함은 원문을 읽지 못했거나 자료끼리 어긋나 판단을 미룬 경우입니다.

이번 조사 환경에서는 한국은행 누리집(bok.or.kr) 본문, 금융위원회(fsc.go.kr), 법제처(law.go.kr), 국세청(nts.go.kr), e-나라지표(index.go.kr)를 직접 열 수 없었습니다(접속 차단 또는 robots 제한). 그래서 한국은행·국가데이터처·금융위원회 자료는 KDI 경제정보센터의 재게시본이나 보도자료 파일 재게시본으로 읽었고, 법령 조문(소득세법 제129조 등)은 원문 대신 해설과 보도로 확인했습니다.

통계청은 2025년 정부 조직 개편으로 국가데이터처가 되었습니다. 2026년 물가 발표의 기관명은 국가데이터처이고, 책에서는 "국가데이터처(옛 통계청)"라고 씁니다. 개편 날짜는 원문으로 확인하지 못했습니다.

시점에 민감한 항목은 표에서 ⏱ 표시를 붙였습니다. 2026년에는 기준금리가 7월과 8월에 연달아 올랐고(2.50% → 2.75% → 3.00%, 7월 결정은 보도로만 확인), 다음 결정은 10월 22일입니다. 이 노트가 확인한 뒤에 바뀔 수 있습니다. 소비자물가지수도 2026년 12월에 기준연도를 2020년에서 2025년으로 바꿀 예정이라, 그때 2025~2026년 상승률이 고쳐질 수 있습니다.

사실 표의 "장" 칸은 그 행을 쓰는 장의 ID(today, compound, rule72, discount, loan, npv, inflation, cagr, fees, final)입니다. 장마다 드러낼 오해는 오해 목록에 따로 모았습니다.

참고한 은행 안내문과 기사는 사실 확인에만 썼습니다. 책의 문장과 예시는 구조만 참고하고 새로 씁니다. 책의 금리·물가·수익률 기본값은 모두 가정이며, 아래의 실제 수치는 "확인일 기준 대략 이 범위"라는 맥락으로만 씁니다.

1. 계산 규칙

수식 기호: P 원금(현재가치), F 미래가치, r 연 금리(소수), n 햇수, m 1년의 복리 횟수, i 기간 금리, N 납입·상환 횟수, A 회당 금액, π 물가 상승률, f 연 비용률, σ 수익률의 표준편차.

1-1today · compound단리와 복리단리: F = P(1 + r·n). 이자가 원금에만 붙습니다. 복리: F = P(1 + r)n. 붙은 이자가 다음 기간 원금이 됩니다. KB 안내문의 예시(1,000만 원, 연 4%, 10년 단리 1,400만 원·복리 약 1,480만 원, 50년 단리 3,000만 원·복리 약 7,107만 원)를 수아가 다시 계산해 맞음(1.0410 = 1.48024, 1.0450 = 7.1067)을 확인했습니다.[S34] [S40]교재 수준 확인
1-2rule72복리 주기와 실효 금리(EAR)표시 금리 r을 1년에 m번 나눠 붙이면 F = P(1 + r/m)mn, 실효 연 금리 EAR = (1 + r/m)m − 1. m이 커질수록 EAR은 er − 1에 다가갑니다(연속 복리, F = P·ern). 연 3%: 해마다 3.0000%, 분기 3.0339%, 달마다 3.0416%, 날마다 3.0453%, 연속 3.0455%.[S34]교재 수준 확인 (원 페이지는 수식 그림이 텍스트로 읽히지 않아 설명 문장과 "상한 er − 1" 문장만 확인. 값은 수아 계산)
1-3rule72두 배 걸리는 해정확한 값 T = ln 2 / ln(1 + r). 72의 법칙 T ≈ 72 / (r×100). 연속 복리에서는 69.3 / (r×100)이 정확합니다. 72는 연 8% 근처에서 가장 잘 맞고, 금리가 낮으면 조금 길게, 높으면 조금 짧게 어림합니다. 원 페이지 표: 3% 실제 23.450년·72법칙 24.000년, 6% 11.896·12.000, 9% 8.043·8.000.[S32] [S41]교재 수준 확인 (원 페이지의 3%·6%·9% 표를 수아 계산과 대조해 소수 셋째 자리까지 같음)
1-4discount현재가치와 미래가치F = P(1 + r)n을 거꾸로 하면 P = F / (1 + r)n. 1/(1 + r)n을 할인 계수, r을 할인율이라고 부릅니다. 복리의 역산이므로 1-1과 같은 출처로 확인합니다.[S34]교재 수준 확인
1-5loan연금(정기 납입)의 현재가치·미래가치기말 납입(보통 연금): PV = A·[1 − (1 + i)−N] / i, FV = A·[(1 + i)N − 1] / i. 기초 납입(선불 연금)은 둘 다 (1 + i)를 한 번 더 곱합니다. i = 0이면 PV = FV = A·N. 대출 원리금균등 상환액 A = P·i / [1 − (1 + i)−N]은 PV 식을 A에 대해 푼 것입니다.[S38]교재 수준 확인 (원 페이지는 수식 그림이 읽히지 않아 변수 정의와 "i > 0일 때 유효, i = 0이면 P/N" 문장을 확인. 식은 수아가 등비급수로 다시 유도)
1-6loan한국 은행 정기적금의 이자 계산(단리형)달마다 같은 돈을 넣고, 회차마다 입금일부터 만기 전날까지 남은 기간만큼 단리로 이자를 줍니다. 하나은행 「정기적금」 상품설명서의 식: 계약액 = 월저축금 × 계약월수 + 월저축금 × 총운용월적수 × 연이율 / 12, 총운용월적수 = 계약월수 × (계약월수 + 1) / 2. 12개월이면 총운용월적수가 78이라 이자 = 월저축금 × 연이율 × 78/12. 그래서 "연 3% 적금"의 이자는 넣은 원금 합계의 3%가 아니라 약 1.625%입니다(평균 6.5개월만 맡긴 셈).[S28] [S30]공식 원문 확인 (은행 상품설명서. 토스뱅크 안내문의 예시 숫자도 같은 방식과 맞음)
1-7loan월복리 적금"월복리 적금"도 있습니다. 하나은행 「급여하나 월복리 적금」은 저축금마다 입금일부터 만기 전날까지 약정금리를 월복리로 계산하고, 중도해지·만기 후 이자는 단리로 줍니다. 단리형과의 차이는 작습니다(월 50만 원, 12개월, 연 3%에서 단리 97,500원, 월복리 98,399원).[S29]공식 원문 확인 (은행 상품설명서). "한국 적금은 대부분 단리"라는 비율 주장은 확인 못함
1-8loan원리금균등·원금균등·만기일시 상환원리금균등: 매달 같은 금액 A(1-5의 식)를 내고, 앞쪽에는 이자 비중이, 뒤쪽에는 원금 비중이 큽니다. 원금균등: 매달 원금 P/N을 같게 갚고 남은 원금에 이자가 붙어 납입액이 줄어듭니다. 총이자 = P·i·(N + 1)/2. 만기일시: 매달 이자 P·i만 내고 원금은 만기에 한 번에 갚습니다. 총이자 = P·i·N. 같은 금리·기간이면 총이자는 원금균등 < 원리금균등 < 만기일시 순입니다.[S31] [S38]보도로 확인 (정의와 총이자 순서는 은행 안내문. 식은 수아가 유도하고 600만 원 예시로 검산)
1-9npv순현재가치(NPV)와 내부수익률(IRR)NPV(r) = Σ Ct / (1 + r)t. IRR은 NPV를 0으로 만드는 할인율입니다. 현금흐름의 부호가 두 번 이상 바뀌면 IRR이 여러 개일 수 있고(데카르트 부호 규칙: IRR 개수 ≤ 부호 변화 횟수), 처음과 마지막 현금흐름의 부호가 같으면 IRR이 없을 수 있습니다(예: −1, +1, −1).[S33]교재 수준 확인 (수아가 두 근 예시와 근이 없는 예시를 직접 계산, 기준값)
1-10inflation피셔 관계정확한 식 (1 + 명목) = (1 + 실질)(1 + 물가), 곧 실질 = (1 + 명목)/(1 + 물가) − 1. 어림식 실질 ≈ 명목 − 물가는 금리가 0에 가까울 때만 잘 맞습니다. 세후 실질은 명목 금리에 (1 − 세율)을 먼저 곱한 뒤 같은 식에 넣습니다(세금은 명목 이자 전체에 붙으므로).[S35]교재 수준 확인 (원 페이지는 수식이 읽히지 않아 "실질 ≈ 명목 − 물가, 금리가 0에 가까울 때 쓰는 어림" 문장만 확인. 세후 식은 은재·수아가 정리했고 원 페이지에는 없음)
1-11cagr산술 평균, 기하 평균, CAGRCAGR = (마지막 값 / 처음 값)1/n − 1 = [(1 + R1)…(1 + Rn)]1/n − 1(기하 평균 수익률). 산술 평균은 늘 기하 평균보다 크거나 같고, 수익률이 흔들릴수록 차이가 커집니다. 어림식: 기하 평균 ≈ 산술 평균 − σ²/2(변동성 손실). +50% 뒤 −50%는 산술 평균 0%인데 CAGR은 −13.40%입니다.[S36] [S37]교재 수준 확인 (원 페이지는 σ²/2 식이 그림이라 "기하 평균 = 산술 평균 − 변동성의 함수" 문장만 확인. 어림식의 정확도는 수아가 예시 경로로 대조)
1-12fees비용의 복리연 비용률 f를 해마다 떼면 n년 뒤 F = P(1 + r − f)n(수익률에서 뺄 때) 또는 P[(1 + r)(1 − f)]n(평가액에서 뗄 때)입니다. 비용이 없을 때와의 비율 [(1 + r − f)/(1 + r)]n이 시간이 갈수록 작아져, 연 1%가 30년 동안 쌓이면 최종 금액의 약 4분의 1이 사라집니다(기준값).[S34] [S26]교재 수준 확인 (식은 복리의 응용으로 수아가 정리. 펀드 보수가 순자산에서 빠진다는 점은 보도로 확인)

NPV·IRR 검산 예시

  • 현금흐름 −100, +230, −132: NPV(10%) = 0, NPV(20%) = 0. IRR이 두 개입니다(부호 변화 두 번).
  • 현금흐름 +100, −300, +250: x = 1/(1 + r)로 두면 100 − 300x + 250x²의 판별식이 90,000 − 100,000 < 0이라 실수 IRR이 없습니다. NPV는 할인율 0%에서 50, 50%에서 11.1, 100%에서 12.5로 늘 양수입니다.

마지막 과제: 600만 원을 상환할까, 3년 투자할까
